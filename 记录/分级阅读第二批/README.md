# 分级阅读第二批：工作记录

2026-11-10 做的西班牙语分级阅读第二批（`a1_11`—`c1_20`，A1—C1 每级 10 篇，共 50 篇，每篇约 1 分钟；A1—A2 0.8 倍速，B1—C1 原速）的编写、审读和生产记录。

成品不在这里：文章 JSON 在 `西班牙语/文章/`，音频（MP3）和字幕（SRT）在 `西班牙语/audio/qwen3_M1F5_25_slow/`（A1—A2）和 `西班牙语/audio/qwen3_M1F5_25/`（B1—C1），视频和核查报告在 Release `graded-reading-2`。

文件里的本机路径换成了占位符：`<KIT>` 是工具包根目录，`<工作区>` 是生产用的工作目录（`<工作区>/gr2` 放生产脚本、状态和日志），`<写作区>` 是写文章用的目录，`<临时目录>` 是临时目录，`~` 是用户主目录。

## 文件

| 文件 | 内容 |
|---|---|

| `日志/` | 每篇的音频、视频、逐句识别核对日志（`<编号>.audio.log`、`<编号>.video.log`、`<编号>.asr.log`），各条生产链的总日志（`audio_queue.log`、`video_*.log`），画面折行检查结果（`wraps_*.txt`） |

## 怎么做的

1. **编写**：按 `编写要求.md` 写每篇的 JSON，用工具包的 `check_articles.py` 检查格式和生词，用 `工具/est.py` 估算时长（片头 1.5 秒 + 每词秒数 × 词数 + 句间 0.8 秒 + 结尾 2 秒），要在 57–63 秒之间。B2 起初按 B1、C1 的中间值每词 0.355 秒估算，每篇都加了一句凑时长；原速实测每词约 0.39 秒，8 句要 66 秒左右，于是用 `工具/drop_sentence.py` 把加的那一句删掉（7 句，约 58–61 秒），各篇 `_说明` 末尾写了删的是哪一句。合成缓存按句子文字存，删句以后其余各句不用重新合成，朗读和识别核对结果都不变。
2. **审读**：按 `审读要求.md` 独立审读，改动用 `工具/fix.py` 做（按原文片段逐条替换，片段在文件里必须恰好出现一次），`工具/diff.py` 列出改了什么。
3. **音频**：`工具/queue_runner.sh` 按 `工具/queue.txt` 的顺序逐篇合成。同一时间只跑一个 `make_audio.py`，因为它最后会改写 `timings.json`。`工具/env.sh` 是各个脚本共用的路径和音色设置。
4. **视频和识别核对**：`工具/video_chain*.sh` 等每篇音频做完就生成视频（工具包的 15 项核查不过就不输出），再用 `asr_check_reading.py` 从成品 MP3 切出每一句识别，和原文逐词比。Qwen3 合成用固定种子，同一句话重新合成结果不变，所以识别对不上的句子是改写措辞（换一种说法或换词）以后重新合成，直到逐词一致。
5. **版式**：做的过程中发现生词释义会在词中间折行、译文最后一行会只剩一个字，于是改了 `make_video.py` 的折行规则，所有第二批视频都按新版式生成。`check_wraps.py` 的检查结果：改之前 `日志/wraps_all.txt`（163 处要处理），改之后 `日志/wraps_new.txt`（1 处：C1-15 第 1 句的词头 algoritmo de recomendación 在两个词之间换行，释义没有断开；后来检查规则改成词头在词与词之间换行只算提示），定稿 `日志/wraps_final.txt`（0 处要处理；“提示”是原文最后一行只有一个词、译文最后一行两个字、词头在词与词之间换行这类，不算问题）。
6. **抽帧检查**：`工具/frames.py` 每篇截两帧（西语最长的一句、生词栏文字最多的一句）拼成图，逐张看版面。
7. **发布**：`工具/build_release.py` 先查 50 篇都有视频、15 项核查全部通过、逐句识别核对通过、视频比文章和 `make_video.py` 都新，再准备 Release 的文件、发布说明和 README 表格；`工具/publish.sh` 提交、推送、上传 Release；`工具/verify_upload.py` 核对远端的文件和本地一致。`工具/collect_records.py` 把这些记录收进这个文件夹。`工具/gen_files.py` 列出要提交进仓库的文件，`工具/desk_copy.py` 把视频复制到桌面的文件夹，`工具/readme_edit.py` 改工具包 README 里第二批的说明。
