# 第二批分级阅读：独立审读要求

你是独立审读，没有参与写作。文章是给中国的西班牙语学习者做逐句精读视频用的（画面显示西语原句、中文翻译、3–5 个生词），用户要求“可以直接使用的水平，不能有任何错误”。编写规则在 `<写作区>/编写要求.md`，先读它；样板是 `西班牙语/文章/a1_11.json`。

逐篇、逐句检查下面每一项，**只报确实有问题、或者明显可以改得更好的地方**，不要为了凑数挑刺：

1. **西语**：语法（性数一致、变位、时态和语式、介词、冠词、代词位置）、拼写、重音符号、标点（¿¡、逗号）；用词是否地道、搭配是否自然；有没有母语者不会这么说的句子。
2. **级别**：语法和词汇是否符合该级别（A1 只用现在时；A2 不该出现虚拟式；B1 以上要有相应难度）。超出级别的词或结构要指出并给替换方案。
3. **中文翻译**：是否忠实（没有漏译、多译、误译），是否通顺自然；标点用全角。
4. **生词**：
   - 释义是否是这句里的意思，和中文翻译是否对得上；释义是否准确（词典意义上不能错）。
   - 词性是否按句中用法标（例如 ser/estar 标 intr.；作形容词用的过去分词标 adj.；se 动词按句中用法标 prnl.）。
   - 词头是否是词典形式（动词原形、名词单数、形容词阳性单数，短语的原形）。
   - 是否只在第一次出现的句子里标；同一词头不重复。
   - 选词是否合适（B1 以上不标一眼就懂的同源词；值得标的固定搭配有没有被拆开标）。
5. **逗号**：名词、形容词列举的逗号有没有登记在 no_pause_commas 里（`-v` 打印的朗读分段里 `|` 是停顿）；不该登记的有没有被登记。
6. **内容**：是否原创、积极、适合课堂；事实性陈述是否站得住（不能有错误的常识）；有没有真实品牌、名人、机构、统计数字。
7. **朗读风险**：有没有语音合成可能读错的东西（生僻专名、外来词、单独一个词成句）。

可以运行（只读，不要改任何文件）：

```
cd <写作区> && ./py 西班牙语/tools/check_articles.py <编号>… -v
cd <写作区> && ./py est.py <编号>…

```
