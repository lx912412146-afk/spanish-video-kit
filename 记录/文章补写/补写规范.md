文章在 `KIT/西班牙语/文章/<编号>.json`，编号是 `a1_01`…`c1_10`。每个文件已经有 `id`、`level`、`no`、`title_es`、`series`、`header` 和逐句切好的原文 `paras[0][i].es`。你要补的字段：`title_zh`、每句的 `zh` 和 `w`，以及 `pos_legend`、`no_pause_commas`，并更新 `_说明`。

**只改分配给你的 10 个文件。** 不要改 `es` 原文、句子的切分和顺序、`id`、`level`、`no`、`title_es`、`series`、`header`，也不要改别的文件和程序。不要生成音频或视频。

## 先看范例

- `KIT/西班牙语/文章/es01.json` 和 `KIT/西班牙语/文章/es01_生词栏说明.md`：原作者的范例和选词思路，比如为什么选、词性怎么标、哪些故意不选。

## 每个字段怎么写

- `title_zh`：标题的中文译名，简洁自然，比如 "Mi familia" → "我的家庭"。
- `zh`：这一句的中文翻译。忠实、通顺、自然，不添加也不漏掉内容，语气符合原文。专有名词用通行译名（Salamanca 萨拉曼卡）。
- `w`：这一句的生词栏，**3–5 个**。句子短的给 3–4 个，长句给 4–5 个，优先 4 个。每个生词是一个对象：
  - `h`：词头，用词典原形。动词写不定式（me levanto → levantarse）；形容词写阳性单数；名词写单数（只有复数形式的除外，比如 deberes）；短语写成词典形式（dar un paseo、tener que + inf.、siempre que）。
  - `pos`：词性，只能用这些标签：`m.` 阳性名词、`f.` 阴性名词、`adj.` 形容词、`adv.` 副词、`tr.` 及物动词、`intr.` 不及物动词、`prnl.` 自复动词、`prep.` 介词、`conj.` 连词、`num.` 数词、`interj.` 感叹词、`pron.` 代词、`loc.` 短语/固定搭配。
    - 动词按它**在这一句里的用法**标 tr. / intr. / prnl.。
    - 多词词头一般标 `loc.`；名词短语跟中心名词的阴阳性（comida típica → f.）；"动词 + 介词 + 不定式"标 `loc.`。
  - `zh`：释义，用这句话里的意思，**不超过 14 个汉字**（不算空格），可以用"，"分隔两个义项。
  - `surface`：这个词在句子里的**原样写法**，大小写和重音都一样，比如句首的 "Mi"、变位形式 "estudia"、复数 "abuelos"。它必须满足三条，否则程序会报错：
    - 在这句的 `es` 里**恰好出现一次**。程序按子串计数，"e"、"a"、"es"、"la" 这类很短的写法几乎一定会出现多次，不能用。
    - 是**完整的词**，前后不能紧挨着字母。比如 "pan" 不能取自 "panadería"。
    - 同一句里各个生词的 surface **互不重叠**。
  - `source`：一律写 `"supplement"`。
- 选词原则：
  - 选**这个等级的学习者最可能不认识、最值得讲**的词和搭配：不规则变位、自复动词、固定搭配（hace frío、dar un paseo、echar de menos）、连接词（sin embargo、no obstante、siempre que）、动词加介词的结构，以及中高级的抽象词汇。
  - A1/A2 可以选常用的日常词汇。等级越高，越要少选一眼就懂的同源词（información、importante 这类），除非是假朋友。
  - **同一篇里，同一个词头只在第一次出现的句子里列。**
  - 生词按在句中出现的先后排序，程序也会自动排。
- `pos_legend`：**恰好**列出这一篇用到的词性标签，值用上面的中文名，比如 `{"m.": "阳性名词", "loc.": "短语，固定搭配"}`。
- `no_pause_commas`：登记"读的时候不停顿的逗号"。规则是：逗号、分号、冒号、破折号处默认停顿 0.35 秒；**列举**（A, B y C）和**并列的形容词**之间的逗号不停顿，要登记在这里。从句、句首状语、插入语两边的逗号照常停顿，不用登记。
  - 格式：`{"<第几句，从 1 开始>": [{"after": "<逗号前那一段的结尾，包含逗号本身>", "why": "<一句话理由>"}]}`。
  - 例子：句子是 "Llevo una lista: leche, huevos, arroz, tomates, manzanas y pan."，这一句的条目是 `[{"after": "leche,"}, {"after": "huevos,"}, {"after": "arroz,"}, {"after": "tomates,"}]`（每条再加上 why）。
  - 程序的切分方式：在 `, ; : —` 后面跟空格的地方切段。如果前一段的结尾等于某条 `after`，这两段就合并、不停顿。只有一个词的段会自动和后面合并，不用登记。登记了却匹配不到会报错。
  - 没有要登记的就写 `{}`。
- `_说明`：把骨架里的"zh、w 待补"改成说明这篇已经补好，比如"zh：逐句中文翻译；w：生词栏（全部为补充词条），……"，并写上你做过的特别判断（比如某个歧义怎么译的）。

## 检查（必须做，直到全部 OK）

在终端运行（环境由 setup_mac.sh 装在 KIT/.mac-env）：

```
cd "KIT" && .mac-env/bin/python 西班牙语/tools/check_articles.py <编号…> -v
```

（把 KIT 换成工具包根目录的实际路径。）`-v` 会打印每句的朗读分段，`|` 是停顿的地方，用它确认列举的逗号没有停顿。输出里 OMP 或 SoX 的警告可以忽略。每篇都要显示 `<编号> OK`；"提醒"也尽量消除。

JSON 用 UTF-8，`ensure_ascii=False` 的写法，缩进 1 格，和骨架一致。可以用 Python 读写，也可以直接编辑。
