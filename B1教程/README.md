# 西班牙语 B1 教程（学生用书＋教师用书＋录音）

《西班牙语 A1 教程》（`../A1教程/`）、《西班牙语 A2 教程》（`../A2教程/`）的续篇，面向学完 A2 的中国大学生和成人学习者：10 个单元、2 个复习单元，学生用书和教师用书各一本（教师用书含 2 套阶段测试），配全部课文、听力、语音跟读、生词跟读和测试的录音。讲解以中文为主，课文、例句和练习用西班牙语。Word、PDF 和录音在 Release [`b1-textbook`](../../../releases/tag/b1-textbook)。

## 内容

| 部分 | 内容 |
| --- | --- |
| 学生用书 | 使用说明；第 1–10 单元（每单元：单元目标、导入、课文一、词汇、语法、交际、课文二、听力、语音和拼写、读写、文化窗口、调解小活动、单元任务、自我评估和 DELE B1 题型小测、单元小结）；复习 1、2（含 DELE B1 题型小测）；附录 A 语法总表、B 动词变位表、C 西中词汇总表、D 课文译文和听力原文 |
| 教师用书 | 教师用书使用说明（教学理念、全书目标与 CEFR / PCIC / DELE B1 的对照、和 A2 的衔接、虚拟式的教学安排、课时方案、录音说明、中国学生在 B1 阶段的常见难点、评价）；逐单元的教学目标、课时安排、分步教学建议、语音教学要点、常见错误、文化背景、补充活动、全部练习答案、本单元录音稿；阶段测试 1、2（可复印的完整试卷、答案、本书仿照 DELE B1 的写作和口语评分量表） |
| 录音 | 每单元的课文、听力、语音跟读、单元小测和生词跟读；复习单元和阶段测试的听力，共 92 段，约 3 小时 24 分钟。文件名是录音号：B1_3-1.mp3、生词跟读 B1_3-V.mp3、小测 B1_3-Q1.mp3、复习 B1_R1-1.mp3、测试 B1_T1-1.mp3 |

- 依据《欧洲语言共同参考框架》（2020 年增补卷）B1 描述和塞万提斯学院《课程计划》（PCIC）B1 清单编写，测试题型参照 DELE B1：PCIC B1 是核心（现在虚拟式的高频用法、否定命令式和代词组合、条件式简单式、过去完成时、将来时、间接引语的基本形式等），少数 PCIC 列在 B2 的高频内容标“B1+ 拓展”，讲得简短、测试不考。编排参考海外交际法 B1 教材（Prisma、Aula、Nuevo Español en marcha、Método 等）的通行做法；课文、对话、练习、人物全部原创，没有使用这些教材的任何内容。整理过程见 `资料/B1大纲和教材结构.md`。
- 人物和 A1、A2 相同（陈雨、李浩、Carmen，以及回国的 Lucía、Diego），加上格拉纳达来的交换生 Irene，故事接着讲第二学年的秋季学期（2027 年 9 月—2028 年 1 月）。A1、A2 的人物和情节整理在 `资料/A1A2人物和情节档案.md`，B1 各单元定下的细节和统一规则在 `待统一问题.md`。
- 录音用本仓库的 Qwen3-TTS 合成，五个声音和 A1、A2 相同，Irene 是新加的第六个声音；对话正常语速、跟读和生词约 0.92 倍；每句都用语音识别（Parakeet）核对，并做响度和电磁音核查。
- 每个单元由一人编写，另一人独立审校，再由第三人二校；复习单元、测试、附录也都单独校对过。

## 重新生成

Word：需要 Node.js 和 `npm install docx@9.5.1`。PDF 用 LibreOffice 26.8 转（用 FONTCONFIG_FILE 指向能找到苹方的字体配置；26.2 会换掉字体）。录音在 `setup_mac.sh` 装好的环境里运行（另需 Parakeet 识别模型）：

```bash
python B1教程/tools/check_unit.py 01 02 03 04 05 06 07 08 09 10 R1 R2 T1 T2
node B1教程/build_b1.js student B1教程/out/西班牙语B1教程_学生用书.docx
node B1教程/build_b1.js teacher B1教程/out/西班牙语B1教程_教师用书.docx
python B1教程/tools/make_tracks.py . B1教程 B1教程/audio_out 识别模型目录 01 02 03
```
