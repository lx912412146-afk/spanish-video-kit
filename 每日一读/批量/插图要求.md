# 西班牙语每日一读（50 篇）：插图要求

每篇视频是一页竖版“阅读卡”，插图在页面左上方，显示尺寸约 384×250（手机竖屏上看）。插图左上角由程序叠上西语标题，字体 Georgia 14.5，深灰色 #55524c。

**样板**：
- `每日一读/批量/style_ref.svg`：用户已看过、选定的样片插图，阳台小菜园；
- 预览图：`每日一读/批量/style_ref.png`。

风格、质感、配色都照它来：柔和的水彩风、暖色纸面、轻微的手绘抖动边缘、纸纹、四周渐隐。

## 你要做的

按《选题表》（`每日一读/批量/选题表.json`，`scene` 字段是画面内容）给你负责的 10 篇各画一张：
- 插图写到 `每日一读/批量/illust/<编号>.svg`；
- 预览写到 `每日一读/批量/illust_png/<编号>.png`。

## 技术要求

- **画布**：`viewBox="0 0 400 260"`，`width="400" height="260"`。
- **结构照样板**：
  - `<defs>` 里的滤镜 `wc`（feTurbulence + feDisplacementMap 水彩抖动）、`soft`、`soft2`、`grain`（纸纹）、`edge` 和遮罩 `fade`（四周渐隐）整段照抄；
  - 全图放在 `<g mask="url(#fade)">` 里，背景先画；
  - 主体放在 `<g filter="url(#wc)">` 里；
  - 地面阴影用 soft2；
  - 最后一层是 `<rect width="400" height="260" filter="url(#grain)"/>`。
- **只用基本元素**：rect、circle、ellipse、path、polygon、polyline、line、g、use、defs、linearGradient、radialGradient、filter、mask、clipPath。
  - **不能有** `<text>`、`<image>`、`<style>`、`<script>`、`<foreignObject>`；
  - 不能有外部链接、内嵌图片；
  - 文件 ≤ 60 KB。

## 画面要求

- **一眼看出画的是什么**：照选题表的画面内容，主体清楚，前景、中景、背景有层次，有柔和的明暗（渐变）、地面阴影。透视合理，物件不要奇怪地重叠、悬空或被截掉一半（四周渐隐处除外）。
- **左上角留给标题**：x 0–240、y 0–48 这块要浅色、安静、少细节，比如墙面、天空、浅色背景。预览程序会量这块：平均亮度要 ≥ 200，起伏要 ≤ 25，不达标标题会看不清。
- **配色**：和样板同一家族。
  - 暖米色、浅杏色的墙面和纸面，柔和的绿、陶土红、灰蓝、暖黄；
  - 不要荧光色；
  - 不要纯黑，最深的颜色约 #4a4038，只用在小细节上。
  - 夜景（星空）可以用深蓝，但要柔和，并且仍然让左上角足够亮，比如左上是浅色的夜空渐变或月光。
- **画面上不能出现**：
  - 任何文字、字母、数字（钟面不画数字，屏幕只画柔和的色块，书和信不写字）；
  - 商标、国旗；
  - 能认出的真实地标、名画、品牌产品。
- **人物**：尽量不画人，像样板那样用物件和场景来讲。实在需要，只画很小的远景剪影，不画五官。
- **质量标准**：和样板一样精致，可以直接放进出版物。宁可少画几样东西，也要每样都画好。

## 流程

1. 先看样板的 SVG 和 PNG。
2. 每画完一张，就运行预览程序：
   ```bash
   python 每日一读/tools/render_svg.py 每日一读/批量/illust/<编号>.svg 每日一读/批量/illust_png/<编号>.png "<西语标题>"
   ```
   - 这条命令要启动 Chromium，Bash 需要设 `dangerouslyDisableSandbox: true`；
   - 西语标题照选题表的 `title_es`。
3. **用 Read 看生成的 PNG**，对照上面的要求检查，有问题就改，改完再看，直到满意。
4. 程序必须输出 `OK`，标题区域没有“提醒”。

最后报告：每张的编号、一句话描述、文件大小，以及你觉得还不够好的地方。

只写你负责的 10 个 SVG 和 10 个 PNG，不要改别的文件。
