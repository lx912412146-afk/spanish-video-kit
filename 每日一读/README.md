# 每日一读（单页朗读视频）

一种视频形式：竖版的一页“阅读卡”，整段配西语朗读。2026-11-11 按用户给的参考视频的**形式**先试做了第 01 篇样片，用户选定逐句高亮版后，同一天做了 **A1—C1 五级、每级 10 篇，共 50 篇**。文章、插图、版面细节都是原创，没有用参考视频里的任何内容。

## 形式

- 画面 1080×1512（5:7 竖版），24 帧/秒。一页上依次是：
  - 标题栏：西语标题 | 中文标题，右边是栏目语“每日一读 积少成多”，下面一条粗线；
  - 水彩风插图，左上角写着西语标题；
  - 右栏“重点词汇”15 条（西语原形＋中文）；
  - 西语短文两段（两端对齐、首行缩进）；
  - 中文译文两段。
- 朗读：西语，先读标题，再逐句读，句间停顿 1.0 秒，全长约 1 分钟。
- **成品是逐句高亮版**（用户 2026-11-11 看过样片后选定）：正在读的那句西语和它的译文标浅黄，读标题时标题栏标黄。
  - 样片另有一个静态版（整段一张图，和参考形式一样），留作备用；50 篇只出逐句高亮版。

## 50 篇（2026-11-11）

- 级别和朗读：
  - A1、A2 用 `qwen3_M1F5_25_slow`（男声，0.8 倍速）；
  - B1、B2、C1 用 `qwen3_M1F5_25`（同一男声，原速）。
- 篇目和插图画面见 [`批量/选题表.md`](批量/选题表.md)；每篇的时长、响度、版面测量、核查项数见 [`批量/成品一览.md`](批量/成品一览.md)。
- 时长 54.5—64.8 秒，平均 59.9 秒；正文共 6328 词。句间停顿 37 篇是 1.0 秒，7 篇 0.9 秒，6 篇 0.8 秒（1.0 秒时 3 秒短时响度波动超过上限 1.0 LU，工具自动缩短）。响度 −16.55—−16.41 LUFS；西语词间空白最大 7.9 px（上限 8 px）。
- 每篇的核查 36—46 项（随句数而定），50 篇共 2074 项，全部通过；报告在 `批量/核查/`。
- 视频在 Release `daily-reading-50`：
  - `daily_A1-01_Mi_abuela.mp4` … `daily_C1-10_La_plaza_lugar_de_encuentro.mp4`（文件名是级别、篇号和去掉重音的西语标题）；
  - `daily-reading-50-SHA256SUMS.txt`：50 个视频的校验和。

### 每级写法

| 级别 | 句数 | 正文词数 | 每句最多 | 语法和内容 |
|---|---|---|---|---|
| A1 | 11—13 | 108—124 | 15 词 | 只用陈述式现在时（可以用 ir a + 原形、gustar、hay、tener que）；常用词，句子短而清楚 |
| A2 | 10—12 | 105—120 | 16 词 | 现在时、现在完成时、简单过去时、过去未完成时、ir a + 原形、比较级 |
| B1 | 9—11 | 130—146 | 22 词 | 再加上现在虚拟式的常见结构（es importante que、para que、cuando + 虚拟式）、条件式、常用连接语 |
| B2 | 8—10 | 116—132 | 24 词 | 再加上过去虚拟式、被动结构、名词化、较复杂的连接语（no obstante、en cambio、de hecho）；有观点、有论证 |
| C1 | 7—9 | 118—134 | 26 词 | 抽象论述、精确的书面词汇、多层从句、让步和假设，像一篇短小的随笔 |

- 每篇都是原创短文，题目避开了分级阅读第一批、第二批已有的题目；人名每篇最多两个，用常见的西语名字。
- 叙述者和朗读音色一致，都是男性：第一人称的形容词、分词一律用阳性。
- 重点词汇 15 条：词头是词典形式，释义取这篇里的意思；第三项是正文里第一次出现的写法，顺序按首次出现。
- 文章里有 `_说明`：写这篇用到的语法、译法上的判断、和插图对应的地方，以及后来改过的地方和原因。

### 怎么做的

1. **选题**：`批量/make_topics.py` 生成 `批量/选题表.json`／`.md`（编号、级别、音色、标题、插图画面）。
2. **写文章**：按 [`批量/编写要求.md`](批量/编写要求.md) 写 `批量/articles/<编号>.json`，格式照 `批量/样板.json`（第 01 篇样片改成批量用的格式）。
   - 每篇用 `tools/check_daily.py` 自查：格式、字符、句数、词数、估算时长、重点词汇、中文标点、列举逗号的登记、容易读错的词。
3. **画插图**：按 [`批量/插图要求.md`](批量/插图要求.md) 手写 SVG 到 `批量/illust/<编号>.svg`，风格照 `批量/style_ref.svg`（样片插图去掉了标题文字，标题由排版程序叠上）。
   - 每张用 `tools/render_svg.py` 自查：不能有文字、外部图片和脚本；要有水彩滤镜、纸纹、四周渐隐；标题区域不能太暗、太花。
4. **审读**：写完后每级 10 篇另做一遍独立审读，逐句核对西语、级别、译文、重点词汇、逗号停顿，并对照插图检查颜色和物件，记录在 `批量/审读/A1.md` … `C1.md`。
5. **合成和出片**：在工具包根目录运行

   ```bash
   python 每日一读/tools/run_batch.py 每日一读/批量 <Parakeet 模型目录>            # 全部 50 篇
   python 每日一读/tools/run_batch.py 每日一读/批量 <Parakeet 模型目录> daily_b2_04  # 只做某几篇
   ```

   - 按选题表顺序一篇一篇合成朗读，同一时间只跑一个合成；朗读好的篇目在另一条线上排版、出视频、核查。
   - 输出到 `批量/out/<编号>/`，进度写在 `批量/status.json` 和 `批量/run.log`。
   - 朗读的文字没变就不重新合成，文章、插图、朗读、工具都没变就不重新出片；核查没过的篇目再跑一次会重做。
   - 合成结果按句子文字缓存，改了一句只重新合成这一句（约 1 分钟一篇）；全新的一篇约 4—5 分钟。
6. **归档**：`tools/collect_batch.py` 先确认 50 篇都有视频、核查都写着“全部通过”、标题和选题表一致，再把视频复制到 Release 目录（写 SHA256SUMS）和桌面，把文章、插图、朗读、时间表、核查报告等复制进本目录。`tools/summary_batch.py` 生成成品一览。

### 合成和核查后改过的地方

全部记录在 [`批量/审读/朗读修正.md`](批量/审读/朗读修正.md)，每处都同步了译文、重点词汇、逗号登记和 `_说明`。

- **朗读识别对不上（6 篇 8 句）**：合成用固定种子，同一句文字重合成结果完全一样，所以只能改写法。
  - 大多是词尾被吞，例如 manzanas → manzan、colocado → coloc、zonas → zon、tardes → tarde、mañanas → mañan：这个音色的词尾 s 很弱。
  - 也有同音词（valla 识别成 baya），和 martillo y 连成一个音吞掉的 y（这个音色把 ll 读成 y）。
  - 改了一句重新合成后，句间停顿或电平档位可能跟着变，同一篇里原来通过的句子也可能出问题（B2-02 第 3 句），所以改完整篇重新核查。
  - 改法是换语序、换同义词或改成单数，例如 una valla de madera → una cerca de madera；dos tardes por semana 改成 dos tardes a la semana 后 s 仍然被吞，最后改成单数 una tarde a la semana；el cepillo, el martillo y la sierra 最后改成 el martillo, la sierra y el cepillo。
- **西语词间空白太大（7 篇）**：排版工具在 12.6—13.4 px 字号、−0.15—+0.1 px 字距里找不到词间空白 ≤ 7.5 px 的一组。
  - 另外试过更细的字号、负词距、换行算法，也做不到；不用连字符断词，免得初学者看不懂。
  - 所以离线排版试了多种改法，每篇只改一两个词让换行位置变一变，意思不变，例如 Solemos plantear → Solemos ver。
- **审读后改的**：
  - 正文和插图对不上的地方：窗帘、自行车的颜色等；
  - 容易连读的语序：Siempre elijo → Elijo siempre；
  - 译名：magdalena 从“松糕”改为“小蛋糕”；
  - 各级的具体改动见 `批量/审读/`。
- A1 篇目字少，页面底部留白比别的级别多（约 140—200 px）。字号统一不放大，保持和其他级别一样。

## 核查（`tools/qa_daily.py`）

1. **规格**：H.264 1080×1512、24 帧/秒、yuv420p，AAC 48 kHz；视频和音频时长相差不超过 1 帧；总时长 53—67 秒。
2. **声音**：
   - 整体响度 −16±0.7 LUFS，峰值 ≤ −1 dBFS；同时有静态版时，两个版本的音轨要逐样本相同；
   - 合成时工具包的响度四项、电磁音两项全部通过；
   - 逐句切出用 Parakeet 识别，和朗读原文逐词比对（换四种切点取最好的），每句（含标题）都必须 0 处出入。
3. **画面**：
   - 高亮版每一段取中间一帧，和全部源图（静态页＋各句高亮页）逐对比较：只看应显示的那张和另一张不同的像素，这一帧必须明显更接近应显示的那张；
   - 每句从开口到读完都高亮这一句；
   - 有静态版时，在全片均匀取 6 个时间点比对。
4. **版面**：页面不滚动、没有文字被截断，底部留白 ≥ 40 px，各区块互不重叠，西语两端对齐的最大词间空白 ≤ 8 px，标题栏左右两块之间留空 ≥ 12 px，插图上的标题不超出插图，词汇栏每条都在栏内。
5. **内容**：
   - 15 个重点词汇的原文写法都能在正文里找到（完整的词）；
   - 中文没有半角标点；
   - 朗读文字＝标题＋正文，逐句一致。

## 样片做的过程中改过的地方

- **句间停顿**：参考视频约 1.3 秒。试了 1.3、1.2、1.1 秒，工具包的 3 秒短时响度波动分别是 1.34、1.24、1.13 LU，超过上限 1.0 LU。原因是窗口里静音占比变大，朗读本身句间偏差只有 0.44 LU。不改核查标准，取能通过的 1.0 秒（0.95 LU）。
- **第 6 句**：原来是 Cuidar el huerto me enseña…，识别核对时 huerto me 四种切法都认成 huerme。固定种子重合成结果不变，所以改成 Cuidar el huerto también me enseña…，译文同步改为“也教会我”。
- **西语排版**：13 px 时第二段有两行词间空白 11–12 px。试了 7 种字号 × 7 种字距，改为 13.1 px、字距 −0.05 px，最大 7 px。
- **独立审校**：西语没有发现错误。译文按审校意见改了两处，更贴近原文：
  - “让我学会了耐心”→“教会我要有耐心”（原文 me enseña）；
  - “从不用化学药剂”→“不用化学药剂”（原文 no uso）。
