## SIELE 常用术语对照

这一附录收集 SIELE 官网、官方考试指南、考试界面和成绩通知里常见的西语术语，按用途分成五组。名词前面带定冠词，可以看出阴阳性；指人的名词写出阳性和阴性两种形式；界面上的按钮和标记，照屏幕上的写法列出。“说明”一栏里涉及考试规定的内容，依据本书第 1 章，各项考试的细节见第 2 到第 5 章。“题型”和“文体”两组收的是讲题型、读题目时常用的西语词，考试界面上的具体措辞以考试当天的屏幕为准。

### 评分和成绩

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| el Certificado SIELE | SIELE 证书 | 考 Global 得到，有四项分数、等级和总分 |
| el Informe SIELE | SIELE 成绩报告 | 考 S1–S5 得到，有所考各项的分数和等级 |
| la puntuación | 分数、得分 | 每项 0–250，Global 总分 0–1000 |
| la validez | 有效期 | 证书和成绩报告都是 5 年 |
| Inferior a A1 | 低于 A1 | 每项分数段表里最低的一档 |
| NO APTO | 不合格 | 官方指南注释：低于 A1 相当于不合格 |
| el calificador, la calificadora | 评分员 | 经过培训和认证，给写作、口语打分 |
| la cohesión | 衔接 | 写作的评分维度 |
| la corrección | 准确 | 写作的评分维度 |
| el alcance | 语言范围 | 写作的评分维度 |
| el uso de la lengua | 语言运用 | 口语的评分维度 |
| el cumplimiento de la tarea | 任务完成 | 写作和口语都有的评分维度 |
| la revisión | 复核 | 写作、口语各可付费复核 1 次 |
| la reclamación | 申诉 | 对考场情况的申诉；购买条款写考后 24 小时内提出 |
| Comprobar certificado | 证书验证 | 官网核验证书真伪的页面 |

复核要在首次收到成绩通知后 7 个自然日内，通过“Mi página”申请，以复核后的分数为最终分数，分数也可能下降。官方没有公布 0–1000 总分对应哪个等级，所以这里没有“综合等级”这样的术语。

### 考试界面和操作

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| Mi página | 我的页面（个人页面） | 在官网查看成绩、下载证书、申请复核 |
| Siguiente | 下一个 | 如听力中点它可提前进入下一个任务 |
| Teclado español | 西班牙语键盘 | 写作界面上的按钮，输入西语特殊字符 |
| Terminar la grabación | 结束录音 | 口语中提前结束录音 |
| NO EVALUABLE | 不计分 | 口语 Tarea 2、5 屏幕笔记框上的标记 |
| la grabación | 录音 | 听力的录音；口语的作答录音 |
| el ratón | 鼠标 | 官方提醒在题目之间移动要用鼠标 |
| el menú desplegable | 下拉菜单 | 阅读 Tarea 3、5 用它选答案 |
| tomar notas | 记笔记 | 口语 Tarea 2、5 可在笔记框里打字 |
| el tiempo de preparación | 准备时间 | 口语 Tarea 2、5 是准备 2 分钟 |
| REALIZAR DEMO DEL EXAMEN | 进入考试模拟 | siele.org 考试页面上的按钮 |
| DESCARGAR GUÍA DE EXAMEN | 下载考试指南 | siele.org 考试页面上的按钮 |

Mi página、Siguiente、Teclado español、Terminar la grabación、NO EVALUABLE 和最后两个按钮，是官方考试指南和官网上的原词；el menú desplegable、tomar notas、el tiempo de preparación 是一般的西语说法，考试界面上是否这样写，以考试当天的屏幕为准。

### 题型

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| la pregunta | 问题、题目 | 口语 Tarea 1、4 的问题用音频播放 |
| la opción | 选项；可选的题目 | 单选题每题 3 个选项 |
| el distractor | 干扰项 | 如听力 Tarea 3 多出的 3 个陈述 |
| el enunciado | 陈述；题干 | 匹配题里要对应的句子 |
| relacionar | 匹配、对应 | 阅读 Tarea 3、听力 Tarea 3 |
| completar | 补全、填空 | 听力 Tarea 1 补全句子 |
| el hueco | 空、空缺 | 阅读 Tarea 4、5 里要填的地方 |
| el fragmento | 片段 | 阅读 Tarea 4 的备选片段；听力 Tarea 5 |
| el diálogo, la conversación | 对话 | 听力 Tarea 1、3 |
| el monólogo | 独白 | 听力 Tarea 3、5、6；口语 Tarea 5 |
| la entrevista | 访谈 | 听力 Tarea 4 |
| la conferencia | 讲座 | 听力 Tarea 5、6 |
| la fotografía | 照片 | 口语 Tarea 2 两张选一张 |
| la situación | 情境 | 口语 Tarea 3 每个情境二选一 |
| el tema | 话题 | 口语 Tarea 4 选定的话题沿用到 Tarea 5 |
| la afirmación | 论断 | 口语 Tarea 5 两个论断选一个 |
| la argumentación | 论证 | 写作 Tarea 2、口语 Tarea 5 |
| el número de palabras | 字数 | 写作 100–150 词；250–300 词 |
