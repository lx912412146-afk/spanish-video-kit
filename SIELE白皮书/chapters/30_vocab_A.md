## A1–A2 常考词汇

这一章按话题整理 SIELE 里 A1、A2 级任务常考的词汇（阅读和听力的 Tarea 1、2，写作 Tarea 1，口语 Tarea 1、2 都以这一级的词为主）。范围参考塞万提斯学院《课程计划》（PCIC）A1–A2 级按话题排列的“具体概念”（nociones específicas），只收这两级最常用、考试里最常碰到的词，共 19 个话题、680 条。每个话题一张表，意思相关的词排在一起，表后是几句常用例句。A1 考生先抓每个话题里最基本的词，A2 考生要做到全部会认、会写。

表里的写法：

- 名词带定冠词，看冠词就知道阴阳性：el libro、la mano。以重读 a 开头的阴性名词，单数前面用 el，但仍是阴性：el agua fría、el aula。阴阳同形的名词写 el/la estudiante；有阴阳两种形式的写 el hijo / la hija，词长的缩写成 el/la funcionario, -a（el funcionario / la funcionaria）。
- 形容词写阳性形式，后面加阴性词尾：nuevo, -a（nueva）、trabajador, -a（trabajadora）、alemán, -ana（alemana，阴性不带重音）。阴阳同形的只写一个：feliz、grande。
- 动词写原形。(ie)、(ue)、(i) 表示词根元音变化：pensar (ie) → pienso，volver (ue) → vuelvo，pedir (i) → pido。(zc) 表示第一人称单数加 z：conocer (zc) → conozco。(í) 表示有些人称重音落在 i 上，要写重音符号：esquiar (í) → esquío。(irreg.) 表示不规则动词；querer (ie, irreg.) 这样两种都标的，现在时是词根变化，别的时态还有不规则形式（quise）。以 -se 结尾的是代词式动词，代词随人称变化：levantarse → me levanto。
- 西班牙和拉美说法不同的常用词两种都列，斜线前是西班牙说法，斜线后是拉美说法，中文栏标“（西 / 拉美）”；拉美各国说法不统一的标“（西 / 拉美多用）”；主要在西班牙用的标“（西）”。同义词之间用逗号隔开：el sueldo, el salario。

| muy | 很（修饰形容词、副词） | mucho, -a | 很多的；（作副词）很，非常 |
| poco, -a | 少的；（作副词）不太，很少 | bastante | 相当；足够的 |
| demasiado, -a | 太多的；（作副词）太 | más | 更，更多（más … que） |
| menos | 更少，不那么（menos … que） | también | 也 |
| tampoco | 也不 | ya | 已经 |
| todavía | 还，仍然（todavía no 还没） | ahora | 现在 |
| aquí | 这里 | allí | 那里 |
| antes | 以前；先（antes de 在……之前） | después | 以后，后来（después de 在……之后） |
| luego | 然后；待会儿 | primero | 首先，先 |

! 汉语的“很”有两种说法：形容词、副词前用 muy（muy bueno、muy bien），动词后用 mucho（Me gusta mucho），不能说 Muy me gusta。

> Este ejercicio es muy fácil, pero el otro es bastante difícil.｜这道练习很简单，可另一道相当难。
> Hoy estoy muy contenta porque he aprobado el examen.｜今天我很高兴，因为考试及格了。
> ¿Ya has terminado los deberes? —No, todavía no.｜你作业做完了吗？——还没呢。
> Mi hermano trabaja mucho y tiene poco tiempo libre.｜我哥哥工作很忙，空闲时间很少。

### 常用动词

下面是 A1、A2 最常用、变位又容易出错的动词，其他动词分散在前面各话题里。这些动词的现在时要很熟，A2 还要会它们的过去时形式。
