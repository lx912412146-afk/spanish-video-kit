## DELE 常用术语对照

这一附录收集 DELE 官方网站、考试指南、样卷和成绩通知里常见的西语术语，按用途分成六组。DELE 是 Diplomas de Español como Lengua Extranjera 的缩写。名词前面带定冠词，可以看出阴阳性；指人的名词写出阳性和阴性两种形式。“说明”一栏里涉及考试规定的内容，依据本书第 1 章，各级的细节见第 2–7 章。

### 考试和证书

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| DELE | 西班牙语作为外语水平证书 | 塞万提斯学院颁发，分 A1–C2 六级 |
| el Instituto Cervantes | 塞万提斯学院 | 颁发 DELE 证书的机构 |
| el diploma | 证书、文凭 | DELE 的 D 就是 diplomas |
| el nivel | 级别 | DELE 分 A1–C2 六个级别 |
| la vigencia indefinida | 永久有效 | 官方对 DELE 证书有效期的说法 |
| el Marco común europeo de referencia | 欧洲语言共同参考框架 | 简称 MCER，英文简称 CEFR |
| el Volumen complementario | 补充卷 | 框架的补充卷，中介任务的依据 |
| para escolares | 青少年版 | 面向青少年考生的 DELE |

### 试卷结构和题型

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| la prueba | 部分；考试 | 每级 4 个部分（C2 是 3 个）；也泛指考试 |
| la tarea | 任务 | 每个部分由几个任务组成 |
| el ítem（复数 ítems） | 题 | 计分的单位，一道题就是一个 ítem |
| las instrucciones | 答题说明 | 每个任务开头的要求 |
| la opción | 选项；可选的题目 | 写作、口语常是两题选一 |
| la selección múltiple | 选择题 | 从几个选项中选出一个 |
| el distractor | 干扰项 | 看似合理但不对的选项 |
| el fragmento | 片段 | 选段填空任务里被抽出的段落 |
| el hueco | 空、空缺 | 完形填空、选段填空里要填的地方 |
| el monólogo | 独白 | 一个人连续说的话 |
| la entrevista | 访谈 | 听力常见材料；C1、C2 口语任务 2 |
| la exposición | 陈述 | 就一个话题连续讲一段 |
| la situación simulada | 模拟情景 | A2、B1 口语的情景对话 |
| la negociación | 协商 | C1、C2 口语任务 3 |

### 各部分的名称和技能

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| Comprensión de lectura | 阅读理解 | A1–B2 第 1 部分 |
| Comprensión auditiva | 听力理解 | A1–B2 第 2 部分 |
| Expresión e interacción escritas | 书面表达与互动 | A1–B2 第 3 部分（写作） |
| Expresión e interacción orales | 口头表达与互动 | A1–B2 第 4 部分（口语） |
| Uso de la lengua | 语言运用 | C1 第 1、2 部分和 C2 第 1 部分名称里有 |
| Expresión, mediación e interacción escritas | 书面表达、中介与互动 | C1、C2 写作部分，2024 年起 |
| Expresión, mediación e interacción orales | 口头表达、中介与互动 | C1、C2 口语部分，2024 年起 |
| Destrezas integradas | 整合技能（旧称） | 2024 年前 C1、C2 写作、口语部分的名称 |
| la comprensión | 理解 | 读懂、听懂 |
| la expresión | 表达 | 独自说一段或写一篇 |
| la interacción | 互动 | 和人交流：回信、对话、协商 |
| la mediación | 中介、语言中介 | 把读到、听到的内容转述、概括给别人 |

C1 的第 1、2 部分全称是 Comprensión de lectura y uso de la lengua、Comprensión auditiva y uso de la lengua；C2 的第 1 部分全称是 Uso de la lengua, comprensión de lectura y auditiva。

### 答题和材料

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| el cuadernillo | 题册 | 阅读、听力的题印在题册上 |
| la hoja de respuestas | 答题卡 | 选择题的答案填在这里 |
| la grabación | 录音 | 听力和部分写作任务要听 |
| la transcripción | 听力原文、文字稿 | 官方样卷附有 |
| la clave（las claves） | 答案 | 官方样卷附有阅读、听力答案 |
| tomar notas | 记笔记 | 口语准备、听录音时可以记 |
| el tiempo de preparación | 准备时间 | 口试前准备，各级 10–30 分钟 |
| el número de palabras | 字数 | 写作要求的单词数范围 |
| el registro | 语体 | 正式（formal）或非正式（informal） |

### 评分和成绩

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| la calificación | 成绩、评定结果 | 普通版只有 APTO 和 NO APTO 两种 |
| la puntuación | 分数、得分 | 各部分、各组的得分 |
| el grupo de calificación | 计分组 | A1–C1 分两组计分 |
| APTO | 通过 | A1–C1 两组各 ≥ 30；C2 三部分各 ≥ 20 |
| NO APTO | 不通过 | 有一组（C2 是一个部分）没过线 |
| la escala holística | 整体评分量表 | 对整体表现给一个总的等级 |
| la escala analítica | 分项评分量表 | 按几个评分项分别打分 |
| los descriptores | 描述语、能力描述 | 说明某一等级能做什么的句子 |
| el cumplimiento de la tarea | 任务完成度 | C1 自 2024 年起新增的评分项 |
| la ficha de ideas principales | 要点清单 | C1 评分员评两个任务 1 时参考 |
| la coherencia | 连贯 | 内容条理清楚、前后一致 |
| la corrección | 准确 | 语法、词汇、拼写的正确程度 |
| el alcance | 范围、丰富程度 | 能用的词汇和语法有多丰富 |
| la fluidez | 流利 | 说话是否顺畅、停顿多少 |
| la revisión de calificaciones | 成绩复核 | 成绩公布后 1 个月内可以申请 |
| el certificado de calificaciones | 成绩证明 | 可在官网个人专区查看 |

### 报名和考试组织

| 西班牙语 | 中文 | 说明 |
| --- | --- | --- |
| la convocatoria | 考期 | 每年 7 个，不是每期都考所有级别 |
| la inscripción | 报名 | 通过授权考点报名 |

| el candidato, la candidata | 考生 | 报名参加考试的人 |
| el examinador, la examinadora | 考官 | 泛指主持、评定考试的人 |

| el calificador, la calificadora | 评分员 | 按量表给写作或口语打分的人 |
| la guía del examen | 考试指南 | 官方对某一级考试的详细说明 |
| el cuadro de especificaciones | 考试规格表 | 列出各部分的任务、题数和时长 |
| el modelo de examen | 样卷 | 官网“Preparar la prueba”下可免费下载 |
