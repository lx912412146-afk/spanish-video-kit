# 西班牙语学习白皮书（《现代西班牙语》老版第一至四册）

把《现代西班牙语》（老版，董燕生、刘建编）第一至四册共 78 课的知识点**按专题**整理成一本书，供总复习和查阅。Word 和 PDF 在 Release [`whitepaper`](../../../releases/tag/whitepaper)。

## 内容

| 部分 | 章 |
| --- | --- |
| 第一部分 总览 | 第 1 章 四册的学习路线；第 2 章 四册语法进度总表（自动生成） |
| 第二部分 语音和正字法 | 第 3 章 语音与正字法 |
| 第三部分 词法 | 第 4 章 名词、冠词、形容词和数词；第 5 章 代词；第 6 章 副词、前置词、连词和构词法 |
| 第四部分 动词 | 第 7 章 动词的变位；第 8 章 动词的时态、语态和用法 |
| 第五部分 句法 | 第 9 章 句子、名词性从句和关系从句；第 10 章 状语从句、引语和语序 |
| 第六部分 分课索引和重点词汇 | 第 11–14 章 第一至四册各课的课文题目、语法和全部词汇（自动生成） |
| 附录 | A 常见错误和易混点；B 语法术语对照表 |

- 每个知识点后面的〔册·课〕是出处，如〔2·9〕是第二册第 9 课。
- 内容依据仓库里四册的分课课件（[`课件/`](../课件/)）和照课本目录整理的课程大纲；例句是课件里的原创例句或新写的句子，不是课本原文。
- 每章由一人编写、另一人独立审校；变位表用脚本逐格核对过。
- 拼写按老版课本（sólo、éste 等带重音），RAE 2010 年起不再要求，见第 3 章。

## 文件

| 文件 | 作用 |
| --- | --- |
| `chapters/*.md` | 各章正文（约定的简化 Markdown，标记见 `白皮书编写要求.md`） |
| `front_matter.md` | 编写说明 |
| `build_whitepaper.js` | 用 docx（npm）把各章、四册课件 JSON 排成 Word：封面、目录（带页码）、各部分、分课索引 |
| `lint.py` | 检查章节文件的标记 |
| `白皮书编写要求.md` | 编写规则和标记说明 |

## 重新生成

需要 Node.js 和 `npm install docx@9.5.1`。在仓库根目录：

```bash
python 白皮书/lint.py 白皮书/chapters/*.md
node 白皮书/build_whitepaper.js 白皮书/out/西班牙语学习白皮书.docx
```

PDF 是用 LibreOffice 转的（`soffice --headless --convert-to pdf`），目录页码由转换时计算；在 Word 里打开时如提示更新域，选“是”即可更新目录页码。字体用苹方（PingFang SC），Windows 上会换成默认中文字体。
