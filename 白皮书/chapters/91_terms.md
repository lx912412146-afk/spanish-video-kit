## 语法术语对照表

本表收四册课件里用到的语法术语，按词类、动词、句法三类排列，便于阅读西语原版的语法书和词典。中文术语和课件一致；西语术语取西班牙语语法界通行的说法，有两种常见叫法的，表里写较常见的一种，另一种在说明栏注出。说明栏里的“RAE”指西班牙皇家语言学院和各国西班牙语学院 2009 年出版的《西班牙语新语法》（Nueva gramática de la lengua española）的叫法，“贝略”指 19 世纪语法学家安德烈斯·贝略（Andrés Bello）的叫法，后者在拉美一些国家的学校语法里仍能见到。课本目录用的西语叫法和通行说法不同时，也在说明栏注出。意思紧密相关的两个术语合在一行，用“／”隔开。二重元音、分音等语音术语见第 3 章，这里不收。

### 词类

#### 名词、冠词、形容词和副词

| 中文术语 | 西班牙语术语 | 说明或例子 |
| --- | --- | --- |
| 名词 | sustantivo | 也叫 nombre：casa、libro |
| 阳性 | masculino | el libro、el día |
| 阴性 | femenino | la casa、la mano |
| 单数／复数 | singular / plural | libro / libros |
| 性数一致 | concordancia de género y número | unas casas nuevas |
| 定冠词 | artículo determinado | 也叫 artículo definido：el、la |
| 不定冠词 | artículo indeterminado | 也叫 artículo indefinido：un |

| 缩合 | contracción | a + el = al，de + el = del |
| 形容词 | adjetivo | alto、verde、feliz |
| 比较级 | comparativo | más… que；同等比较 tan… como |
| 相对最高级 | superlativo relativo | el más alto de la clase |
| 绝对最高级 | superlativo absoluto | altísimo、facilísimo |
| 副词 | adverbio | bien、aquí、mañana |
| 以 -mente 结尾的副词 | adverbio en -mente | rápidamente、fácilmente |

### 动词

#### 动词的类别

| 中文术语 | 西班牙语术语 | 说明或例子 |
| --- | --- | --- |
| 变位 | conjugación | 第一、二、三变位：-ar、-er、-ir |
| 规则动词／不规则动词 | verbo regular / irregular | hablar；ser、ir、tener |

#### 语式和时态

| 中文术语 | 西班牙语术语 | 说明或例子 |
| --- | --- | --- |
| 语式 | modo | 陈述式、虚拟式、命令式 |
| 陈述式 | modo indicativo | 叙述事实 |
| 虚拟式 | modo subjuntivo | 愿望、怀疑、假设等 |
| 命令式 | modo imperativo | 肯定命令式：habla、hablad |
| 否定命令式 | imperativo negativo | no hables；RAE 归入虚拟式 |
| 时态 | tiempo verbal | 表示动作的时间关系 |
| 复合时态 | tiempo compuesto | haber + 过去分词 |
| 现在时 | presente | 陈述式现在时：hablo |
| 简单过去时 | pretérito perfecto simple | hablé；传统名称 pretérito indefinido |
| 过去未完成时 | pretérito imperfecto | hablaba；贝略称 copretérito |
| 现在完成时 | pretérito perfecto compuesto | 也简称 pretérito perfecto |
| 过去完成时 | pretérito pluscuamperfecto | había hablado |
| 将来未完成时 | futuro simple | hablaré；传统名称 futuro imperfecto |
| 将来完成时 | futuro compuesto | habré hablado；传统名称 futuro perfecto |
| 简单条件式 | condicional simple | hablaría；也叫 potencial simple |
| 复合条件式 | condicional compuesto | 也叫 condicional perfecto |
| 虚拟式现在时 | presente de subjuntivo | hable、coma |
| 虚拟式过去未完成时 | pretérito imperfecto de subjuntivo | hablara / hablase |
| 虚拟式现在完成时 | pretérito perfecto de subjuntivo | haya hablado |
| 虚拟式过去完成时 | pretérito pluscuamperfecto de subjuntivo | hubiera / hubiese hablado |
| 表示推测的将来时 | futuro de probabilidad | 也叫 futuro de conjetura |

### 句法

#### 句子成分

| 中文术语 | 西班牙语术语 | 说明或例子 |
| --- | --- | --- |
| 主语 | sujeto | Ana canta. 里的 Ana |

| 间接宾语 | complemento indirecto | Escribo a Paco. |

| 支配补语 | complemento de régimen | pensar en、soñar con |
