## 动词的变位

西班牙语动词靠词尾变化来表示人称、数、时态和式，一个动词单是简单形式就有五十多个。这一章只讲“形式”：各个时态怎样构成，哪些动词不规则、不规则在哪里，拼写和重音怎样变。各时态、各式的用法见第 8 章，虚拟式在从句里的用法见第 9、10 章。每个时态第一次出现的课都标在出处里，后面的复习课、小结课只在需要时列出。

- 人称和数：每个时态有六个人称形式，即 yo、tú、él / ella / usted、nosotros、vosotros、ellos / ellas / ustedes。usted、ustedes 是尊称，动词用第三人称形式〔1·2〕。拉丁美洲一般不用 vosotros，“你们”都说 ustedes，vosotros 的形式在拉美很少听到，但要会认〔1·2〕。
- 三种变位：原形动词以 -ar、-er、-ir 结尾，分别叫第一、第二、第三变位〔1·7〕〔1·8〕〔1·9〕。去掉这两个字母，剩下的部分是词根（habl-、com-、viv-），变位就是在词根上加不同的词尾。
- 主语常省略：词尾已经表明人称，主语代词一般不说出来；要强调、对比或者意思不清时才说〔1·2〕〔1·7〕。
- 规则和不规则：大多数动词按三种模式规则变位。不规则动词多半只是词根不规则，词尾照样按规则加；而且不规则变化成批、成类地出现，按类记比逐个死记省力得多。

### 式和时态总览

西班牙语动词有三个式：陈述式把事情当作事实来陈述；虚拟式表示愿望、请求、情感、怀疑等主观色彩，多用在从句里；命令式表示命令和请求。此外还有三个非人称形式：原形动词、副动词和过去分词，它们不随人称变化。

每个式下面分若干时态。时态分简单和复合两类：简单时态只有一个词（hablo、hablé）；复合时态由助动词 haber 加过去分词构成（he hablado、había hablado）。haber 的每个简单时态加上过去分词，就构成一个对应的复合时态，所以复合时态只要会变 haber 就行〔3·7〕。

- 陈述式：连同简单条件式和复合条件式在内一共十个时态，四册讲了其中九个。只有先过去时（hube hablado）四册未讲。
- 条件式：简单条件式和复合条件式现在多数语法书归入陈述式，〔4·4〕讲绝对时和相对时，也是把简单条件式和陈述式其他时态放在一起比较的；旧说把它们单列为“条件式”。四册课件都只叫“简单条件式”“复合条件式”，前面不加“陈述式”。
- 虚拟式：一共六个时态，四册讲了现在时、过去未完成时、现在完成时、过去完成时四个。虚拟式将来时（hablare）和虚拟式将来完成时（hubiere hablado）四册未讲。
- 命令式：只有肯定命令式的 tú、vosotros 有自己的形式；usted、ustedes、nosotros 的肯定命令式和所有人称的否定命令式都借用虚拟式现在时〔1·16〕〔2·3〕。命令式没有 yo 的形式。
- 非人称形式：原形动词（第一册课件多叫“不定式”）和副动词都有简单、复合两种形式；过去分词只有一种，用作形容词时有性数变化〔2·1〕。

#### 四册的进度

四册引入变位形式的顺序大致是：先陈述式，再命令式，再虚拟式；先简单时态，再复合时态。复习时可以按这个顺序检查自己掌握了哪些形式：

- 第一册：陈述式现在时，规则动词分三课学〔1·7〕〔1·8〕〔1·9〕，不规则动词从 ser〔1·2〕起逐课加入，词根变化动词集中在〔1·13〕〔1·14〕；肯定命令式〔1·15〕〔1·16〕〔1·17〕；简单过去时〔1·19〕〔1·20〕；过去未完成时〔1·21〕。
- 第二册：过去分词〔2·1〕；虚拟式现在时的变位、否定命令式和副动词〔2·3〕；将来未完成时〔2·7〕；虚拟式现在时用在从句里〔2·9〕；现在完成时〔2·13〕；过去完成时〔2·15〕；简单条件式〔2·16〕；原形动词的用法〔2·17〕。
- 第三册：虚拟式过去未完成时〔3·2〕；虚拟式过去完成时和复合条件式〔3·9〕；将来完成时〔3·13〕；虚拟式现在完成时〔3·15〕；复合原形动词〔3·16〕。
- 第四册：不再引入新的变位形式，侧重时态、体和式的用法小结，如动词的体〔4·3〕、绝对时和相对时〔4·4〕、两种过去时的区别〔4·9〕、简单条件式的用法〔4·12〕。

#### 变位之间的推导关系

记变位不必一个个死记。大多数形式可以从少数几个“基本形式”推出来，不规则动词也基本遵守这些推导关系。所以学一个不规则动词，关键是记住它的原形、现在时 yo 的形式、简单过去时（特别是 ellos 的形式）、将来时词根和过去分词。

| 要推的形式 | 从哪儿推 | hablar | tener |
| --- | --- | --- | --- |
| 虚拟式现在时 | 现在时 yo 去 -o，换词尾 | hablo → hable | tengo → tenga |
| usted 等的命令式 | 用虚拟式现在时 | hable, hablemos | tenga, tengamos |
| 否定命令式 | no + 虚拟式现在时 | no hables | no tengas |
| tú 肯定命令式 | 现在时 él 的形式 | habla | ten（例外） |
| vosotros 肯定命令式 | 原形动词 -r 换成 -d | hablad | tened |
| 虚拟式过去未完成时 | 简单过去时 ellos 去 -ron | hablaron → hablara | tuvieron → tuviera |
| 将来时、简单条件式 | 原形动词或不规则词根 | hablaré, hablaría | tendré, tendría |
| 复合时态 | haber + 过去分词 | he hablado | he tenido |

! 例外很少：虚拟式现在时只有 ser、ir、estar、dar、saber、haber 六个动词不从 yo 的形式推（sea、vaya、esté、dé、sepa、haya）；tú 的肯定命令式只有八个不规则（di、haz、ve、pon、sal、sé、ten、ven）；虚拟式过去未完成时从简单过去时推，没有例外。

### 三种规则变位

规则动词只要记词尾。-er 和 -ir 动词的词尾大部分相同，只在几处不同：陈述式现在时的 nosotros、vosotros（comemos / vivimos，coméis / vivís），vosotros 的肯定命令式（comed / vivid），以及以原形动词为基础的将来时和条件式（comeré / viviré）。下面各表都用 hablar、comer、vivir 三个动词。

#### 人称词尾的共同规律

各个时态的词尾虽然不同，人称的标志却很一致，掌握了这些共同点，看到一个陌生的形式也能先判断人称：

- tú 的形式几乎都以 -s 结尾：hablas、hablabas、hablarás、hablarías、hables、hablaras；只有简单过去时（hablaste）和肯定命令式（habla）例外。
- nosotros 的形式在所有时态里都以 -mos 结尾：hablamos、hablábamos、hablaremos、hablemos、habláramos。
- vosotros 的形式都以 -is 结尾：habláis、hablasteis、hablabais、hablaréis、habléis、hablarais；只有肯定命令式例外（hablad）。
- 第三人称复数的形式都以 -n 结尾：hablan、hablaron、hablaban、hablarán、hablen、hablaran，连 son、van、fueron 这样的不规则形式也不例外。
- 第三人称单数没有专门的人称标志，可以看作这个时态的“基本形”。
- yo 的形式在陈述式现在时里以 -o 结尾，少数例外是 soy、estoy、voy、doy、sé、he；在过去未完成时、简单条件式和虚拟式各时态里，yo 和第三人称单数同形（hablaba、hablaría、hable、hablara），意思不清时要说出主语。

#### 陈述式现在时

去掉 -ar、-er、-ir，加上表里的词尾〔1·7〕〔1·8〕〔1·9〕。

| 人称 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablo | como | vivo |
| tú | hablas | comes | vives |
| él / ella / usted | habla | come | vive |
| nosotros, -as | hablamos | comemos | vivimos |
| vosotros, -as | habláis | coméis | vivís |
| ellos / ellas / ustedes | hablan | comen | viven |

- 词尾：-ar 动词是 -o、-as、-a、-amos、-áis、-an；-er 动词是 -o、-es、-e、-emos、-éis、-en；-ir 动词是 -o、-es、-e、-imos、-ís、-en。
- 重音：只有 vosotros 的词尾带重音符号（-áis、-éis、-ís），其余形式都重读倒数第二个音节，不写重音符号〔1·7〕〔1·9〕。
- -er 和 -ir 动词只差 nosotros、vosotros 两个人称：comemos / vivimos，coméis / vivís〔1·9〕。
- 词根以元音结尾的 leer、creer，vosotros 的形式写成 leéis、creéis，两个 e 分开读〔1·8〕。
- -ar、-ir 动词 nosotros 的现在时和简单过去时同形（hablamos、vivimos），-er 动词不同形（comemos / comimos）。

> Mi padre trabaja en una fábrica.｜我父亲在一家工厂工作。
> ¿Lees en español o en inglés?｜你用西班牙语读还是用英语读？
> ¿Dónde vivís? —Vivimos en el centro.｜你们住在哪儿？——我们住在市中心。

#### 陈述式简单过去时

| 人称 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablé | comí | viví |
| tú | hablaste | comiste | viviste |
| él / ella / usted | habló | comió | vivió |
| nosotros, -as | hablamos | comimos | vivimos |
| vosotros, -as | hablasteis | comisteis | vivisteis |
| ellos / ellas / ustedes | hablaron | comieron | vivieron |

- 词尾：-ar 动词是 -é、-aste、-ó、-amos、-asteis、-aron；-er 和 -ir 动词的词尾完全相同，都是 -í、-iste、-ió、-imos、-isteis、-ieron〔1·19〕。
- yo 和第三人称单数重读最后一个音节，必须写重音符号：hablé、habló，comí、comió，viví、vivió。少了重音符号就成了别的形式：hablo 是现在时 yo 的形式，hable 是虚拟式现在时〔1·19〕。
- tú 的词尾是 -aste、-iste，后面没有 -s，不要写成 hablastes；vosotros 的词尾 -asteis、-isteis 不带重音符号。
- -er 动词 nosotros 的形式和现在时不同（comimos / comemos），-ar、-ir 动词同形（hablamos、vivimos），要靠上下文和时间词区分〔1·19〕。

> Ayer hablé con el profesor.｜昨天我和老师谈过了。
> Mi hermana comió en casa de una amiga.｜我妹妹在一个朋友家吃的饭。
> Anoche escribí una carta a mis abuelos.｜昨晚我给祖父母写了一封信。

#### 陈述式过去未完成时

| 人称 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablaba | comía | vivía |
| tú | hablabas | comías | vivías |
| él / ella / usted | hablaba | comía | vivía |
| nosotros, -as | hablábamos | comíamos | vivíamos |
| vosotros, -as | hablabais | comíais | vivíais |
| ellos / ellas / ustedes | hablaban | comían | vivían |

- 词尾：-ar 动词是 -aba、-abas、-aba、-ábamos、-abais、-aban；-er 和 -ir 动词相同，都是 -ía、-ías、-ía、-íamos、-íais、-ían〔1·21〕。
- -aba 系列只有 nosotros 带重音符号（hablábamos）；-ía 系列每个人称的 í 都带重音符号（comía、vivíais），表示 í 和后面的 a 分开读〔1·21〕。
- yo 和第三人称单数同形（hablaba、comía），意思不清时要说出主语〔1·21〕。
- 这是最规则的时态：只有 ser、ir、ver 三个动词不规则（见后文）；词根变化动词在这里也完全规则，如 jugaba、solía、contaba〔1·22〕。

> Mi abuelo vivía en el campo.｜我爷爷那时住在乡下。
> Antes comíamos en casa todos los días.｜以前我们每天在家吃饭。

#### 陈述式将来未完成时

| 人称 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablaré | comeré | viviré |
| tú | hablarás | comerás | vivirás |
| él / ella / usted | hablará | comerá | vivirá |
| nosotros, -as | hablaremos | comeremos | viviremos |
| vosotros, -as | hablaréis | comeréis | viviréis |
| ellos / ellas / ustedes | hablarán | comerán | vivirán |

- 将来时不去掉词尾，而是在整个原形动词后面加词尾：-é、-ás、-á、-emos、-éis、-án，三种变位的词尾完全相同〔2·7〕。
- 除了 nosotros，每个人称都带重音符号：hablaré、hablarás、hablará、hablaréis、hablarán；hablaremos 不带〔2·7〕。
- 将来时的词尾和 haber 的现在时（he、has、ha、hemos、habéis、han）很像，因为历史上将来时就是由“原形动词 + haber”合成的，可以借此记忆：hablar + é，hablar + ás……
- 不规则的只是词根，词尾照样加（tendré、haré），见后文“将来时和条件式的不规则词根”。

> Mañana hablaré con el director.｜明天我要和经理谈一谈。
> ¿Cuándo volverás a casa?｜你什么时候回家？

#### 简单条件式

| 人称 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablaría | comería | viviría |
| tú | hablarías | comerías | vivirías |
| él / ella / usted | hablaría | comería | viviría |
| nosotros, -as | hablaríamos | comeríamos | viviríamos |
| vosotros, -as | hablaríais | comeríais | viviríais |
| ellos / ellas / ustedes | hablarían | comerían | vivirían |

- 和将来时一样以整个原形动词为基础，加 -ía、-ías、-ía、-íamos、-íais、-ían，三种变位相同〔2·16〕。
- 这套词尾和 -er、-ir 动词过去未完成时的词尾一样，区别在于前面是整个原形动词还是词根：comería（条件式）/ comía（过去未完成时），viviríamos / vivíamos。
- 每个人称的 í 都带重音符号：hablaría、hablaríamos、hablaríais。
- 不规则动词的条件式词根和将来时完全相同：tendré → tendría，haré → haría〔2·16〕。

> Yo que tú, hablaría con el profesor.｜我要是你，就去跟老师谈谈。
> ¿Podría usted ayudarme?｜您能帮帮我吗？

#### 虚拟式现在时

| 人称 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hable | coma | viva |
| tú | hables | comas | vivas |
| él / ella / usted | hable | coma | viva |
| nosotros, -as | hablemos | comamos | vivamos |
| vosotros, -as | habléis | comáis | viváis |
| ellos / ellas / ustedes | hablen | coman | vivan |

- 构成：陈述式现在时 yo 的形式去掉 -o，-ar 动词加 -e、-es、-e、-emos、-éis、-en，-er 和 -ir 动词加 -a、-as、-a、-amos、-áis、-an〔2·3〕〔2·9〕。简单的记法是“元音对调”：-ar 动词换成 e，-er、-ir 动词换成 a。
- 因为从 yo 的形式出发，现在时 yo 不规则的动词，虚拟式整套都跟着不规则：tengo → tenga，conozco → conozca（见后文）〔2·9〕。
- yo 和第三人称单数同形（hable、coma）；只有 vosotros 带重音符号：habléis、comáis、viváis〔2·3〕。
- 不要和陈述式混淆：-ar 动词的虚拟式用 e，-er 动词的陈述式也用 e，所以 comes 是陈述式，hables 是虚拟式；反过来，comas 是虚拟式，hablas 是陈述式。
- -car、-gar、-zar 等动词要改写辅音以保持读音：toque、pague、empiece〔1·16〕〔2·3〕，见后文“拼写变化”。

> No hables tan alto, por favor.｜请别这么大声说话。
> Quiero que me escribas.｜我希望你给我写信。

#### 虚拟式过去未完成时

| -ra 式 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablara | comiera | viviera |
| tú | hablaras | comieras | vivieras |
| él / ella / usted | hablara | comiera | viviera |
| nosotros, -as | habláramos | comiéramos | viviéramos |
| vosotros, -as | hablarais | comierais | vivierais |
| ellos / ellas / ustedes | hablaran | comieran | vivieran |

| -se 式 | hablar | comer | vivir |
| --- | --- | --- | --- |
| yo | hablase | comiese | viviese |
| tú | hablases | comieses | vivieses |
| él / ella / usted | hablase | comiese | viviese |
| nosotros, -as | hablásemos | comiésemos | viviésemos |
| vosotros, -as | hablaseis | comieseis | vivieseis |
| ellos / ellas / ustedes | hablasen | comiesen | viviesen |

- 构成：简单过去时第三人称复数去掉 -ron，加 -ra 式词尾（-ra、-ras、-ra、-ramos、-rais、-ran）或 -se 式词尾（-se、-ses、-se、-semos、-seis、-sen）〔3·2〕。
- 因为以简单过去时为基础，-er、-ir 动词都有 -ie-（comiera、viviera），-ar 动词是 -a-（hablara）。
- 只有 nosotros 带重音符号，标在 -ramos、-semos 前面的元音上：habláramos、hablásemos，comiéramos、comiésemos，viviéramos、viviésemos〔3·2〕。
- 两套形式意思相同，一般可以互换，口语里 -ra 式更常用〔3·2〕。表示客气的 quisiera，以及在条件句主句里代替复合条件式的 hubiera + 过去分词〔3·9〕，一般只用 -ra 式。

! hablara（虚拟式过去未完成时）和 hablará（将来时），hablaras 和 hablarás，hablaran 和 hablarán，写法只差一个重音符号，读音的重读位置也不同（ha-bla-ra / ha-bla-rá），写和读都要分清。

> Quería que habláramos con el rey.｜他想让我们去和国王谈谈。
> Le pedí que comiera algo.｜我请他吃点东西。
> Mis padres querían que viviese con ellos.｜父母想让我和他们一起住。

#### 命令式

命令式没有 yo 的形式。肯定命令式里只有 tú、vosotros 有自己的形式，usted、ustedes、nosotros 借用虚拟式现在时；否定命令式所有人称都是 no + 虚拟式现在时〔1·15〕〔1·16〕〔2·3〕。

| 肯定命令式 | hablar | comer | vivir |
| --- | --- | --- | --- |
| tú | habla | come | vive |
| usted | hable | coma | viva |
| nosotros, -as | hablemos | comamos | vivamos |
| vosotros, -as | hablad | comed | vivid |
| ustedes | hablen | coman | vivan |

| 否定命令式 | hablar | comer | vivir |
| --- | --- | --- | --- |
| tú | no hables | no comas | no vivas |
| usted | no hable | no coma | no viva |
| nosotros, -as | no hablemos | no comamos | no vivamos |
| vosotros, -as | no habléis | no comáis | no viváis |
| ustedes | no hablen | no coman | no vivan |

- tú：和陈述式现在时第三人称单数同形：habla、come、vive；词根变化照样变：empieza、duerme、vuelve〔1·15〕。
- vosotros：把原形动词词尾的 -r 换成 -d：hablad、comed、vivid〔1·15〕。
- usted、ustedes、nosotros：就是虚拟式现在时的相应形式：hable、hablen、hablemos〔1·16〕。nosotros 的命令式意思是“我们……吧”。
- 否定命令式：no + 虚拟式现在时，tú 和 vosotros 也不例外：no hables、no habléis，不能说 no habla、no hablad〔2·3〕。
- 拉丁美洲不用 vosotros，对几个人说话一律用 ustedes 的形式。
- 肯定命令式和别的形式同形时要看上下文：come 可以是“他吃”，也可以是“你吃吧”；hable 可以是“您说吧”，也可以是虚拟式现在时〔1·15〕〔1·16〕。

#### 带代词的命令式

- 肯定命令式：宾格、与格和自复代词都连写在动词后面，与格在前、宾格在后。连写以后原来的重读音节不变，常常要补写重音符号：compra → cómpralo，di → dímelo，compre → cómprelo〔1·15〕〔1·16〕。
- vosotros 的形式后接 os 时去掉 -d：sentad + os → sentaos，lavaos；-ir 动词去掉 -d 后 i 要加重音符号：vestíos；irse 是例外，说 idos〔1·15〕。
- nosotros 的形式后接 nos 或 se 时去掉词尾 -s：sentemos + nos → sentémonos，digamos + se + lo → digámoselo；接 lo、la 等不去 -s：comprémoslo〔1·16〕〔1·18〕。
- ustedes 的形式直接加 se，后面不再加 n：siéntense，不写 siéntensen〔1·16〕〔1·17〕。
- 否定命令式：代词放在动词前面：no lo abras、no te sientes、no os sentéis〔2·3〕。

| levantarse | 肯定命令式 | 否定命令式 |
| --- | --- | --- |
| tú | levántate | no te levantes |
| usted | levántese | no se levante |
| nosotros, -as | levantémonos | no nos levantemos |
| vosotros, -as | levantaos | no os levantéis |
| ustedes | levántense | no se levanten |

> Siéntate aquí, Ana.｜安娜，坐这儿。
> Niños, lavaos las manos.｜孩子们，洗洗手。
> Estamos cansados. Sentémonos aquí.｜我们累了。我们在这儿坐下吧。
> No te preocupes por nosotros.｜别为我们担心。

#### 非人称形式

| 形式 | hablar | comer | vivir |
| --- | --- | --- | --- |
| 原形动词 | hablar | comer | vivir |
| 复合原形动词 | haber hablado | haber comido | haber vivido |
| 副动词 | hablando | comiendo | viviendo |
| 过去分词 | hablado | comido | vivido |

- 原形动词就是词典里列出的形式。复合原形动词是 haber + 过去分词，表示先完成的动作〔3·16〕。
- 副动词：-ar 动词的词根加 -ando，-er、-ir 动词加 -iendo〔2·3〕。副动词没有性数变化。复合副动词 habiendo + 过去分词（habiendo terminado）四册课件没有专门讲，认识即可。
- 过去分词：-ar 动词的词根加 -ado，-er、-ir 动词加 -ido〔2·1〕。在复合时态里分词永远不变，以 -o 结尾；用作形容词（包括 estar + 分词、ser + 分词的被动语态）时要和名词性数一致：la puerta abierta、las cartas escritas〔2·1〕〔2·16〕〔3·7〕。
- 动词短语（ir a + 原形动词、tener que + 原形动词、estar + 副动词等）只变第一个动词，后面的原形动词、副动词不变：Voy a estudiar，Tenemos que salir，Estábamos cenando〔1·7〕〔1·8〕〔2·3〕〔4·3〕。
- 代词连写在原形动词和副动词后面。副动词加一个代词就要补重音符号：vistiéndome、haciéndolo；原形动词加一个代词不用补（verlo），加两个要补：dártelo、explicárselo〔1·10〕〔1·11〕〔2·3〕。复合原形动词的代词连写在 haber 后面：haberlo visto〔3·16〕。

> Me estoy vistiendo. / Estoy vistiéndome.｜我正在穿衣服。
> La puerta está abierta, pero las ventanas están cerradas.｜门开着，可窗户都关着。
> Gracias por haber venido a la exposición.｜谢谢你来看展览。

#### 自复动词的变位

自复动词（levantarse、lavarse、vestirse 等）本身的变位和一般动词一样，只是多了一个随人称变化的代词：me、te、se、nos、os、se，和主语同人称、同数〔1·13〕。代词的位置是：

- 在变位动词前面：me lavo、se vistió；否定时 no 在代词前面：no me lavo〔1·13〕。
- 复合时态里放在 haber 前面：me he lavado、se había ido〔2·13〕〔2·15〕。
- 和原形动词、副动词连用时，可以放在前面的变位动词前，也可以连写在原形动词、副动词后面：Me voy a acostar / Voy a acostarme，Me estoy vistiendo / Estoy vistiéndome〔1·13〕〔2·3〕。
- 肯定命令式连写在后面，否定命令式放在前面：lávate / no te laves〔1·15〕〔2·3〕。

| 形式 | lavarse | vestirse（i） |
| --- | --- | --- |
| 现在时 yo | me lavo | me visto |
| 简单过去时 él | se lavó | se vistió |
| 现在完成时 yo | me he lavado | me he vestido |
| ir a + 原形动词 | voy a lavarme | voy a vestirme |
| estar + 副动词 | estoy lavándome | estoy vistiéndome |
| tú 命令式 | lávate | vístete |
| vosotros 命令式 | lavaos | vestíos |
| nosotros 命令式 | lavémonos | vistámonos |
| 否定命令式 tú | no te laves | no te vistas |

> Me levanto a las seis y media.｜我六点半起床。
> Nos hemos levantado muy temprano.｜我们起得很早。
> Voy a acostarme. / Me voy a acostar.｜我要去睡了。

### 复合时态

复合时态都由“haber 的某个简单形式 + 过去分词”构成：haber 负责表示人称、数、时态和式，过去分词只表示动作已经完成，形式不变〔2·13〕〔3·7〕。四册讲到的复合时态和它们用的 haber 的形式如下：

| 复合时态 | haber 用的形式 | 例（hablar） | 出处 |
| --- | --- | --- | --- |
| 现在完成时 | 现在时 he… | he hablado | 〔2·13〕 |
| 过去完成时 | 过去未完成时 había… | había hablado | 〔2·15〕 |
| 将来完成时 | 将来未完成时 habré… | habré hablado | 〔3·13〕 |
| 复合条件式 | 简单条件式 habría… | habría hablado | 〔3·9〕 |
| 虚拟式现在完成时 | 虚拟式现在时 haya… | haya hablado | 〔3·15〕 |
| 虚拟式过去完成时 | 虚拟式过去未完成时 hubiera… | hubiera / hubiese hablado | 〔3·9〕 |
| 复合原形动词 | 原形动词 haber | haber hablado | 〔3·16〕 |
| 复合副动词 | 副动词 habiendo | habiendo hablado | 四册未专门讲 |
| 先过去时 | 简单过去时 hube… | hube hablado | 四册未讲 |

haber 作助动词时的各个简单时态：

| haber | 现在时 | 过去未完成时 | 将来未完成时 | 简单条件式 |
| --- | --- | --- | --- | --- |
| yo | he | había | habré | habría |
| tú | has | habías | habrás | habrías |
| él / ella / usted | ha | había | habrá | habría |
| nosotros, -as | hemos | habíamos | habremos | habríamos |
| vosotros, -as | habéis | habíais | habréis | habríais |
| ellos / ellas / ustedes | han | habían | habrán | habrían |

| haber | 虚拟式现在时 | 虚拟式过去未完成时（-ra） | 虚拟式过去未完成时（-se） |
| --- | --- | --- | --- |
| yo | haya | hubiera | hubiese |
| tú | hayas | hubieras | hubieses |
| él / ella / usted | haya | hubiera | hubiese |
| nosotros, -as | hayamos | hubiéramos | hubiésemos |
| vosotros, -as | hayáis | hubierais | hubieseis |
| ellos / ellas / ustedes | hayan | hubieran | hubiesen |

- haber 的现在时不规则（he、has、ha、hemos、habéis、han）〔2·13〕；过去未完成时是规则的 había……〔2·15〕；将来时、条件式的词根是 habr-〔2·7〕〔2·16〕；虚拟式现在时是 haya……，不能从 yo 的形式 he 推出〔2·9〕〔3·15〕；虚拟式过去未完成时从 hubieron 推出 hubiera、hubiese〔3·9〕。
- 作助动词时现在时第三人称单数是 ha（ha llegado）；作无人称动词表示“有”时是 hay（hay un libro）〔1·3〕〔2·13〕。
- 过去分词在复合时态里永远不变：Ella ha llegado，Las chicas habían salido，不随主语变成 llegada、salidas〔2·13〕〔3·7〕。
- 不规则过去分词在所有复合时态里照用：he hecho、había dicho、habré vuelto、haya visto〔2·13〕〔3·13〕。
- 复合时态和“estar / ser + 过去分词”要分清：He escrito las cartas 里的分词不变；Las cartas están escritas、Las cartas fueron escritas por Ana 里的分词和主语性数一致〔2·1〕〔2·16〕〔3·7〕。
- no 和宾格、与格、自复代词都放在 haber 前面，haber 和分词之间一般不插入别的词：No lo he visto，Me había ido，Si me lo hubieras dicho……〔2·13〕〔2·15〕〔3·9〕。复合原形动词例外，代词连写在 haber 后面：Siento no haberte llamado〔3·16〕。
- 无人称的 haber（“有”）在各时态里都只用第三人称单数：hay、había、hubo、habrá、habría、ha habido、haya、hubiera。Había muchos coches，一般不说 habían〔1·21〕〔2·7〕。

> ¿Has visto a Pedro hoy? —No, no lo he visto.｜你今天见到佩德罗了吗？——没有，没见到。
> Cuando llegamos a la estación, el tren ya había salido.｜我们到车站时，火车已经开走了。
> Para las ocho ya habré terminado los deberes.｜八点以前我就会把作业做完。
> Si lo hubiera sabido, no habría venido.｜早知道这样，我就不来了。

### 不规则动词的归类

不规则动词虽然多，但大多只在某几个形式上不规则，而且成类出现。下面按“哪里不规则”分类：先讲现在时（词根元音变化、第一人称特殊），再讲简单过去时、过去未完成时、将来时和条件式、分词和副动词，最后讲由这些形式推出来的虚拟式和命令式。要记住一条：一个基本形式不规则，从它推出来的形式也跟着不规则。

#### 词根元音变化：现在时

- 规律：词根里最后一个元音 e 或 o 重读时，e 变 ie，o 变 ue；有一批 -ir 动词是 e 变 i〔1·8〕〔1·9〕〔1·13〕。u 变 ue 的只有 jugar 一个〔1·22〕〔3·13〕。
- 只有重读的词根元音才变。陈述式现在时 nosotros、vosotros 的重音落在词尾上（pensamos、pensáis），这两个人称不变；其余四个人称都变〔1·13〕。
- 词根里有几个元音时，变的是最后一个：despertar → despierto，preferir → prefiero，recordar → recuerdo〔1·13〕〔1·14〕。
- 哪些动词有词根变化，从原形上看不出来：pensar 变而 pesar 不变，contar 变而 comprar 不变，只能逐个记。

| 人称 | pensar（e→ie） | volver（o→ue） | pedir（e→i） | jugar（u→ue） |
| --- | --- | --- | --- | --- |
| yo | pienso | vuelvo | pido | juego |
| tú | piensas | vuelves | pides | juegas |
| él / ella / usted | piensa | vuelve | pide | juega |
| nosotros, -as | pensamos | volvemos | pedimos | jugamos |
| vosotros, -as | pensáis | volvéis | pedís | jugáis |
| ellos / ellas / ustedes | piensan | vuelven | piden | juegan |

- 课件里出现过的这类动词主要有：
  - e → ie：querer〔1·9〕，empezar、despertar、pensar〔1·13〕，comenzar、preferir〔1·14〕，sentir〔1·24〕，extender〔3·1〕，negar〔3·4〕，recomendar〔3·8〕，encender〔3·18〕，encerrar〔4·12〕，defender、manifestar〔4·17〕。
  - o → ue：poder〔1·8〕，volver〔1·10〕，acostarse、almorzar、dormir〔1·13〕，recordar〔1·14〕，costar、probarse、llover〔1·16〕，contar、soler〔1·22〕，doler〔2·1〕，mover〔3·9〕，resolver〔4·13〕，comprobar、demostrar〔4·15〕。
  - e → i（都是 -ir 动词）：vestirse〔1·13〕，medir〔1·18〕，pedir、repetir、servir〔1·20〕，elegir〔2·10〕，seguir、conseguir〔2·17〕，rendirse〔3·4〕，corregir〔4·9〕。
  - u → ue：jugar（juego、juegas……jugamos）〔1·22〕〔3·13〕。
- 词典和课件常在动词后面用括号标出变化类型：pensar (ie)、dormir (ue, u)、pedir (i, i)。-ir 动词括号里的第二项，表示简单过去时、副动词等处的第二种变化（见下一节）〔1·13〕。
- 有些动词同时还有别的不规则：tener、venir 是 e → ie 加上 yo 的形式 -go（tengo、tienes）；decir 是 e → i 加上 -go（digo、dices）〔1·9〕〔1·12〕。adquirir 是少见的 i → ie（adquiero）〔3·11〕。

> Las clases empiezan a las ocho.｜八点开始上课。
> Mi hermano duerme ocho horas.｜我弟弟睡八个小时。
> Los sábados juego al fútbol con mis amigos.｜我每个星期六和朋友们踢足球。

#### 词根元音变化：其他时态和形式

- -ar、-er 词根变化动词只在重读的地方变：陈述式现在时、虚拟式现在时、tú 命令式和 usted、ustedes 命令式按上面的规律变，nosotros、vosotros 不变（pensemos、volváis）〔1·17〕〔2·9〕。其他时态全部规则：pensé、volví、pensaba、volveré、pensando〔1·20〕。
- -ir 词根变化动词还有第二种变化：在词根元音不重读的某些形式里，e 变 i，o 变 u。出现在五处：简单过去时第三人称单复数（sintió、sintieron，durmió、durmieron，pidió、pidieron）〔1·20〕；虚拟式现在时 nosotros、vosotros（sintamos、durmáis）〔2·3〕；由此而来的 nosotros 命令式（durmamos、vistámonos）〔1·17〕；整套虚拟式过去未完成时（sintiera、durmiera、pidiera）〔3·2〕；副动词（sintiendo、durmiendo、pidiendo）〔2·3〕。
- e → i 型（pedir）在重读和不重读的位置都是 i，所以虚拟式现在时六个人称都是 i：pida、pidas……pidamos、pidáis〔2·3〕。

| 形式 | pensar（ie） | sentir（ie, i） | dormir（ue, u） | pedir（i, i） |
| --- | --- | --- | --- | --- |
| 现在时 yo / nosotros | pienso, pensamos | siento, sentimos | duermo, dormimos | pido, pedimos |
| 虚拟式现在时 yo / nosotros | piense, pensemos | sienta, sintamos | duerma, durmamos | pida, pidamos |
| 简单过去时 él / ellos | pensó, pensaron | sintió, sintieron | durmió, durmieron | pidió, pidieron |
| 虚拟式过去未完成时 yo | pensara | sintiera | durmiera | pidiera |
| 副动词 | pensando | sintiendo | durmiendo | pidiendo |

#### 不规则命令式

- tú 的肯定命令式有八个不规则形式，都是单音节，要单独记：decir → di，hacer → haz，ir → ve，poner → pon，salir → sal，ser → sé，tener → ten，venir → ven〔1·15〕。
- 派生动词照样变，变成多音节以后按重音规则加重音符号：mantener → mantén〔2·18〕，detener → detén，proponer → propón，componer → compón。
- vosotros 的肯定命令式全部规则：decid、haced、id、poned、salid、sed、tened、venid〔1·15〕。
- usted、ustedes、nosotros 的肯定命令式和所有否定命令式都用虚拟式现在时，所以按 yo 的形式变：diga、haga、ponga、salga、tenga、venga、traiga、conozca〔1·17〕；ser、ir、estar、dar、saber 用 sea、vaya、esté、dé、sepa〔2·3〕。
- ir 的 nosotros 肯定命令式一般用 vamos（我们走吧），irse 是 vámonos；否定用 no vayamos、no nos vayamos。

| 原形动词 | tú | vosotros | usted | 否定（tú） |
| --- | --- | --- | --- | --- |
| decir | di | decid | diga | no digas |
| hacer | haz | haced | haga | no hagas |
| ir | ve | id | vaya | no vayas |
| poner | pon | poned | ponga | no pongas |
| salir | sal | salid | salga | no salgas |
| ser | sé | sed | sea | no seas |
| tener | ten | tened | tenga | no tengas |
| venir | ven | venid | venga | no vengas |

! 同形词要分清：ve 是 ir 的命令式（去），也是 ver 的命令式和现在时第三人称单数；ven 是 venir 的命令式（来），也是 ver 的现在时第三人称复数；sé 是 ser 的命令式，也是 saber 的现在时 yo 的形式；di 是 decir 的命令式，也是 dar 的简单过去时 yo 的形式〔1·15〕〔1·20〕。

> Ven aquí, Ana.｜安娜，过来。
> Haz los ejercicios, Pepe.｜佩佩，做练习。
> Dígame su nombre, por favor.｜请告诉我您的名字。
> No le digas nada a Ana.｜什么也别告诉安娜。

#### 只用部分人称或部分时态的动词

- 表示自然现象的 llover、nevar、amanecer 等没有主语，只用第三人称单数：llueve、nieva、amanece，ha llovido，va a llover〔2·11〕〔3·6〕。表示天气的 hacer（hace frío）和表示存在的 haber（hay）也只用第三人称单数〔1·3〕〔1·17〕〔2·11〕。
- gustar、doler、parecer、interesar、faltar 这类动词，主语多是事物，常用的只是第三人称单数和复数：me gusta / me gustan，me duele / me duelen〔1·16〕〔2·1〕〔2·8〕〔3·13〕。它们本身的变位并不特殊（doler 是 o → ue），其他人称也存在（A Ana le gusto yo），只是用得少。
- soler 主要只用现在时和过去未完成时：suelo、solía〔1·22〕〔3·12〕。
- poder、haber 一般不用命令式，querer、saber 的命令式也很少用。

> En invierno nieva mucho en el norte de China.｜中国北方冬天常下雪。
> Me duelen mucho los ojos.｜我眼睛疼得厉害。
> De niña, solía jugar con mis primas en la calle.｜我小时候常和表姐妹们在街上玩。

### 拼写变化和重音变化

有些动词的变位并不是真正的不规则：读音完全按规则，只是为了符合正字法，书写要改动；或者重读落在 i、u 上，要加重音符号。这类变化很有规律，看词尾就能判断。

#### 为保持读音改写辅音

字母的读音受后面元音的影响：c 在 a、o、u 前读 [k]，在 e、i 前读 [θ]（拉美读 [s]）；g 在 a、o、u 前读 [g]，在 e、i 前读 [x]。变位时词尾的元音一换，为了保持原来的读音，前面的辅音就要改写。

| 词尾 | 改写 | 出现在 | 例 |
| --- | --- | --- | --- |
| -car | c → qu（e 前） | 简单过去时 yo；虚拟式现在时 | busqué；busque |
| -gar | g → gu（e 前） | 简单过去时 yo；虚拟式现在时 | llegué；llegue |
| -zar | z → c（e 前） | 简单过去时 yo；虚拟式现在时 | empecé；empiece |
| -guar | gu → gü（e 前） | 简单过去时 yo；虚拟式现在时 | averigüé；averigüe |
| -ger、-gir | g → j（a、o 前） | 现在时 yo；虚拟式现在时 | cojo；coja |
| -guir | gu → g（a、o 前） | 现在时 yo；虚拟式现在时 | sigo；siga |
| 辅音 + -cer | c → z（a、o 前） | 现在时 yo；虚拟式现在时 | convenzo；convenza |
| 元音 + -er、-ir | i → y（两元音之间） | 简单过去时第三人称、副动词等 | leyó；leyendo |

- -car、-gar、-zar、-guar：只在 e 前改写。简单过去时只有 yo 的词尾以 e 开头，所以只有 yo 变（busqué，但 buscaste、buscó）；虚拟式现在时六个人称都变（busque、busques……），借用虚拟式的 usted、ustedes、nosotros 命令式和否定命令式也跟着变（pague、no toques、empecemos）〔1·16〕〔1·19〕〔2·3〕。
- 课件里这类动词很多：-car 有 buscar、sacar、tocar、explicar、complicar、destacar、marcar〔1·18〕〔1·19〕〔1·24〕〔2·3〕〔3·15〕〔4·8〕〔4·13〕；-gar 有 llegar、pagar、fregar、colgar、entregar、encargar、pegar、obligar、agregar、otorgar〔1·19〕〔2·4〕〔2·18〕〔3·6〕〔3·11〕〔3·15〕〔4·10〕；-zar 有 empezar、almorzar、comenzar、alcanzar、avanzar、enlazar、esforzarse〔1·19〕〔3·9〕〔4·2〕〔4·11〕〔4·15〕；-guar 有 averiguar〔3·2〕。
- -ger、-gir、-guir 和辅音 + -cer：只在 a、o 前改写。现在时只有 yo 的词尾是 -o，所以只有 yo 变（cojo，但 coges）；虚拟式现在时六个人称都变（coja、cojas……）。g → j 的有 coger、recoger、proteger、elegir、corregir、exigir、dirigir、surgir〔2·10〕〔2·12〕〔2·16〕〔3·11〕〔3·14〕〔4·2〕〔4·9〕〔4·12〕；gu → g 的有 seguir、conseguir、distinguir〔1·18〕〔2·17〕〔4·8〕；c → z 的有 convencer〔3·10〕。这几类的简单过去时不受影响：cogí、seguí。注意 conocer → conozco 多出一个 [k] 音，属于不规则变化；convencer → convenzo 读音不变，只是拼写变化。
- 词尾是 -jar、-jer、-jir 的动词不必改写，因为 j 在任何元音前都读 [x]：trabajar → trabajé、trabaje。
- 有的动词同时有两种变化：empezar 是 e → ie 加 z → c（empiece、empecemos），jugar 是 u → ue 加 g → gu（juegue、juguemos），seguir、elegir、corregir 是 e → i 加改写（sigo、elijo、corrijo），fregar 是 e → ie 加 g → gu（friego、fregué）〔1·17〕〔1·19〕〔3·13〕〔4·9〕。

| --- | --- | --- | --- | --- |
| yo | busqué | llegué | empecé | averigüé |
| tú | buscaste | llegaste | empezaste | averiguaste |
| él / ella / usted | buscó | llegó | empezó | averiguó |
| nosotros, -as | buscamos | llegamos | empezamos | averiguamos |
| vosotros, -as | buscasteis | llegasteis | empezasteis | averiguasteis |
| ellos / ellas / ustedes | buscaron | llegaron | empezaron | averiguaron |

| 虚拟式现在时 | buscar | llegar | empezar | averiguar |
| --- | --- | --- | --- | --- |
| yo | busque | llegue | empiece | averigüe |
| tú | busques | llegues | empieces | averigües |
| él / ella / usted | busque | llegue | empiece | averigüe |
| nosotros, -as | busquemos | lleguemos | empecemos | averigüemos |
| vosotros, -as | busquéis | lleguéis | empecéis | averigüéis |
| ellos / ellas / ustedes | busquen | lleguen | empiecen | averigüen |

| --- | --- | --- | --- | --- |

| tú | coges | cojas | sigues | sigas |

- 元音 + -er、-ir 动词把两个元音之间不重读的 i 写成 y，也是拼写规则：leyó、leyeron、leyendo、leyera，creyó、cayó、oyó、construyó〔1·20〕〔3·2〕〔3·7〕。

#### 重读的 i、u 加重音符号

- 以 -iar、-uar 结尾的动词分两类。一类变位时 i、u 本身重读，要写重音符号，和旁边的元音分开读：enviar → envío〔2·13〕，variar、guiar、confiar、desviar 同〔3·7〕〔3·10〕〔4·1〕〔4·14〕；efectuar → efectúo〔1·14〕，continuar → continúo，actuar → actúo〔3·11〕。另一类 i、u 不重读，和后面的元音构成二重元音，不加重音符号：estudiar → estudio，cambiar → cambio，averiguar → averiguo。属于哪一类没有简单的规则，拿不准时查词典。
- reunir → reúno，prohibir → prohíbo 也是同样的道理：重读的 u、i 加重音符号，表示不和前面的元音构成二重元音〔2·2〕〔2·10〕〔4·7〕。
- 这种重音只出现在重读落在词根上的形式里：陈述式现在时和虚拟式现在时的 yo、tú、él、ellos，以及 tú、usted、ustedes 的命令式（envía、envíe、envíen）。nosotros、vosotros 重读词尾，不加：enviamos、enviéis〔2·13〕。

| 人称 | enviar | efectuar | reunir | prohibir |
| --- | --- | --- | --- | --- |
| yo | envío | efectúo | reúno | prohíbo |
| tú | envías | efectúas | reúnes | prohíbes |
| él / ella / usted | envía | efectúa | reúne | prohíbe |
| nosotros, -as | enviamos | efectuamos | reunimos | prohibimos |
| vosotros, -as | enviáis | efectuáis | reunís | prohibís |
| ellos / ellas / ustedes | envían | efectúan | reúnen | prohíben |

- 虚拟式现在时同样：envíe、efectúe、reúna、prohíba；tú 命令式：envía、efectúa、reúne、prohíbe。

> Te envío unas fotos.｜我给你寄几张照片。
> ¿Dónde se efectúan los exámenes?｜考试在哪儿进行？
> Aquí se prohíbe fumar.｜这里禁止吸烟。

#### 变位里的重音符号：小结

变位形式要不要写重音符号，完全按西班牙语的一般重音规则来判断：以元音或 n、s 结尾的词，正常重读倒数第二个音节；以其他辅音结尾的词，正常重读最后一个音节；重读位置不合这两条的要写重音符号，重读倒数第三个音节的一律写。用这条规则可以把前面分散讲过的重音问题串起来：

- 重读最后一个音节、又以元音或 -n、-s 结尾的，要写：hablé、habló、comí、hablaré、hablarás、hablarán、estás、están。
- 重读倒数第三个音节的，要写：hablábamos、habláramos、hablásemos、éramos、íbamos；连写代词以后变成倒数第三个音节重读的也要写：cómpralo、dígame、siéntense。
- 重读的 i、u 和旁边的 a、e、o 分开读的，要在 i、u 上写：comía、vivíamos、hablaría、leído、oímos、envío、reúno。
- 重读的二重元音以 -is 结尾的，写在强元音上：habláis、coméis、estéis。
- 单音节词不写：fui、fue、dio、vio、di、vi、va、ve、vais、dais、veis；只有为了区分同形词才写，如 sé（saber、ser）和 se，dé（dar）和 de〔1·10〕〔1·15〕〔2·3〕。
- 连写代词后按整个新词判断：dime、verlo、comedlo、sentaos 重读倒数第二个音节，不写；dímelo、dártelo、vestíos 要写〔1·11〕〔1·15〕。

### 容易混淆的形式

不少变位形式写法相近或完全同形，读和写都要靠重音符号和上下文分辨。下表把前面分散提到的几组集中起来：

| 形式 | 区别 |
| --- | --- |
| hablo / habló | 现在时 yo / 简单过去时 él |
| hable / hablé | 虚拟式现在时 / 简单过去时 yo |
| hablara / hablará | 虚拟式过去未完成时 / 将来时 él |
| comía / comería | 过去未完成时 / 简单条件式 |
| hablamos, vivimos | 现在时和简单过去时同形 |
| fui, fue, fueron… | ser 和 ir 的简单过去时同形 |
| fuera, fuese… | ser 和 ir 的虚拟式过去未完成时同形 |
| ve | ir 的命令式；ver 的命令式和现在时 él |
| ven | venir 的命令式；ver 的现在时 ellos |
| sé / se | saber 现在时 yo、ser 命令式 / 代词 |
| di | decir 的命令式；dar 的简单过去时 yo |
| dé / de | dar 的虚拟式现在时 / 前置词 |
| está / esta | estar 的现在时 él / 指示形容词 |
| vino | venir 的简单过去时 él；名词“葡萄酒” |
| ha / hay | 助动词 haber / 无人称动词“有” |
| hecho / echo | hacer 的过去分词 / echar 的现在时 yo |

下面是变位里最常见的书写错误：

| 常见错误 | 正确写法 | 原因 |
| --- | --- | --- |
| hablastes | hablaste | tú 的简单过去时没有 -s |
| tuvé, hizó | tuve, hizo | 强变化简单过去时不写重音符号 |
| fuí, dió, vió | fui, dio, vio | 单音节不写重音符号 |
| dijieron, trajieron | dijeron, trajeron | -j- 型用 -eron |
| conducí, andé | conduje, anduve | -ducir 是 -j- 型，andar 是 -u- 型 |
| queré | querré | querer 去掉 e 后两个 r |
| ponido, volvido | puesto, vuelto | 不规则过去分词 |
| no hablad, no habla | no habléis, no hables | 否定命令式用虚拟式 |
| sentémosnos | sentémonos | nosotros 加 nos 去掉 -s |
| habían muchos coches | había muchos coches | 无人称 haber 用单数 |

! 分辨时态时先看词尾前面是什么：将来时和简单条件式的词尾加在整个原形动词后面（hablar-é、comer-ía），简单过去时和过去未完成时的词尾加在词根后面（habl-é、com-ía）；再看重音符号的位置（hablara / hablará，hablo / habló）。
