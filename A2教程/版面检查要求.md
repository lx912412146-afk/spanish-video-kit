# 《西班牙语 A2 教程》版面检查要求

两本 PDF：学生用书 `A2教程/out/西班牙语A2教程_学生用书.pdf`、教师用书 `A2教程/out/西班牙语A2教程_教师用书.pdf`，A4，要直接打印给学生和老师用。你只查版面，不查内容对错，也不改任何文件。

检查图：学生用书 `A2教程/qa/s/sheet_XXX-YYY.png`，教师用书 `A2教程/qa/t/sheet_XXX-YYY.png`，每张 6 页（左上角红字是 PDF 页码）。先逐张看你负责的检查图；看到可疑的地方，放大渲染那一页再确认（输出到你自己的目录）：

`pdftoppm -f N -l N -r 110 -png <PDF> <你的目录>/p`

也可以用同一目录下的 `pdftotext -f N -l N -layout <PDF> -` 按文字核对。

要找的问题（只报“必须改”的）：
- 空白页、几乎空白的页，或者页面下半部分无故大片空白（超过 40%；每个单元从新页开始，单元末页很短是正常的）
- 标题孤零零留在页底；表头行单独留在页底；对话框、例句框、×/√ 对比框被切开、只剩一行在另一页
- 表格：列太窄导致一个词断成几行、文字溢出格子、表格超出版心
- 文字重叠、被裁切、超出页边；字体突然变化（比如出现和全书不一样的字体）；行距异常
- 西语单词在行中间被断开；中文标点出现在行首；数字被拆到两行
- 残留的标记符号：**、> 、@音频、#、`
- 题目列表：题号、选项、答案的缩进和对齐不齐；选项和题干分在两页
- “音频 3-1”这样的录音标签和下面的对话框分在两页
- 页眉（“西班牙语 A2 教程 · 学生用书 / 教师用书”）和页码缺失或错误；目录点线和页码对不齐
- 阶段测试能不能直接复印：每个部分从新页开始，题目、选项、答题线清楚

下面这些已经知道、决定不改，不用报（和 A1 一样）：段末只有一两个汉字成行；表格格子里最后一两个汉字单独成行；新的一节开始前上一页底部空 30% 左右；例句框或表格整体移到下一页造成的页底空白（40% 以内）；阶段测试里新部分另起一页、整块的短任务移到下一页造成的页底空白；连读符号“‿”在 pdftotext 里顺序乱（印出来是对的）；“‿”画在相连两个字母的下面、两个词挨在一起（Era‿un 印成 Eraun 下面一道弧，和 A1 一样）；地址里两个数字分在两行；阶段测试阅读部分每个任务另起一页造成的上一页空白；正文里（不是词表里）的西语短语在空格处转行。

汇报（中文，400 字以内）：只列“必须改”的问题，每条写书名、PDF 页码和具体问题。没有就写“没有必须改的问题”。
