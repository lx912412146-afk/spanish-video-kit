## 1. CEFR 的 A2 能力描述

**说明**：增补卷的量表里，A2 一行通常包括两档：横线以上是“加强档”A2+（strong Waystage），横线以下是 A2 本档。本次提取的文字层没有保留横线，下表把两档合在一起概括，**没有逐条区分哪几条属于 A2+**（未核实）。增补卷第 38 页解释了“基准档”（criterion levels）和“加强档”（plus levels）的区别：加强档表示能力很强但还没有达到上一级的最低标准，上一级的特征开始出现。[S1 p.38]（已核实：官方原文）

### 1.1 总体描述（Global scale）

- **A2 总体描述（中文概括）**：能听懂与切身相关领域（很基本的个人和家庭信息、购物、本地地理、工作）的句子和常用表达；能在简单的日常任务中，就熟悉的日常事务进行简单、直接的信息交流；能用简单的话描述自己的背景、周围环境和与切身需要有关的事情。[S1 p.175；S2]（已核实：官方原文；S2 是 2001 年版措辞，S1 改成了性别中立的写法，内容相同）
- **A2 的“显著特征”**（增补卷附录 1）：A2 相当于“Waystage”规格。表示社交功能的描述语大多集中在这一级：用简单的日常礼貌形式问候和称呼、问候、问对方近况并对消息作出反应，处理很短的社交交流，问答工作和空闲时做什么，发出和回应邀请，商量做什么、去哪儿并约见面，主动提出和接受提议（*make and accept offers*）；也包括外出办事：在商店、邮局、银行办简单事务，获取出行信息，乘公共交通，问路指路，买票。**A2+** 的特点是在别人帮助下更主动地参与对话（开始、维持和结束简单对话），独白能力明显增强：描述过去的活动和个人经历、习惯和日常、计划和安排，说喜欢什么不喜欢什么，比较物品。[S1 p.173]（已核实：官方原文）

### 1.3 语言能力（A2）

- **语言范围**：掌握基本语言，能应付内容可预见的日常情境，但一般要压缩想表达的意思、找词；能用基本句型，靠背下来的短语、几个词的词组和套语谈自己和别人、做什么、地方、东西等。[S1 p.130]（已核实：官方原文）
- **词汇范围**：词汇足以进行涉及熟悉情境和话题的日常事务，表达基本交际需要和应付基本生存需要。[S1 p.131]（已核实：官方原文）
- **语法准确性**：能正确使用一些简单结构，但仍然**系统地**犯基本错误；不过一般能让人明白要说什么。[S1 p.132]（已核实：官方原文）
- **词汇控制**：能控制与具体日常需要有关的有限词汇。[S1 p.133]（已核实：官方原文）
- **语音控制**（整体、发音、韵律三栏）：发音一般清楚到能被听懂，但对方不时需要要求重复；其他语言对重音、节奏和语调的强烈影响可能影响可懂度，需要对方配合；熟悉词语的发音清楚；音位上有系统性的错误也不妨碍理解，只要对方愿意适应说话人的语言背景；常用词和短语的重音等韵律特征基本够用。[S1 p.135]（已核实：官方原文）
- **正字法**：能抄写关于日常事物的短句（如路线说明）；能把口头词汇里的短词写得大致符合读音（不一定完全符合标准拼写）。[S1 p.136]（已核实：官方原文）
- **社会语言得体性**：能用简单方式完成和回应基本语言功能（交换信息、请求、表达观点和态度）；能按基本惯例、用最简单的常用表达进行简单而有效的社交；能发出和回应邀请、建议、道歉等。[S1 p.137]（已核实：官方原文）
- **主题展开**：能用简单的要点讲故事或描述；能在很简单的文本里用“比如”举例。**连贯和衔接**：能用最常见的连接词把简单句连起来讲故事或描述；能用 and、but、because 连接词组。[S1 p.140–141]（已核实：官方原文）
- **流利度**：能用简短的话让人明白，尽管停顿、开头说错、改口很明显；能比较顺利地就熟悉话题组织短语，应付简短交流。**命题精确度**：在就熟悉的常规事务进行简单直接的有限信息交换时能说清想说的话，其他情况下一般要压缩意思。[S1 p.142]（已核实：官方原文）

### 1.4 自评表（S1 附录 2，p.177–181）中的 A2 格（中文概括）

- 听：能听懂与最切身相关领域（很基本的个人和家庭信息、购物、本地地理、工作）有关的短语和最高频词汇；能抓住简短、清楚、简单的消息和通知的要点。
- 读：能读很短的简单文本；能在广告、简章、菜单、时刻表这类简单日常材料中找到具体的、可预见的信息；能读懂简短的简单私人信件。
- 口头互动：能在需要就熟悉话题和活动进行简单直接信息交流的简单例行任务中交流；能处理很短的社交交流，尽管通常听不懂得足以自己维持对话。
- 口头表达：能用一串短语和句子简单描述家人和其他人、居住条件、教育背景和目前或最近的工作。
- 书面表达：能用 and、but、because 等简单连接词连接一串简单的短语和句子。
- 书面和在线互动：能进行基本的社交互动，说自己的感受、在做什么、需要什么，用感谢、道歉或回答问题回应评论；能完成订购商品这类简单事务，能执行简单指示，能和乐于帮忙的伙伴合作完成共同任务。
- 调解：文本——能转述日常切身话题的简短文本的要点（文本须用简单语言、表达清楚）；概念——能在简单的实际任务中合作，问别人怎么想、提出建议、听懂回应（可以不时要求重复）；交际——能用简单词语请人解释、表示自己听懂和/或同意，能转述可预见日常情境中关于个人需要的要点，能看出人们意见不合或出现困难并用简单短语寻求妥协。

（以上已核实：官方原文 [S1]。增补卷的自评表是扩充版，把 2001 年版的“写”拆成“书面表达”和“书面和在线互动”，又加了调解三行。）

**对编写的直接含义**：

1. CEFR 把“描述过去的活动和个人经历”“问答过去的活动”“讲一个简单的故事（如假期里的事）”“很简短地描述事件、过去的活动和个人经历”都列在 A2（见上表“描述经历”“信息交换”“创意写作”），所以**过去时是 A2 的核心任务**，与 PCIC 把三个过去时的基本形式都放在 A2 一致（见 2.1）。
2. A2 的语法准确性描述是“仍然系统地犯基本错误，但意思清楚”，评价时应以“能被理解”为标准，不要求过去时选用完全正确（DELE A2 的 2 分档描述也是这样，见第 4 节）。
3. A2 新增而 A1 没有的交际功能主要是：请人帮忙和借东西、指出问题、看病预约、电话和留言转告、比较人和物、讨论去哪儿和约定、写感谢和道歉的短信、填写日常表格和网上报名。这些可以直接作为单元的交际目标。

## 2. 塞万提斯学院《课程计划》（PCIC）A2 内容清单

> **结论（回答“哪些在 A2、哪些到 B1”）**：
> - **A2**：pretérito indefinido（规则变位和 ser、ir、tener、hacer、estar、ver、dar）、pretérito imperfecto（规则变位和 ser、ir、ver；描写和习惯）、pretérito perfecto（含强变分词和时间标记）、perfecto 与 indefinido 按时间标记区分、叙述中 indefinido 和 imperfecto 的基本配合、**肯定**命令式（含 usted/ustedes 和代词后置）、estar + 副动词、ir a / acabar de / empezar a / volver a / terminar de / poder / tener que / hay que + 原形动词、OD 和 OI 代词（含 *se lo* 和代词重复）、比较级、*nada / nadie / nunca*、*si* + 现在时＋现在时、*por eso / entonces / primero / luego / después / por último / cuando*。
> - **B1**：**简单将来时**（功能 A2 有一条例外）、**条件式**（A2 只有 *me gustaría*）、**否定命令式**、现在虚拟式、过去完成时、imperfecto 和 indefinido 的**系统对比**（被打断、同时发生、*cuando / mientras*）、强变过去式（*pude, puse, dije, vine…*）和 e>i / o>u 的过去式、**代词组合的系统规则**、*soler / dejar de / seguir* + 副动词、*deber* + 原形动词、*algo / alguien / alguno / ninguno*、相对最高级和 *-ísimo*、关系副词 *donde*、*por / para* 的对比、*si* + 现在时＋将来时、*aunque / sin embargo / además / así que*。
> 这与 DELE A2 的评分量表一致：书面表达 2 分（达到 A2）的描述是“现在时和陈述式的过去时、代词、物主词、常用迂说法（*tener que, ir a*）”，而 3 分（明显超过 A2）才提到“现在虚拟式、将来时、迂说法、过去时的配合”（见第 4 节）。

### 2.5 发音和韵律（A1–A2 合并清单）中与 A2 关系较大的内容 [S10]（已核实：官方原文）

PCIC 的发音清单 A1 和 A2 合在一起（详见 A1 汇编 2.6）。A1 教材已经覆盖元音、主要辅音对立、重音规则、疑问句语调和连读的入门。下列条目在 A2 阶段值得重点复习或深化（选择是本文作者的建议，条目本身是官方原文）：

- **重音区别词义**（*caso / casó*）和**动词的重音规律**：现在时重音多在倒数第二音节（vosotros 形式例外）；其他时态的重音落在固定的词素上（清单举的类型是 *trabajé, trabajaba, trabajaré, he trabajado*）——这正好对应 A2 的 indefinido、imperfecto 和将来时。
- **跨词重新分音节**和**元音连读**（清单举的类型有 *tomar algo*、*dos amigos*、*me he levantado*、*vivo en Málaga*）——pretérito perfecto 的 *he / ha* 常和前后的元音连读。
- **语调单位的切分**：枚举中每项一个语调单位；超过十五个音节的简单句至少两个单位；并列复句分成不同单位（*Quiero ir // pero no puedo*）——对应 A2 的叙述和连接词。
- **陈述句句末的降调、升调和平调**，以及句末语调的表情功能（肯定的断言和带犹豫的断言）；**特殊疑问句、一般疑问句**的语调；**感叹句和表情类言语行为**的基本语调；问候和礼貌用语的语调。
- **节奏**：西语倾向于音节计时；**必须停顿的地方**（*No tenemos que seguir* / *No, tenemos que seguir*）和可停顿的地方；填充停顿（*eeee*、*mmm*、*pues*、*bueno*）。
- **辅音**：塞音与擦音、清音与浊音的对立（清单举的类型有 *poca / boca*、*barco / cabo*、*dato / seda*）；l 与 r（*pelo / pero*）；单击和多击颤音（*pero / perro*）；ñ、ch、yeísmo；[x]；齿间音和 seseo。
- **元音**：二合元音和元音分读（*reí / rey*）、三合元音；口语中把分读读成二合元音的倾向。

### 2.6 正字法（Ortografía）A2 栏 [S11]（已核实：官方原文）

- **字母**：b 用于第一变位动词和 *ir* 的 imperfecto（*-aba*、*iba*）；v 用于 *andar, estar, tener* 的 indefinido（*anduve, estuve, tuve*）、n 后（*enviar, invitar*）、*-avo, -evo, -ivo* 等结尾；c 用于以 z 结尾的单数变复数（*luz / luces*）；z 用于 *hacer* 的 indefinido 第三人称单数（*hizo*）；j 用于 *-aje* 结尾；h 在词尾和词中（*¡ah!, ahora*）；**y 用于常用动词副动词的拼写变化（*leyendo, oyendo, yendo*）**；ll 用于 *-illa, -illo*；n 在 v 前；x 在音节末读 /s/，个别专名里读 /x/（*Ximena*）。
- **大小写**：罗马数字表示世纪和君主（*siglo XXI*）；方位名词（*el Norte* / *el norte de la ciudad*）、职务、机构、学科、神祇、节日和历史事件（*Navidad*、*Día de la Constitución*）大写；带冠词的城市名冠词大写（*La Paz*）；书信称呼后的冒号之后另起一行大写。
- **音节和拼写**：音节结构；行末移行（ch、ll、rr 不拆开，同一音节的辅音组合不拆开，数字不拆开）；千位和百万位的写法；世纪的罗马数字；日期写法（带不带冠词、数字日期）。
- **重音符号**：**命令式和副动词后接一个代词时按一般规则加重音（*cómpralo, comprándolas*）**；**区别性重音 *mi / mí*、*si / sí***。
- **标点**：年份和页码不加点；列表不加点；逗号用于列举、*ni* 的列举、句首称呼、顺序副词（*primero, después, luego*）后；**冒号用于举例和书信称呼后（*Querido Alfonso:*）**，书信的段落和缩进；省略号表示未完的列举；疑问句和感叹句的标点；括号用于分类编号；连字符（*Madrid-Asturias*）；破折号用于提纲；斜线（*100 km/h*）；星号作注释。
- **缩写和符号**：缩写的复数（*Uds., págs.*）；度量单位（*km, g, l*）；*ºC*。

### 2.7 语用策略（Tácticas y estrategias pragmáticas）A2 中与编写有关的条目 [S12]（已核实：官方原文）

- **话语标记**：连接词只列结果类 *por eso, entonces*；信息组织词 *primero*（开始）、*luego, después*（继续）、*por último*（结束）；源于命令式的接触标记 *oye / oiga, mira / mire*。
- **否定**：*—¿Has visto algo? —No, no.*（重复否定）；*todavía / aún* 与否定连用（*Juan no ha llegado todavía*）；*en toda la semana* 一类时间表达只用于否定句。
- **语调的情态功能**：特殊疑问句用升调表示关心答案，有时带责备。
- **时间视角**：用现在时表将来，使信息显得确定（*Ya voy*；*Mañana voy a Barcelona*）。
- **礼貌**：用无人称的 *se* 和 *hay* 弱化说话人或听话人的角色（*¿Se puede pasar?*；*Hay que estudiar más*）；用间接言语行为（*¿Me das el pan?* 代替命令；*Aquí hace frío* 代替“关窗”）；词汇化的命令式 *perdona / perdone* 表示礼貌。

  3. 习俗 —— A 家庭和性格，**ser 和 estar + 形容词**；B **pretérito perfecto**（最近的过去和经历）；C ***(no) hay que / (no) se puede***（禁止和义务），尾重、倒数第二、倒数第三音节重读词；D 传统
  4. 空闲时间 —— A 住房和家具，***me gustaría + inf.***；B **indefinido 与 perfecto**（电影和周末活动）；C **OD 和 OI 代词**，重音符号；D 西语电影、节日
  5. 从前和现在 —— A **imperfecto**（过去的习惯和情况；本板块后有 imperfecto 和 indefinido 混合的练习）；B **比较级和最高级**；C 在城市里出行（问路、交通工具），二合元音；D 布宜诺斯艾利斯
  6. 做饭 —— A 写广告、电话买卖；B 买菜，**不定词 *algo / nada, alguien / nadie, algún / ningún***，二合元音和分读；C **无人称 *se***（菜谱）；D 地中海饮食
  7. 建议 —— A 海滩和健康，**肯定和否定命令式**；B **ser / estar**（情绪）；C ***¡Que te mejores!*：现在虚拟式（表达愿望）**，r/rr 的拼写；D 健康习惯
  8. 报纸 —— A 职业和招聘广告；B 报纸版面，***estaba + 副动词* 与 indefinido**（正在做某事时发生了另一件事）；C **间接引语**，/p/–/b/；D 西语作家
  9. 预测 —— A ***llevar + 副动词***（持续了多久）；B **简单将来时**（预测；本板块还练习条件句）；C 观点（*A mí me parece*、*yo creo / pienso*、*a mí también / tampoco*），c 和 z；D 移民
  10. 计划 —— A ***voy a / pienso + inf.***；B ***cuando* + 虚拟式**；C **关系从句**，s、z、c、cc 的拼写；D 西班牙民主过渡
- **说明**：NEEM 第 1 册（A1）已经教过 indefinido、imperfecto、*ir a*、命令式、OD 代词、比较级和 *estar* + 副动词（A1 汇编 3.4），第 2 册在此基础上系统化，并在后半册进入虚拟式、将来时和间接引语。

**归纳**（据第 3.1–3.4 节和上表）：

1. **开头先复习现在时**（含不规则），四套都是这样（NEEM 第 0 单元，其余第 1 单元）。
2. **第一个过去时是 indefinido**：四套都先教 indefinido（NEEM 第 1 单元、Aula 第 2 单元、nuevo PRISMA 第 2 单元、拉美版 Prisma 第 3 单元），并常配“传记”或“假期”话题；随后很快教 pretérito perfecto 及其与 indefinido 的对比（第 3–6 单元）。
3. **imperfecto 放在中段或后段**（NEEM 第 5、nuevo PRISMA 第 6、拉美版 Prisma 第 7、Método 第 7、Aula 第 9 单元），先讲“过去的习惯、从前和现在”，再在同一单元或后面一两个单元讲 **imperfecto 与 indefinido 的对比**，往往配“讲故事、趣事、新闻”话题和 *estaba* + 副动词。
4. **命令式放在中后段**：肯定命令式在第 7–12 单元，常配“健康、建议、家务规则”；**否定命令式三套和肯定式一起教**（NEEM、nuevo PRISMA、拉美版 Prisma），并且和现在虚拟式放在相邻位置；Aula Plus 2 只教肯定式。
5. **将来时：三套在 A2 后段教**（NEEM 第 9、nuevo PRISMA 第 8、拉美版 Prisma 第 10 单元），常配“预测、可持续未来、条件句”；Aula Plus 2 不教。条件式只有两套 Prisma 系统教，NEEM 和 Aula 只用 *me gustaría* 或 *¿podrías…? / ¿te importaría…?* 一类礼貌说法。
6. **现在虚拟式**：三套在最后一两个单元入门（表达愿望、*cuando* + 虚拟式），Aula 不教。
7. **总体看，海外 A2 教材普遍比 PCIC A2 走得远**：除 Aula Plus 2 外，都在后半册进入 PCIC 列在 B1 的将来时、条件式、否定命令式、虚拟式、间接引语；**PCIC A2 的核心里，三个过去时、OD/OI 和比较级都放在前半册到中段，肯定命令式在中后段**。
8. **话题顺序的共性**：复习和相识 → 假期或传记（indefinido）→ 经历和刚发生的事（perfecto）→ 住房、城市、比较 → 从前和现在（imperfecto）→ 讲故事（过去时对比）→ 健康和建议（命令式、*doler*）→ 未来、计划和愿望。

## 4. DELE A2 的结构（现行 2020 版）

### 4.1 总体结构

| 考试 | 时长 | 任务和题量 | 分值 |
|---|---|---|---|
| 1 阅读理解 | 60 分钟 | 4 个任务，25 题（5 + 8 + 6 + 6） | 25 分（25%） |
| 2 听力理解 | 40 分钟 | 4 个任务，25 题（6 + 6 + 6 + 7） | 25 分（25%） |

- 前三项在官方考试日按考点时间进行；口试可以安排在官方考试日的前一天或后一天。[S13]
- 阅读和听力的试题印在同一本试卷上，答案涂在单独的答题卡上；每题答对 1 分，答错 0 分，不倒扣分。[S14 p.8、p.10]

### 4.2 各任务的格式（中文概括，只记格式）

**阅读理解**（文本总长 1325–1725 词；真实文本，必要时改写到本级可理解的程度）[S14 p.8–9；S15 p.1]

| 任务 | 文本 | 题型 | 考查能力 |
|---|---|---|---|
| 1（5 题） | 一封私人信件、邮件或其他短书信（个人领域），250–300 词 | 读一篇，5 道三选一 | 抓主旨，找简单、可预见的具体信息 |
| 2（8 题） | 八篇改写的信息或宣传材料：很短的报刊文章、宣传册、广告、海报、通知、博客、论坛、活动通告（公共领域），每篇 50–80 词 | 读八篇，每篇一道三选一 | 在含描述、指示、通知、规定的短文中找相关信息 |
| 3（6 题） | 三篇信息或描写类文本（同上，另加菜谱、节目单、招聘广告），每篇 100–120 词 | 把 6 个句子或问题与三篇文本配对 | 找具体的、可预见的信息 |
| 4（6 题） | 一篇叙述性文本：时人小传、日记、博客、故事、报刊新闻、旅游指南中关于人物地点事件的文字（个人和公共领域），375–425 词 | 读一篇，6 道三选一 | 抓叙述性短文的要点和话题转换 |

**听力理解**（文本总长 975–1465 词；录音棚录制，模拟真实口语；每段播放两遍，前后有停顿；录音中的指令与试卷相同）[S14 p.10–11；S15 p.2]

| 任务 | 录音 | 题型 | 考查能力 |
|---|---|---|---|
| 1（6 题） | 六段当面的非正式对话（日常活动、空闲时间、爱好）或事务性对话（商店、餐馆、车站、机场），每段 50–80 词 | 每段一道三选一，**选项是图片** | 听懂简短非正式对话的要点 |
| 2（6 题） | 六条简短的广播内容：新闻、节目片段、广告、活动信息（首映、打折、报名等），每条 40–60 词 | 每条一道三选一 | 抓广播短讯的大意（语速慢、发音清楚） |
| 3（6 题） | 一段两人交换个人信息的对话（消息、日常生活、建议、约会），225–275 词 | 把 6 个句子与说话人配对：**男的、女的、或两人都不是** | 听出非正式对话的要点和具体信息 |
| 4（7 题） | 七条通知、指示、广告（录音、广播或喇叭；时间、优惠、安全须知）或电话留言（约会、通知、请求），每条 30–50 词，没有噪音 | 把 7 条录音与 10 个句子中的 7 个配对 | 抓录音或广播信息的要点 |

**书面表达与互动**（考生共写 130–150 词）[S14 p.12–13；S15 p.3]

| 任务 | 给考生的材料 | 要写的东西 | 字数 |
|---|---|---|---|
| 1 书面互动 | 写作提示，以及一篇 35–45 词的来信、便条、留言、邀请或邮件（按原文体裁格式呈现） | 回一张便条、明信片、留言、邮件或短信，内容是个人生活的日常事务（习惯、愿望、喜好、学习或工作的地方和经历、住处、生活条件等） | 60–70 词 |
| 2 书面表达 | 写作提示；照片和/或文字给出的简单信息 | **两个选项选一个**：A 关于个人生活的日常话题；B **根据照片或资料写传记或叙述**。要求用连起来的句子描述周围事物，很简短地描述事件、过去的活动和个人经历 | 70–80 词 |

**口语表达与互动**（12 分钟；考前 12 分钟准备三个任务，可以记笔记、写提纲并在考试时参考；开始时有几句寒暄；两位考官，一位提问，一位只评分）[S14 p.17–18；S15 p.4]

| 任务 | 时长 | 内容 | 材料 |
|---|---|---|---|
| 1 陈述 | 2–3 分钟 | **从两个话题中选一个**，做一段准备过的独白，用简单的话描述自己日常生活中与该话题有关的方面和经历（个人领域） | 题卡：任务说明和该话题要谈的几个方面 |
| 2 描述图片 | 2–3 分钟 | 根据一张照片做独白，简单描述一个日常生活场景中的实际事务（购物、乘交通工具等）（公共领域） | 题卡：描述提示和一张日常场景照片 |
| 3 与考官对话 | 3–4 分钟 | **以任务 2 的照片为情景**，与考官进行模拟对话：满足基本需要的事务性对话，或关于日常活动、空闲时间、工作、爱好的非正式对话 | 任务说明 |

### 4.3 评分和及格

- **总分 100**，分两组计算：第 1 组＝阅读（25）＋书面（25）；第 2 组＝听力（25）＋口语（25）。**每组都要达到 30.00 分（满分 50）**才算“合格”（Apto），否则“不合格”（No apto）。成绩在考后 1–3 个月通过网站公布（通知单只供参考，不是证书），可以申请复核。[S14 p.27]（已核实：官方原文）
- **书面和口语的评分**：用整体量表，每项给 0–3 分，**2 分相当于 CEFR A2（Plataforma 档）**，3 分为明显超过，1 分为未达到，0 分为空白、离题或无法辨认；原始分按“得分 × 25 ÷ 满分”换算成 25 分制。[S14 p.13、p.18、p.25]
  - 书面：两位评分员独立评分后取平均；**两个任务各占 50%**；每个任务给“语言运用”（占 66%）和“任务完成”（占 34%）两个分。[S14 p.12–13、p.25–26]
  - 口语：**评分员占 60%，提问的考官占 40%**；评分员逐任务评分（**任务 1、任务 2 各占评分员部分的 25%，任务 3 占 50%**；任务 1–2 用一个量表，任务 3 用另一个），提问考官对整场考试给一个总评；每次都分“语言运用”（66%）和“任务完成”（34%）。（指南 p.26 的汇总表把任务 3 印成“25%”，但表内数值和正文都对应 50%，应是印刷错误。）[S14 p.17、p.26]
- **量表描述的要点**（中文概括，供本书自编量表参考，不是原文）[S14 p.14、p.19–20]：
  - 书面 2 分：词汇语法有限，但会用陈述式的现在时和过去时、代词、物主词、常用迂说法（*tener que, ir a*），能用顺序词、简单连接词和关系词连接短句，完成描述、讲述、询问等；会犯基本的、系统性的错误（ser / estar / haber、一致、规则和不规则过去时），但不妨碍理解；任务方面可以漏掉或答错一个要点。3 分才要求较好地控制**现在虚拟式、将来时、迂说法、过去时的配合**，能用从句和 *además, sin embargo, aunque, como* 等连接词，并加入细节、评论或理由。
  - 口语（任务 1–2）2 分：能表达事实、愿望、偏好、情绪和评价（*me gusta, quiero, creo que*），话语用 *porque*、副词、指示词作简单连接，控制基本规则（陈述式现在时和过去时、一致、冠词、物主词、基本迂说法），有明显外国口音和零星发音错误但容易听懂；任务方面最多漏答一个要点或两个要点答得不完整。3 分要求较好地控制将来时、常用迂说法等，用 *es que, por eso, además* 连接，发音清楚可懂。
- **2027 年考期**（据新官网，2026-10-23 读取）：普通 A2 考试有 3 月 5 日、4 月 2 日、**5 月 22 日**（报名截止 4 月 7 日）、**7 月 9 日**（报名截止 5 月 12 日）、9 月 10 日、10 月 15 日、11 月 13 日；学校版 A2/B1 为 5 月 21 日和 11 月 12 日。[S16]（已核实：官方原文；各考点是否开考每一期，未核实）

### 4.4 对本书测试的启示（建议）

1. **单元小测和阶段测试的题型**可以直接借用上述格式（题目内容自编）：阅读用“一封 250 词左右的邮件＋三选一”“短告示三选一”“三篇短文与句子配对”“一篇叙述文三选一”；听力用“看图三选一”“广播短讯三选一”“对话里的话是男的说的、女的说的还是都不是”“留言与句子配对”；写作用“回一封 35–45 词的来信，写 60–70 词”和“看照片或资料写 70–80 词传记或叙述”；口语用“二选一话题的 2–3 分钟准备陈述”“描述日常场景照片”“以照片为情景的角色扮演”。

## 5. 中国学习者在 A2 阶段的难点

### 5.1 有文献依据的难点

| 难点 | 依据 | 可信度 |
|---|---|---|
| **过去时的选用是动词错误的大头**：Yin (2024) 分析 99 名中国大学生（A2 和 B1）的 392 篇口头和书面文本，共 1612 个动词错误，**时态混淆占 63.5%**；其中用现在时代替过去时 709 例，用过去时代替现在时 315 例；**口头任务的错误占 73.9%，书面占 26.1%**；**叙述文的错误占 65.3%，描写文占 34.7%**；A2 组最常见的错误类型是**动词不变位、直接用原形**，B1 组是时态混淆；A2 组用的动词种类少（多是 ser、haber、tener），所以错误绝对数少但比例高。作者认为原因之一是国内常用的《现代西班牙语》（*Español Moderno*）先教现在时、到 A2 才引入过去时，学生花在现在时上的时间多；而且学生背熟了变位但不会在语境中选用 | Yin 2024 [S31] 印刷页 235–244（语料来自北华大学的学生，语料库名 CorSinoELE） | （已核实：官方原文） |

| **ser / estar**：汉语形容词作谓语不用系词，学生会直接漏掉 ser 或 estar（类型：*\*Ella muy guapa*、*\*Nosotros muy cansados*）；有些 ser / estar 混用属语言内部的发展性错误（类型：*\*Comer en clase no es bien*）；*ser bueno / estar bueno* 这类词义差别理解和表达都难 | Cortés Moreno 2002 [S30] 第 4.5、5 节 | （已核实：官方原文） |
| **ser / estar、tener / haber、usar / llevar 的混用**是 A2–B1 学生词汇性动词错误中最多的三类（在 192 个词汇混淆错误中分别为 51、47、10 例，如描述图片时用 *tiene* 代替 *hay*，用 *usa* 代替 *lleva* 表示穿戴）；B1 学生也照样犯 | Yin 2024 [S31] 印刷页 243–244 | （已核实：官方原文） |
| **无重音代词**：汉语一个“我/我们”同时对应西语的主格、宾格、物主形式，学生会写出 *\*Da nosotros más tiempo* 这类句子；滥用主语代词；在一段话里 tú 和 usted 混用；**西语要求重复的 OD / OI 代词，学生往往只用一个**（类型：*\*Daré a mi compañero la fotocopia*，缺 *le*；*\*La fruta compramos nosotros*，缺 *la*） | Cortés Moreno 2002 [S30] 第 4.2、4.9 节 | （已核实：官方原文） |
| **介词**（包括 por / para）：用错、多用、漏用（类型：*\*enamorada con él*、*\*He decidido a comprar*、*\*Vamos pasear*），原因有汉语、英语的负迁移和语言内部的发展 | Cortés Moreno 2002 [S30] 第 4.6 节 | （已核实：官方原文；没有找到专门研究中国学生 por / para 的文献） |
| **冠词**：漏用（*\*Próxima semana voy…*）、多用（*\*Ahora no tengo el tiempo libre*）；**该用冠词的地方用物主词**（*\*Mete tus manos en tus bolsillos*，与 A2 的 *Me duele la cabeza* 直接相关）；受英语影响在职业前加不定冠词 | Cortés Moreno 2002 [S30] 第 4.4 节；Lin 2005 [S33]（台湾大学生作文中冠词错误最集中） | （已核实：官方原文；S33 内容依 A1 汇编） |
| **一致和变位**：主谓不一致（*\*Nosotros empieza*，汉语动词不分人称，加上英语影响和语言发展因素）；名词性别不知道导致的一致错误（*\*las problemas*）；**时态呼应**（*\*Llegó a casa y no encuentra a nadie*）是最难的一致问题 | Cortés Moreno 2002 [S30] 第 4.8 节；Yin 2024 [S31]（叙述文中人称一致错误突出） | （已核实：官方原文） |
| **条件句**：汉语只有一种条件句，连词可省，不区分真实和非真实，学生常常回避条件句 | Cortés Moreno 2002 [S30] 第 4.11 节 | （已核实：官方原文） |

| **口头表达弱于书面**：中国课堂长期偏重书面和传统教法，学生口头表达时很难把语法知识用出来，并且紧张 | Yin 2024 [S31] 印刷页 238–239（转引其他研究） | （已核实：官方原文；是作者的讨论，不是实验结果） |

### 5.2 本书的经验性建议（暂无可靠文献，作为编写原则）

- **过去时的选用**（经验）：
  - 先用**时间标记**建立第一条规则（*ayer / el año pasado / en 2020* → indefinido；*hoy / esta semana / ya / alguna vez* → perfecto；*antes / de niño / todos los días* → imperfecto），再讲“事件和背景”；不要一开始就讲抽象的“体”。
  - 用时间轴图示，并明确告诉学生**“了”不等于 indefinido、“过”不等于 perfecto**（例如“我昨天去了”和“我去过”都可能对应 indefinido 或 perfecto）。
  - Yin (2024) 发现错误集中在口头和叙述，所以每个过去时单元都要有限时的口头叙述练习，并用“照片描述（imperfecto）→ 讲事件（indefinido）”的顺序搭配 DELE 口语任务 2。
  - 西班牙和墨西哥在“今天发生的事”上用时不同（西班牙多用 perfecto，墨西哥日常多用 indefinido），Lucía 和 Diego 的对话可以自然体现，但要在注释里说明。（这一点本次没有从 PCIC 核实，编写时请查 RAE/ASALE《新语法》。）
- **动词变位负担**（经验）：A2 新增的变位很多（indefinido 和 imperfecto 全套，加上命令式），每单元控制新的不规则形式数量；按 PCIC 只把 ser、ir、tener、hacer、estar、ver、dar 的 indefinido 作为核心，其余强变式（*pude, puse, quise, vine, dije, supe*）标“A2+”分两三个单元逐步加入。Yin (2024) 发现 A2 组最常见的是“不变位”，所以练习要从“必须变位”的产出开始，而不只是选择题。
- **ser / estar 和 hay / tener**（经验）：A1 教了核心用法；A2 加“只能和 estar 搭配的形容词”（*contento, enfermo, cansado*）、*estar* + 分词表结果（*está roto*）、*estamos a / en*、*ser* + *por / para*。描述图片时专门练 *hay* 和 *tener* 的区别（对应 Yin 2024 的发现），穿戴专门练 *llevar*。
- **无重音代词**（经验）：先练“东西→代词”的替换和位置（变位动词前；原形动词、副动词、肯定命令式后），再练 *se lo*；**对代词重复（*A mí me…*、*Se lo doy a Luis*）专门讲，因为汉语没有**。西班牙不少地区用 *le* 指男性人物的直接宾语（*le vi*），Lucía 说话时可能出现，教材统一用 *lo*，在教师用书里说明。（*le* 的地区用法本次未从 PCIC 核实）
- **por / para**（经验）：A2 只教 PCIC A2 列出的几种具体用法（*para* + 目的/对象，*por* + 原因/经过/方式），作为词块来学；两者的系统对比留到 B1。
- **命令式**（经验）：肯定命令式 tú 形式和现在时第三人称单数同形，最容易学；*usted / ustedes* 形式（PCIC A2）与虚拟式同形，建议先作为“礼貌命令”的固定形式学（*perdone, mire, siga, tome*），不讲虚拟式；否定命令式放到 A2+ 或 B1，只教 *no te preocupes, no pasa nada* 这类固定说法时也要标明。中国学生对直接用命令式可能觉得不礼貌，要说明西语里命令式加 *por favor* 在很多场合是正常的礼貌方式（PCIC 语用 A2 也列了“命令式＋客气语”）。
- **冠词**（经验）：A2 重点练“身体部位和衣物用定冠词不用物主词”（*Me duele la cabeza*、*Me pongo el abrigo*）和“爱好名词带冠词”（*Juego al tenis*、*Me encanta el cine*）。
- **语音**（经验）：A2 阶段的重点是**重音区别词义**（*hablo / habló*、*tomo / tomó*）、**-aba / -ía 的重音**、**连读**（*he estado*）、**叙述和感叹的语调**；r / rr / l 和清浊塞音继续每两单元复习一次。
- **课堂文化**（经验）：沿用 A1 的“归纳活动后立即给中文讲解框”和“讲练式替代路线”；口语任务给足准备时间（模仿 DELE 的 12 分钟准备），减少学生开口的焦虑。

## 6. 给本书编写者的建议

### 6.1 总体原则（建议）

1. **以 PCIC A2 为核心，把海外教材常提前教的 B1 项目标为“A2+ 拓展”**：PCIC A2 栏的语法、功能和词汇必须全部覆盖；将来时、否定命令式、代词组合的系统规则、*soler / dejar de*、*algo / alguien / ninguno*、相对最高级、*donde*、强变过去式等，按海外教材的通行做法可以在 A2 接触，但在学生用书中统一标“A2+ 拓展”，不纳入核心考核（与 A1 的“A1+ 拓展”做法一致）。
2. **过去时贯穿全书**：CEFR A2 和 DELE A2 都以“描述过去的活动和经历、讲简单的故事、写传记”为核心任务。建议前 5 个单元集中建立三种过去时，后 5 个单元在新话题中反复使用。
3. **单元目标写成“我能……”**，按 CEFR A2 描述语（第 1 节）改写，每单元 4–6 条。
4. **每单元一个调解小活动**，按 CEFR A2 调解描述语设计（例如把中文通知的要点用西语转告交换生，或把西语留言转告中国同学）。
5. **测试按 DELE A2 题型**（第 4 节），单元小测 10–15 分钟，三次阶段测试和一次期末测试。
6. **原创要求**：课文、对话、练习、人物故事一律自编；单元划分和标题不照搬任何教材（下面的草案已与第 3 节对照过，标题都是自拟的）。

### 6.2 建议学时（建议）

10 个单元，每单元 9–10 学时，加 3 个复习单元（各 3–4 学时）和阶段测试、期末测试，共约 **100–120 学时**，相当于中国高校西语专业第二学期精读课，或成人业余班两个学期。参照：NEEM 2 为 60–80 学时（含练习册）[S27]；Método 为 80–100 学时（强化）到 130 学时（普通）[S17]；原版 Prisma A2 据书店信息约 90 学时（未核实）。A2 的新语法比 A1 密，建议不要少于 100 学时。

**草案说明**：

- **与海外教材的区别**：保留了第 3.5 节总结的通行顺序（复习现在时 → indefinido → perfecto 及对比 → imperfecto → 过去时对比 → 代词 → 命令式和健康 → 比较 → 将来和计划），但**imperfecto 和过去时对比提前到第 4–5 单元**（比 Aula、两套 Prisma 早，与 NEEM 相近），让后半册的新话题都能反复使用三种过去时；**不教条件式和虚拟式**（只有 *me gustaría* 和几句固定祝愿语），将来时、否定命令式只作 A2+，比 NEEM 和两套 Prisma 更贴近 PCIC A2，又比 Aula Plus 2 多给一些 A2+ 内容。情境（中国校园、寒假和春节、交换生回国）、语音重点、每单元的调解活动和中外对比都是本书原创。

### 6.5 学生用书单元的推荐组成（建议）

沿用 A1 的 15 个栏目（A1 汇编 6.4、单元规划），A2 作以下调整：

1. 单元首页的“我能……”按 CEFR A2 描述语写，并标出本单元对应的 DELE A2 题型。
2. 课文二改为 A2 的语篇类型：传记、日记、博客、个人邮件、菜谱和说明、招聘广告、告示、新闻短讯（PCIC 语篇类型 A2）。
3. 语法栏每个讲解框标 **A2 / A2+**；过去时单元的讲解框都配时间轴图。
4. 读写栏的写作字数从 A1 的 30–40 词提高到 **60–70 词（书信类）和 70–80 词（叙述、传记类）**，与 DELE A2 一致。
5. 口语栏每单元有一次“准备—陈述—追问”的 2–3 分钟练习，并给出准备用的提纲格。
6. 语音栏除发音外，每单元有一项语调或节奏练习（叙述、感叹、命令、请求、疑问）。
7. 单元小测改为 DELE A2 题型（10–15 分钟）。
8. 书后附录：A2 语法总表、动词变位表（增加 indefinido、imperfecto、perfecto、肯定命令式；A2+ 的将来时单列）、西中词汇总表、课文译文和听力原文。

### 6.6 教师用书的推荐内容（建议）

在 A1 教师用书的框架上（A1 汇编 6.5）增加：

1. 全书目标与 CEFR A2、PCIC A2、DELE A2 的对照表，列出每个 A2+ 项目在 PCIC 中的实际级别（可以直接用本文 2.1.2 的表）。
2. **过去时教学的专门说明**：三种过去时的分工、时间标记清单、“了 / 过”与西语时态的对应和不对应、常见偏误（第 5 节）、建议的练习顺序。
3. 每单元的“中国学生常见错误预警”增加：漏系词、hay / tener 混用、llevar / usar 混用、代词重复缺失、物主词代替冠词、口头叙述中用现在时代替过去时。
4. 按 DELE A2 两维度（语言运用 66%、任务完成 34%）改写的本书写作和口语量表（中文，写明是本书的量表，不是官方量表）。
5. 三次阶段测试和期末测试，题型按第 4 节，听力有录音，附答案和评分说明。
6. 西班牙和墨西哥用法差异的注释清单（perfecto / indefinido 的选用、*le / lo*、词汇差异），供教师讲解时参考。
