# 《西班牙语 A2 教程》单元规划

《西班牙语 A1 教程》的续篇，面向学完 A1 的中国大学生和成人学习者。学生用书 10 个单元＋2 个复习单元，教师用书逐单元对应，另有 2 套阶段测试。约 100–120 学时（每单元 10–12 学时）。依据 CEFR A2 和塞万提斯学院《课程计划》（PCIC）A2（资料见 `资料/A2大纲和教材结构.md`）；编排思路和 A1 一样参考海外交际法教材的通行做法，单元划分、标题、人物、课文、练习全部原创。A1 的人物、情节、已学内容见 `资料/A1人物和情节档案.md`，A2 必须和它一致。

## 学生用书每单元的组成（约 14–18 页）

和 A1 相同：单元首页（标题、“我能……”目标 4–6 条、任务预告）→ 导入 → 课文一（对话，录音）＋理解练习＋生词表 → 词汇 → 语法（观察例句＋小归纳 → 中文讲解框和表格，标 A2 / A2+ 拓展 / 复习 A1；中国学生常见错误提示；练习由控制到半控制）→ 交际（功能句型表、两人对话、信息差、角色扮演）→ 课文二（实用文本或第二段对话，有录音）→ 听力（1–2 个练习，原文在附录）→ 语音和拼写（讲解＋跟读录音＋练习）→ 读写（读一篇 150–200 词的短文，写一段 60–80 词的短文：邮件、留言、博客、小传、明信片）→ 文化窗口（中文讲，关键词西语，“比一比”）→ 调解小活动 → 单元任务 → 自我评估（“我能……”自评表＋10 分钟左右的 DELE A2 题型小测）→ 单元小结（语法要点表＋本单元生词总表）。

A2 的篇幅和难度比 A1 大一点：课文一的对话约 200–280 词；读写的阅读短文约 150–200 词；写作 60–80 词。

复习单元（约 6–8 页）：语法和词汇复习练习、DELE A2 题型小测（阅读、听力、书面表达、口语各一部分）、学习档案提示。

全书附录：A 语法总表（编写）、B 动词变位表（编写：A2 学的时态）、C 西中词汇总表（程序从各单元生词总表生成）、D 课文译文和听力原文（程序从录音稿生成）。

## 教师用书

- 总体说明（编写）：教学理念、全书目标与 CEFR / PCIC / DELE A2 的对照、和 A1 的衔接、课时方案（每周 4、6、8 学时）、录音使用说明（声音和人物对照、z/ce/ci 的读法说明同 A1）、中国学生在 A2 阶段的常见难点。
- 逐单元（10＋2 复习单元）：教学目标和重难点；课时安排；分步教学建议（归纳式和讲练式两种路线，快班慢班建议）；语音教学要点；中国学生常见错误；文化背景补充；补充活动；全部练习答案；单元小测答案；本单元全部录音稿（程序附上）。
- 阶段测试 2 套（第 1–5、6–10 单元后），DELE A2 题型、题目自编，含听力（有录音）、答案、写作和口语评分量表（本书自编）。
