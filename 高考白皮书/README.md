# 西班牙语高考白皮书

为参加普通高考、外语科目选考西班牙语的高中生和老师整理的一本备考书：试卷结构、各题型的经典类型和考试模板、原创样题和答案解析、写作范文、易错点和易错题、应试注意事项、常考词汇和表达，以及一套按真题格式原创的模拟卷。Word 和 PDF 在 Release [`gaokao-whitepaper`](../../../releases/tag/gaokao-whitepaper)。

## 内容

| 部分 | 章 |
| --- | --- |
| 第一部分 总览 | 第 1 章 高考西班牙语概况：外语语种和课标、命题依据、试卷结构、考试时间和听力安排、各地差异、课标要点、教材、报考和录取注意 |
| 第二部分 各部分题型和考试模板 | 第 2–6 章 听力、阅读、完形填空（语言运用第一节）、语法填空（语言运用第二节）、写作：结构、经典类型、做题方法、原创样题和解析、便签和短文范文 |
| 第三部分 易错点、易错题和注意事项 | 第 7 章 语法易错点；第 8 章 用词、拼写和重音易错点；第 9 章 易错题精练（带答案和解析）；第 10 章 应试技巧和注意事项 |
| 第四部分 常考词汇和表达 | 第 11 章 按课标主题整理的常用词汇；第 12 章 高频动词、搭配和固定结构；第 13 章 写作常用表达和模板句 |
| 附录 | A 备考计划；B 原创模拟卷（全真格式，含答案、范文和听力原文）；C 语法术语和语法项目一览 |

- 本书是独立编写的备考资料，不是教育部、教育部教育考试院或省级考试机构的出版物。
- 试卷结构依据教育部教育考试院 2024 年 1 月公布的高考综合改革适应性测试西班牙语科新课标试卷和专家解读；语言范围依据《普通高中西班牙语课程标准（2017 年版 2020 年修订）》；整理过程和每条事实的来源、可信度见 `资料/高考西班牙语考试事实.md`。试卷结构、听力安排和计分办法以当年教育部教育考试院和本省教育考试院公布的为准。
- 样题、篇章、听力原文、范文和模拟卷全部是按现行试卷格式新写的，不是高考真题，也不是考试院公布的样卷。官方没有公开西班牙语写作的评分标准，书中不写评分档次。
- 拼写按现行 RAE 规范（solo、este 不加重音）。
- 每章由一人编写、另一人独立审校，再做第二轮校对和全书一致性检查。按新课标卷题型、只考《现代西班牙语》第一册的模拟卷见 [`试卷/第一册高考模拟卷/`](../试卷/第一册高考模拟卷/)。

## 文件

| 文件 | 作用 |
| --- | --- |
| `chapters/*.md` | 各章正文（约定的简化 Markdown，标记见 `高考白皮书编写要求.md`） |
| `front_matter.md` | 编写说明 |
| `资料/` | 考试事实文件（编写时的依据，每条注明来源和可信度） |
| `build_gaokao.js` | 用 docx（npm）把各章排成 Word：封面、编写说明、目录（带页码）、各部分和附录 |
| `lint.py` | 检查章节文件的标记 |
| `高考白皮书编写要求.md`、`写作分工共同说明.md` | 编写规则、标记说明和各章内容要求 |

## 重新生成

需要 Node.js 和 `npm install docx@9.5.1`。在仓库根目录：

```bash
python 高考白皮书/lint.py 高考白皮书/chapters/*.md 高考白皮书/front_matter.md
node 高考白皮书/build_gaokao.js 高考白皮书/out/西班牙语高考白皮书.docx
```

PDF 是用 LibreOffice 转的（`soffice --headless --convert-to pdf`），目录页码由转换时计算；在 Word 里打开时如提示更新域，选“是”即可更新目录页码。字体用苹方（PingFang SC），Windows 上会换成默认中文字体。
