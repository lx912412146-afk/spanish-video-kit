# 西班牙语 A1 教程（学生用书＋教师用书＋录音）

面向中国大学生和成人零起点学习者的西班牙语 A1 教材：12 个单元、3 个复习单元，学生用书和教师用书各一本，配全部课文、听力、语音跟读、生词跟读和测试的录音。讲解以中文为主，课文、例句和练习用西班牙语。Word、PDF 和录音在 Release [`a1-textbook`](../../../releases/tag/a1-textbook)。

## 内容

| 部分 | 内容 |
| --- | --- |
| 学生用书 | 使用说明；第 1–12 单元（每单元：单元目标、导入、课文一、词汇、语法、交际、课文二、听力、语音和拼写、读写、文化窗口、调解小活动、单元任务、自我评估和小测、单元小结）；复习 1–3（含 DELE A1 题型小测）；附录 A 语法总表、B 动词变位表、C 西中词汇总表、D 课文译文和听力原文 |
| 教师用书 | 教师用书使用说明（教学理念、全书目标与 CEFR / PCIC / DELE A1 的对照、课时方案、中国学生常见难点、评价）；逐单元的教学目标、课时安排、分步教学建议（归纳式和讲练式两种路线）、语音教学要点、常见错误、文化背景、补充活动、全部练习答案、本单元录音稿；阶段测试 1–3（可复印的完整试卷、答案、本书的写作和口语评分量表） |
| 录音 | 每单元的课文、听力、语音跟读、单元小测和生词跟读；复习单元和阶段测试的听力。文件名是录音号：A1_3-1.mp3、生词跟读 A1_3-V.mp3、小测 A1_3-Q1.mp3、复习 A1_R1-1.mp3、测试 A1_T1-1.mp3 |

- 依据《欧洲语言共同参考框架》（2020 年增补卷）A1 描述和塞万提斯学院《课程计划》（PCIC）A1 清单编写，编排思路参考了海外交际法教材（Método、Prisma、Aula、Nuevo Español en marcha 等）的通行做法；课文、对话、练习、人物全部原创，没有使用这些教材的任何内容。整理过程见 `资料/A1大纲和教材结构.md`。
- 标“A1+ 拓展”的语法点属于 PCIC 的 A2 内容，本书提前接触，不作为核心要求。
- 人物：上海一所大学（虚构）西语专业的陈雨、李浩，西班牙交换生 Lucía、墨西哥交换生 Diego，西语老师 Carmen。以西班牙的说法为准，墨西哥说法在注释里对照。拼写按现行 RAE 规范。
- 录音用本仓库的 Qwen3-TTS 声音合成（五个声音：工具包男声和四个克隆声音），语速约 0.9 倍；每句都用语音识别（Parakeet）核对，并做响度和电磁音核查。
- 每个单元由一人编写、另一人独立审校，再做全书一致性修订和第二轮校对；版面检查了多轮。

## 文件

| 文件 | 作用 |
| --- | --- |
| `student/uNN.md`、`teacher/uNN.md`、`audio/uNN.md` | 各单元的学生用书、教师用书和录音稿（NN 为 01–12，复习单元 R1–R3，阶段测试 T1–T3） |
| `student/front.md`、`teacher/front.md`、`student/appA.md`、`student/appB.md` | 使用说明和附录（附录 C、D 由程序生成） |
| `build_a1.js` | 排版程序：`node build_a1.js student` / `teacher` 生成 Word |
| `tools/make_tracks.py` | 录音程序：按录音稿合成，逐句识别核对，响度和电磁音核查 |
| `tools/check_unit.py` | 检查一个单元的标记、录音号、练习和答案、生词表 |
| `tools/vocab_audit.py`、`tools/dedupe_vocab.py` | 全书生词一致性检查和去重 |
| `voices/` | 克隆用的参考录音 |
| `编写要求.md`、`单元规划.md`、`复习和测试编写要求.md`、`审校要求.md`、`二校要求.md` | 编写规则、单元规划和审校要求 |

## 重新生成

Word：需要 Node.js 和 `npm install docx@9.5.1`。PDF 用 LibreOffice 转（目录页码转换时计算）。录音在 `setup_mac.sh` 装好的环境里运行（另需 Parakeet 识别模型）：

```bash
python A1教程/tools/check_unit.py 01 02 03 04 05 06 07 08 09 10 11 12 R1 R2 R3 T1 T2 T3
node A1教程/build_a1.js student A1教程/out/西班牙语A1教程_学生用书.docx
node A1教程/build_a1.js teacher A1教程/out/西班牙语A1教程_教师用书.docx
python A1教程/tools/make_tracks.py . A1教程 A1教程/audio_out 识别模型目录 01 02 03
```
