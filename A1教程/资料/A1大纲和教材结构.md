## 1. CEFR 的 A1 能力描述

### 1.1 总体描述（Global scale）

- **A1 总体描述（中文概括）**：能听懂和使用为满足具体需要而说的熟悉的日常用语和非常基础的短语；能介绍自己和别人，能就个人信息（住在哪里、认识谁、有什么东西）提问和回答；只要对方说得慢、说得清楚并愿意帮忙，就能进行简单的交流。关键词：*familiar everyday expressions*、*very basic phrases*、*satisfaction of needs of a concrete type*、*talks slowly and clearly and is prepared to help*。[S2]（已核实：官方原文）
- **2020 年增补卷对 A1 的改动**：增补卷增设了 **Pre-A1** 段（A1 的一半）；加强了 A1 和 C 级的描述；增加了在线互动（online interaction）、使用远程通讯、对创意文本的反应等量表；新设语音控制量表（分为整体、发音、韵律三部分）；把调解（mediation）扩展为 19 个活动量表和 5 个策略量表；描述语改为性别中立，并兼顾手语（*modality-inclusive*）。[S1 第 1–2 章、“Summary of changes”]（已核实：官方原文）
- **对本书的意义**：零起点成人的头两三个单元其实处在 Pre-A1 到 A1 之间。Pre-A1 的描述语（例如在有图片和手势支持时听懂非常简单的问题，认读数字、价格、日期和星期几）可以用作第 1–3 单元的目标。[S1 p.48 等]（已核实：官方原文）

### 1.3 语言能力（A1）

- **语言范围**：只掌握关于个人信息和具体需要的非常基础的简单表达；能在单句中用一些基本结构，常有省略。[S1 p.130]（已核实：官方原文）
- **语法准确性**：只能有限地控制已学过的几种简单语法结构和句型。[S1 p.132]（已核实：官方原文）
- **词汇**：掌握与具体情境相关的基本词语和短语。[S1 p.131]（已核实：官方原文）
- **语音控制**：熟悉对象能费点力听懂其有限的词语和短语；能正确发出有限的音，以及简单熟悉词语的重音；在指导下能模仿目标语的音；韵律受母语影响很大，需要对方配合。[S1 p.135–136]（已核实：官方原文）
- **正字法**：能抄写熟悉的词语和短语；能拼出自己的地址、国籍等个人信息；能使用基本标点（句号、问号）。[S1 p.136]（已核实：官方原文）
- **社会语言得体性**：能用最简单的日常礼貌形式（问候、告别、介绍、请、谢谢、对不起）建立基本的社交接触。[S1 p.136]（已核实：官方原文）
- **流利度**：只能说很短的、孤立的、大多是背好的话语，常停下来找词。[S1 p.142]（已核实：官方原文）
- **多元文化库**：能意识到数字写法、距离、报时等方面存在不同的做法，但在简单交际中用起来可能还有困难。[S1 p.124]（已核实：官方原文）

### 1.4 自评表（Self-assessment grid，S1 附录 2，p.177–180）中的 A1 格（中文概括）

- 听：说得慢而清楚时，能认出关于自己、家庭和身边具体事物的熟悉词语和非常基础的短语。
- 读：能看懂告示、海报、商品目录等上面熟悉的名字、词语和非常简单的句子。
- 口头互动：对方愿意放慢语速重复或换个说法并帮自己组织语言时，能进行简单交流；能就最直接的需要或非常熟悉的话题问答简单问题。
- 口头表达：能用简单的短语和句子描述自己住在哪里和认识的人。
- 书面表达：能写简单的孤立短语和句子。
- 在线互动：能发简短的问候帖并作很简单的回应；能完成很简单的网购，填写个人信息。
- 调解：能转述标牌、通知、海报、节目单这类短小文本中简单、可预见的信息。

（以上已核实：官方原文 [S1]。2001 年版自评表“写”一栏的 A1 格通常被引用为“能写简短明信片、能在酒店登记表上填个人信息”，本次没有读到 2001 年版原表（未核实）。S1 第 2.6 节提到，2001 年版第 3.5 节描述过一个低于 A1 的水平，包括填写简单的个人信息表格、写简短明信片，增补卷把这一档定名为 Pre-A1（已核实：官方原文）。）

**对编写的直接含义**：CEFR 的 A1 在“时间”方面只要求会用“下周”“上周五”这类**词汇化短语**表示时间，不要求掌握过去时形态（见上表“信息交换”）。这与 PCIC 把过去时都放在 A2 的做法一致（见 2.2）。

## 2. 塞万提斯学院《课程计划》（PCIC）A1 内容清单

**总体情况**：PCIC（《Plan curricular del Instituto Cervantes. Niveles de referencia para el español》，2006）把内容分为 13 个清单：1 目标、2 语法、3 发音和韵律、4 正字法、5 功能、6 语用策略、7 语篇类型和文本、8 一般概念、9 具体概念、10 文化参考、11 社会文化知识和行为、12 跨文化技能和态度、13 学习策略。语言类清单（2–9）按 A1–A2、B1–B2、C1–C2 三页给出，**语法、功能、正字法、概念等页面把 A1 和 A2 分成两栏**；**发音清单则把 A1–A2 合在一起，不再细分**；文化参考和社会文化两项**不按级别**，而按“接触、深化、巩固”三个阶段（fase de aproximación / profundización / consolidación）排列。[S3–S11 及 PCIC 索引页（Wayback 2024-12-06）]（已核实：官方原文）

DELE A1 官方指南写明，DELE 考试的语言内容范围就是《西班牙语参考水平》（NRE，即 PCIC）各清单。[S24]（已核实：官方原文）

### 2.1 语法（Gramática）A1 栏主要项目 [S3]（已核实：官方原文）

下表是 A1 栏的全部大项（中文概括，例词是常用词，不是 PCIC 例句的抄录）：

| 类别 | PCIC A1 内容 |
|---|---|
| 名词 | 专有名词（人名、姓不加冠词；国名一般不加冠词，El Salvador 例外；称谓 señor/señora + 姓）；表时段的普通名词（mañana、tarde、noche）；**性**：-o 阳 / -a 阴，以其他元音或辅音结尾的词，缩略词 la foto / la moto / la radio，异根词（padre/madre）；**数**：元音后加 -s，辅音后加 -es，以 -s 结尾的单音节或末音节重读词加 -es |
| 形容词 | 品质形容词作定语和表语；常用国籍形容词；性数变化（alto/alta，español/española，以辅音结尾的不变）；后置；用 muy 表示绝对最高级 |
| 冠词 | 定冠词 el/la/los/las 及缩合形式 al/del；不定冠词 un/una/unos/unas（第一次提到的事物）；gustar 句中主语名词必须带冠词；haber（hay）一般不与定冠词连用，estar 可以；hay + 光杆名词 |
| 指示词 | este/ese/aquel 全套形式，中性 esto/eso/aquello；空间远近；¿Qué es eso? |
| 物主词 | 前置非重读式 mi/tu/su（及复数），nuestro/vuestro 的性数变化，su 的多义；不能与冠词连用，不能单独使用 |
| 数量词 | **基数词**（含百位、千位，如“两百”的性变化）；**序数词到第十**；poco、mucho、bastante；también / tampoco |
| 代词 | 主格人称代词全套（含 usted/ustedes；拉美以 ustedes 代替 vosotros；voseo 地区的 vos）；主语一般省略，对比时出现；**gustar 只要求第一人称 me**（Me gusta…）；**se 作自复代词**（levantarse、peinarse）；关系代词 que（限定性）；疑问词 qué、quién/quiénes、cuánto/a/os/as |
| 副词 | 地点 aquí/ahí/allí（拉美 acá/allá），时间 ahora/hoy/mañana，数量 poco/mucho/bastante，**muy 与 mucho 的对立**，bien/mal，sí/no，también/tampoco；疑问副词 dónde、cómo；por qué 与 porque 的区别 |
| 动词 | **陈述式现在时：规则动词全套，加上 ser、estar、haber、ir 的不规则变位**；现在时表“此刻”和“持续状态”；不定式（作主语、宾语：Me gusta…、Quiero…）；规则过去分词作形容词（estoy cansado） |
| 句法 | 名词短语内部一致（限定词—名词—形容词）、主谓一致、表语一致；ser 表身份、类别（国籍、职业）、星期；estar 表位置和 bien/mal；直接宾语（无 a 的人和物）；SVO 基本语序；陈述句、一般疑问句、特殊疑问句；hay 无人称句 |
| 复句 | y、ni、o、pero、uno… otro…；不定式宾语从句（Quiero + 不定式）；**creer que + 陈述式**；que 引导的限定性关系从句；**porque**（原因，后置）；**para + 不定式**（目的） |

**PCIC A1 栏里空着的项目**（PCIC 把它们放到 A2 或以后）[S3]（已核实：官方原文）：

- 9.2（陈述式其他时态）、9.3 命令式、9.4.2 副动词，A1 栏都没有内容；
- 现在时的**元音变化不规则**（e>ie、o>ue、e>i）、**辅音不规则**和正字法变化，以及 saber、dar，都在 A2；
- **现在完成时（pretérito perfecto）在 A2**（语法清单 9.1.6：haber 变位、规则和常用不规则过去分词，搭配 hoy、este año、ya、todavía no 等时间标记）；**简单过去时（indefinido）和过去未完成时（imperfecto）也都在 A2**；
- **迂说法（perífrasis）都在 A2**：ir a + 不定式、acabar de、empezar a、volver a、poder + 不定式、tener que / hay que + 不定式、estar + 副动词；
- **直接宾语代词 lo/la/los/las、第三人称间接宾语 le/les**，以及 encantar、interesar、doler，都在 A2；
- **比较级**（más/menos/tan… como，mejor/peor/mayor/menor）在 A2；
- 现在时表习惯（Siempre…）和表将来（Mañana voy…）的用法在 A2 栏列出。

**说明**：PCIC A1 的语法栏只明确列出 ser、estar、haber、ir 四个不规则动词，但同一级别的功能清单里已经把 tengo（年龄）、quiero、prefiero、sé、conozco 作为**固定说法**使用（见 2.2）。也就是说，PCIC 允许 A1 把这些高频形式当词汇块学，到 A2 再系统讲变位规律。[S3、S4]（已核实：官方原文；“当词汇块”的解释是本文作者的归纳）

> **结论（回答“现在完成时放在哪一级”）**：PCIC 把现在完成时放在 **A2**，A1 不教任何过去时态；A1 只用 ayer、el lunes 这类时间词指过去（一般概念清单 4.2.2）。[S3、S8]（已核实：官方原文）
> 但不少标着 A1 的海外教材在最后一两个单元提前教现在完成时或简单过去时（见第 3 节），这是教材的选择，不是 PCIC 的要求。

### 2.2 功能（Funciones）A1 栏主要项目 [S4]（已核实：官方原文）

| 大类 | A1 功能（中文概括；括号内是 PCIC 列出的典型说法类型） |
|---|---|
| 1 提供和索取信息 | 指认人和物（Yo…，este/ese/aquel，esto）；询问人（¿Quién es? ¿Cómo te llamas?）、物（¿Qué es esto?）、地点（¿Dónde…?）、国籍（¿De dónde eres?）、职业（¿A qué te dedicas?）、数量（¿Cuántos…?）、时间（¿Qué hora es?）、原因（¿Por qué…?）；给出个人信息、地点、时间、目的（para + 不定式）、原因（porque…）；纠正别人的说法；确认（…, ¿no?）。**“描述”（1.6）和“叙述”（1.7）A1 栏空着** |
| 2 表达观点、态度和知识 | 问看法（¿Y tú?）、表达看法（Creo que…）；评价（muy/bastante bien/mal，Es muy/un poco + 形容词）；同意和不同意（Yo también / tampoco，No, no es…）；Sí, pero…；不确定（Creo que…，Quizá，Es posible）；问和表达知道或不知道（¿Sabes…? / Sé… / No conozco…）；**问和表达能力（¿Sabes nadar? / Sé + 不定式）** |
| 3 表达喜好、愿望和感受 | **表达喜好：(No) me gusta (mucho) + 名词 / 不定式**（注意：“问别人的喜好”3.1 在 A1 栏空着，¿Te gusta…? 列在 A2）；问偏好（¿Té o café?）、表达偏好（Prefiero…）；表达愿望（Quiero + 名词 / 不定式）；**问和表达计划：用现在时 + 表将来的时间词**（Esta noche…，El domingo…；ir a + 不定式在 A2） |
| 4 影响对方 | 用省略动词的礼貌形式下指令（¡Silencio, por favor! Más despacio, por favor）；¿Puedes repetir?；要东西（Un café, por favor）；回应请求（Sí, sí / No）；拒绝允许（No, lo siento）；提供和邀请（¿Quieres un…? ¿Un café?）；接受和拒绝（Sí, gracias / No, gracias） |
| 5 社交 | 问候和回应（Hola，Buenos días / tardes / noches）；称呼（Hola + 名字，Señor/Señora + 姓，Por favor）；介绍别人（Este es…）和自我介绍（Soy… / Me llamo… + 职业）；回应介绍（Encantado）；道歉（Perdón）；感谢（(Muchas) gracias）；表示哀悼（Lo siento）；祝酒（¡Salud!）；祝贺（¡Felicidades!）；告别（Adiós，Hasta mañana，Hasta el + 星期几，Chao） |
| 6 组织话语 | 引起注意、回应；当面问某人（¿El Sr. + 姓, por favor?）及回答（Sí, soy yo）；表示在听（Sí）；请人安静；用非语言方式（看表、收拾东西）结束谈话 |

### 2.3 语篇类型（Géneros discursivos）A1 [S7]（已核实：官方原文）

- **口头**：关于人和地点的非常简短的非正式面对面对话（理解和产出）；面对面的事务性对话（简单购物、问地点、问路）（理解和产出）。
- **书面**：车票、钞票（理解）；酒店、商店、超市、市场的告示和商场楼层指引（理解）；双语词典（理解）；**个人信息表格（理解和产出）**；旅游信息单和小册子（理解）；营业时间表和公共交通时刻表（理解）；当日套餐、旅游套餐、快餐店菜单（理解）；非常简短的便条（理解）；**简短的明信片和电子邮件（理解和产出）**。
- **宏观功能（描写）**：A1 列出描写人（外貌、衣着、性格）、物、地点（住房的房间和家具）的典型顺序：先锚定对象，再列出特征；用现在时和形容词性过去分词、空间和时间指示词。叙述（3.4）A1 没有内容。

### 2.4 话题概念（Nociones específicas）A1 主要词汇领域 [S9]（已核实：官方原文）

（中文概括主要词汇范围，不逐词照录）

1. 个人身体：常见身体部位；外貌（高矮胖瘦、头发和眼睛的颜色、胡子、眼镜）；起床、洗澡等动作。
2. 性格：友好/不友好、聪明、勤劳、开朗、严肃、害羞、好交际等基本形容词。
3. 个人身份：姓名（两个姓）、地址（街道、门牌、楼层、邮编、邮箱）、电话和手机、出生地和出生日期、国籍、年龄、性别、婚姻状况、职业；证件（护照、身份证、驾照）；随身物品（钥匙、钱包、包、表、手机、眼镜、电脑、信用卡）。
4. 人际关系：核心家庭和亲属称谓（父母、子女、兄弟姐妹、叔舅、侄甥、祖辈、孙辈、堂表亲）、伴侣、朋友、上司、同事；聚会。

6. 教育：中学、大学、课、图书馆、老师、学生、课程表、考试；**课堂用语**（练习、单元、页码、两人一组、听说读写、重复、做作业）；文具和教室家具。
7. 工作：常见职业；工作地点；有工作/失业；假期。
8. 休闲：旅行、读书看报、看电视电影、听音乐、去酒吧/电影院/博物馆/公园；唱歌跳舞；跑步、游泳、滑雪、踢足球、打篮球和网球。
9. 媒体和通讯：电视、广播、电话、电子邮件；写明信片和信；网络（@、点、网页）。
10. 住房：房屋类型（独栋、公寓、单间）；房间名称；电梯、楼梯、阳台、花园；新旧、朝外/朝内、地段、交通方便；基本家具和电器。
11. 服务：邮局（信、明信片、信封、邮票）；银行（钱、欧元、分、信用卡、换钱）；医院、医生、护士；警察、消防员。
12. 购物：超市、市场、商店、出口、问询处；基本服装（裤子、牛仔裤、裙子、衬衫、毛衣、鞋、包）；价格、付款、刷卡。
13. 健康卫生：生病；去医院、看医生；药店；洗脸、洗手、刷牙、洗澡。
14. 旅行和交通：证件和行李；地图；单程票/往返票；度假、去海边/山区/乡下；酒店（单人间/双人间、带浴室等）；街道、机场、港口、火车站、地铁站、公交站；步行、坐车、坐火车、坐地铁、坐飞机、坐船。
15–19. 经济（贵/便宜）；数字和电脑；国家、首都、总统、国王；艺术（电影、戏剧、音乐、博物馆、展览、教堂）；主要宗教的名称。
20. 地理和自然：太阳；国家、城市、村镇、首都；东南西北；山、海、河、海滩；城市设施（市中心、广场、公园、商场、医院、学校、博物馆、车站）；乡村；**四季、下雨、下雪、冷、热、晴、刮风、天气好/不好**；动物、植物、花、树。

**一般概念（Nociones generales）A1 补充** [S8]（已核实：官方原文）：存在（hay、tener，如“城里有/没有地铁”）；在场（estar）；品质（ser）；事件时间（La clase es el lunes）；基数词和序数词（到第十）；más/menos、muy/mucho、bastante/poco；大小、长短、高矮、快慢；冷热（hacer frío/calor）；位置（estar；cerca/lejos、左右、旁边、尽头、中间、在…之间）；方向（直走、左转、右转）；**移动（ir、volver、venir、llegar、salir、entrar；a pie / en coche / en metro…）**；来源（ser de）；**钟点**（含“几点差几分”的说法及拉美说法）；星期、周末、月份、季节、早中晚、mañana/tarde/noche；过去用 ayer、el + 星期几、en + 月份；将来用 mañana、el + 星期几、现在时。

### 2.5 文化参考和社会文化知识（不按级别，“接触阶段”为最浅一层）

- **PCIC 的分级原则**：文化参考和社会文化知识两项按“接触—深化—巩固”三个阶段排列，导言明确说这三个阶段与语言部分的 A/B/C 等级**没有系统对应关系**；分级依据是“普遍性”和“可及性”：最有国际知名度、最容易接触到的内容放在接触阶段。使用者可以每个 A/B/C 阶段对应一个文化阶段，也可以按主题分配。[S10 导言]（已核实：官方原文）
- **文化参考·接触阶段举例**（中文概括）[S10]（已核实：官方原文）：西语国家的气候差异（有的国家没有四季、有雨季、不下雪；摄氏和华氏）；知名地理标志（安第斯山、亚马孙河、的的喀喀湖、巴拿马地峡等）；人口和原住民的重要性；政体和国家象征（国旗、国歌）；各地代表性菜肴和节日（例如西班牙的海鲜饭、凉菜汤，墨西哥的亡灵节）；首都和知名城市及其标志性地点；货币和度量衡；教育阶段和知名大学；主要报刊、电视台和广播；交通（大机场、航空公司、铁路、地铁标志、泛美公路）；主要宗教；官方语言和语言机构（RAE、各国语言学院）；重大历史节点和人物；有国际影响的作家、音乐人、电影人、舞蹈（探戈、萨尔萨、昆比亚）；绘画名作和大博物馆。
- **社会文化知识·接触阶段举例**（中文概括）[S11]（已核实：官方原文）：常见姓名、双姓（父姓和母姓）、婚后保留原姓、常见昵称；证件（护照、身份证、居留证、学生证）；家庭结构；**作息时间**（工作日安排、三餐时间、商店营业时间、学校作息、按时段使用 buenos días / buenas tardes / buenas noches）；三餐习惯、tapa 和 merienda、上菜顺序（前菜、第一道、第二道、甜点）、面包的地位、餐桌用语、酒吧和餐馆的点餐方式；问候方式（握手、贴面）、称呼、身体距离；与陌生人搭话和打招呼的方式。

### 2.6 发音和韵律（A1–A2 合并清单）[S5]（已核实：官方原文）

- **发音基础**：西语的发音特点（元音清晰、不弱化；非重读元音音色不变；倾向开音节；没有塞擦化等）；“口音”的概念和西语世界的发音差异。
- **语调**：语调单位和标点（句号、逗号、问号、感叹号）的对应；陈述句的降调；**一般疑问句与特殊疑问句的语调区别**（如 ¿Quién es tu profesor? 与是非问句）；问候和礼貌用语的语调。
- **音节和重音**：音节结构（CV、CVC、CCV、VC 等，倾向开音节）；**跨词重新分音节**（如 dos amigos 读作 do-sa-mi-gos）；重音的性质，重音可以区别词义（caso / casó）；尾重词、倒数第二音节重读词、倒数第三音节重读词；动词现在时的重音规律（多在倒数第二音节，vosotros 形式例外）。
- **节奏和停顿**：以音节计时为主；必须停顿和可停顿的位置；填充停顿（eeee、mmm、pues、bueno）。
- **元音**：五个元音及其舌位；二合元音、三合元音和元音分读。
- **辅音**：**塞音与擦音、清音与浊音的对立**（例如 p/b、t/d、k/g 的最小对立）；ñ；ch；y 和 ll 的合并（yeísmo）；**l 与 r 的对立（pelo / pero）**；**单击颤音和多击颤音的对立（pero / perro）**；j（[x]）；z 的齿间音和拉美、西班牙南部的 seseo。
- **连音**：元音合并（sinalefa，如 vivo en…）；词组内部不停顿（冠词+名词、介词+名词、迂说法等连读）。

### 2.7 正字法 A1 [S6]（已核实：官方原文）

字母表和字母名称（含复数说法）；**一个音对应多个字母（b/v 都读 /b/；ge、gi 和 j 都读 /x/；k、qu、c+a/o/u 都读 /k/）和一个字母对应多个音（w、y）**；双字母 ch、ll；拼读；元音可带重音符号；al、del；连词 y 在 i 前变 e，o 在 o 前变 u；各辅音字母的写法；大写规则（双字母只大写第一个字母，大写字母也要标重音）；音节划分中不可分的辅音组合；数字、小数（用逗号）、日期、钟点的写法；**重音符号：疑问词和感叹词带重音；区别性重音 qué/que、él/el、té/te、sé/se、tú/tu**；标点：**西语问号和感叹号必须成对使用**（开头倒置的 ¿ ¡）；逗号用于列举；冒号用于列举和钟点；括号；引号标外语词；连字符用于复姓；对话中的破折号；斜线（profesor/a）；常用缩写（Sr.、Sra.、D.、Ud.、tfno.、c/）。

## 4. DELE A1 的结构（简要，供单元练习题型参考）

DELE A1 现行为 **2020 年版**，总分 100，四项考试各 25 分。[S24]（已核实：官方原文）

| 考试 | 时长 | 任务和题型（中文概括） |
|---|---|---|
| 1 阅读理解 | 45 分钟，4 个任务，25 题 | ①读一封短信或电子邮件（150–175 词），三选一，最后一个选项是图片（5 题）；②九条很短的便条、广告、标牌，选六条与短句配对（6 题）；③九条带图的短广告或说明，选六条与人物需求配对（6 题）；④读一篇说明性或通知类文本（175–210 词），三选一（8 题） |

| 4 口语表达与互动 | 10 分钟，另有 10 分钟准备 | ①**自我介绍**（1–2 分钟：姓名、年龄、国籍等）；②**就身边话题做简短陈述**（2–3 分钟，例如日常生活、认识的人、物品、地点、学业）；③**与考官对话**（3–4 分钟，回答关于前面内容的问题，并向考官提两个准备好的问题）。一位考官主持，一位评分；评分量表分“语言运用”和“任务完成”两项，0–3 分 |

### 5.1 有文献依据的难点

### 5.2 本书的经验性建议（暂无可靠文献，作为编写原则）

- **b/v**：西语里 b 和 v 读音相同（PCIC 正字法清单明确两个字母对应同一个音 /b/ [S6]，已核实），但学过英语的学生常把 v 读成英语的唇齿音，需要在第 1 单元就说明；同时要教元音之间的浊擦音变体（如 *cabo* 中的 b），PCIC 也把塞音和擦音的区别列入 A1–A2 [S5]。
- **颤音 r/rr**：成人学会多击颤音往往需要几周到几个月，建议每单元的语音栏目都有 r/rr/l 的最小对立练习，评价时以“能区分、能被听懂”为目标，不要求一开始就发出标准的多击颤音。
- **重音**：汉语有声调而没有西语这种词重音规律，学生容易把每个音节读得一样重，或用声调代替重音。从第 1 单元起，在生词表中用下划线或加粗标出重读音节，并尽早讲重音符号规则。
- **性数一致**：汉语名词没有性和数的变化，建议用颜色标记阴阳性，并把“冠词+名词+形容词”作为一个整体反复操练。
- **ser/estar**：两个词汉语都可译为“是/在”，混用很普遍。A1 只教 PCIC 规定的核心用法：ser 用于身份、国籍、职业、性格、时间，estar 用于位置和 bien/mal；第 10 单元前后再做一次对比小结，把 estar + 形容词表状态（cansado、contento）作为 A2 预习。
- **动词变位**：中国学生的记忆能力强，但口头即时提取慢。建议用“变位表 + 高频句型块（Me llamo… / Vivo en… / Tengo… años）+ 限时口头操练”结合的办法，并控制每单元新的不规则动词数量。
- **语调和疑问句**：PCIC 把一般疑问句的语调列为 A1–A2 内容 [S5]。中国学生常用陈述语调说疑问句，或按汉语习惯在句末加语气词，需要专门练习。
- **课堂文化**：中国学生习惯“先讲解后练习”，对“先观察、自己归纳”的交际法流程可能不适应。建议学生用书保留归纳活动，但每个归纳活动后马上给出中文讲解框；教师用书提供“讲练结合”的替代教学路线。

## 6. 给本书编写者的建议

### 6.1 总体原则

1. **以 PCIC A1 为底线，以 A1 教材的通行做法为上限**：PCIC A1 栏的语法、功能和词汇必须全部覆盖；四套海外教材普遍提前教的 A2 项目（元音变化不规则动词、gustar 全人称、ir a + 不定式、命令式少量形式、现在完成时少量用法），本书可以教，但在学生用书中统一标为“A1+ 拓展”或“A2 预习”，不纳入 A1 核心考核。
2. **按 CEFR 2020 增补卷写可检测的“我能……”目标**：每单元 4–6 条，写进单元首页和自我评估；第 1–3 单元可以借用 Pre-A1 的描述语。
3. **中文讲解，西语输入和输出**：语法框、语音说明、文化说明用中文；课文、例句、练习指令用西语（第 1–4 单元的指令可附中文）。
4. **每单元都有一个任务和一个调解小活动**：任务产出可以检查的作品；调解活动按 CEFR A1 调解描述语设计，用中文或西语转述标牌、菜单、通知、日程中的简单信息（例如把校园通知的要点用西语转告外国同学，或把西语海报的时间、地点、价格用中文告诉朋友）。
5. **文化采用“西语世界＋中西对比”**：按 PCIC 文化参考“接触阶段”选材，同时覆盖西班牙和拉美，避免只讲西班牙；每单元有一个“比一比”问题。
6. **原创要求**：课文、对话、人物、插图、练习一律自编；单元标题和顺序不照搬任何教材（下面的草案已与第 3 节四套教材对照过，标题都是自拟的）。

### 6.2 建议学时

12 个单元，每单元 8–10 学时，加上第 4、8、12 单元后的复习和阶段测试，共约 **110–130 学时**，相当于中国高校西语专业第一学期精读课，或成人业余班两学期。（建议，参照 S12、S15、S22 中的学时说明）

**草案说明**：

- **与 PCIC 的对照**：PCIC A1 的语法要点（ser、estar、haber/hay、ir、规则现在时、冠词、性数、物主词、指示词、疑问词、数字、序数词到第十、自复动词 se、me gusta、porque、para + 不定式、que 关系从句、creer que）分布在第 1–11 单元；功能要点（问候、介绍、个人信息、观点和同意、喜好、能力、偏好、愿望、用现在时谈计划、点餐和要东西、邀请、感谢、道歉、告别）也全部覆盖。
- **与海外教材的区别**：本草案保留了第 3.5 节总结的通用顺序（身份 → 身边环境 → 日常 → 消费 → 城市 → 计划 → 回顾），但单元划分、标题、情境（中国大学校园、宿舍、食堂、微信群这类聊天群）、语音线索（针对中国学生的对比训练）、每单元的调解活动和中西对比都是本书原创；能力（saber + 不定式）按 PCIC 放在 A1 的喜好单元，现在完成时只作为第 12 单元的有限预习，与 Aula（最后单元集中讲现在完成时）和 NEEM、Prisma（教简单过去时）的处理都不同。
- **可选扩展**：如果学时更多，可以加一个“身体与健康”单元（doler、看病，PCIC A2）或“工作与职业”单元。

### 6.4 学生用书单元的推荐组成（每单元约 12–16 页）

1. **单元首页**：主题图片，“我能……”目标（4–6 条，按 CEFR 写），本单元任务预告。
2. **情境输入 A、B**：两段自编的短对话或实用文本（表格、聊天记录、广告、日程），配录音；先做理解活动。
3. **词汇工作坊**：主题词汇和常用搭配，图示配合中文释义，标出重读音节和名词的阴阳性。
4. **语法发现与讲解**：先让学生观察例句、自己填出规律，再给出中文讲解框和表格；标注 PCIC 级别（A1 / A1+）；列出中国学生的常见错误提示。
5. **练习**：控制性练习（变位、配对）→ 半控制练习（替换对话）→ 交际练习（信息差、角色扮演、调查）。
6. **语音与拼写**：每单元一个针对中国学生的重点（元音、重音、r/rr/l、清浊塞音、b/v 和擦音变体、语调、连读、拼写对应），配最小对立词练习。
7. **读写园地**：PCIC A1 列出的实用文体（表格、便条、明信片、聊天消息、广告、菜单、时刻表），读一篇、写一篇（30–40 词）。
8. **文化窗口**：西语世界的一个文化点和一个“比一比”问题（中国做法与西语国家做法）。
9. **调解小活动**：西语转中文或中文转西语的简单信息转述。
10. **单元任务**：小组或个人完成的综合任务，产出作品，可放进学习档案。
11. **自我评估**：“我能……”自评打勾，加 DELE A1 题型小测（5–10 分钟）。
12. **单元小结**：语法要点表和西中对照词汇表（附录音）。

全书附录：语法总表、动词变位表（规则动词，ser、estar、ir、tener、hacer 等）、西中词汇总表、听力原文、练习答案（或放在练习册里）。每 4 个单元后安排一个复习单元。

### 6.5 教师用书的推荐内容

1. **总体说明**：教学理念（行动导向和任务型教学，同时考虑中国课堂“讲练结合”的习惯）；全书目标与 CEFR A1、PCIC A1、DELE A1 的对照表；每单元的课时分配方案（每周 4、6、8 学时三种）。
2. **逐单元教学指导**：
   - 单元目标和重难点；**中国学生常见错误预警**（语音、冠词、性数一致、ser/estar、变位）；
   - 分步教学建议（导入—呈现—练习—产出—评价），每步的时间、课堂组织方式和板书示例；
   - **两种教学路线**：“归纳式”（交际法原样）和“讲练式”（先讲后练），以及快班和慢班的增删建议；
   - 语音教学要点：发音部位说明、最小对立词清单、纠音方法；
   - 文化背景补充材料（教师参考，不进学生用书）；
   - 全部练习答案和听力原文。
3. **可复印或可投影的活动卡**：信息差卡片、角色卡、游戏卡、调查表、任务评价表。
4. **评估工具**：每单元一份 10–15 分钟的小测；三次阶段测试和一套期末试卷，均采用 DELE A1 题型（题目自编）；口语和写作评分量表（参照 DELE A1 的 0–3 分整体量表和“语言运用、任务完成”两个维度改写成中文）；学习档案的评价标准。
5. **附录**：课堂用语（西中对照）、中国学生常见偏误清单、推荐的真实语料和网络资源类型、参考文献（CEFR 2020、PCIC、DELE A1 指南等）。
