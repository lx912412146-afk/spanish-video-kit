# 《西班牙语 A1 教程》单元规划

面向中国大学生和成人零起点学习者。学生用书 12 个单元＋3 个复习单元，教师用书逐单元对应，另有 3 套阶段测试。约 110–130 学时（每单元 8–10 学时）。依据 CEFR A1 和塞万提斯学院《课程计划》（PCIC）A1（资料见 `资料/A1大纲和教材结构.md`）；编排思路参考海外交际法教材的通行做法（导入 → 输入 → 观察归纳 → 练习 → 任务 → 文化 → 自评），但单元划分、标题、人物、课文、练习全部原创。

## 学生用书每单元的组成（约 12–16 页）

1. **单元首页**：标题（西／中）、“我能……”目标 4–6 条、本单元任务预告。
2. **导入**：一两个热身活动（看词、配对、说一说）。
3. **课文一**（对话，录音）→ 理解练习 → 生词表。
4. **词汇**：主题词汇表和练习。
5. **语法**：先观察例句（小归纳活动），再给中文讲解框和表格，标 A1 / A1+；中国学生常见错误提示；练习（控制 → 半控制）。
6. **交际**：功能句型表（西／中）→ 两人对话、信息差、角色扮演。
7. **课文二**（实用文本：表格、便条、聊天记录、广告、菜单、时刻表、邮件等，或第二段对话，有录音）→ 理解练习。
8. **听力**：1–2 个听力练习（只给题，录音原文在书后附录）。
9. **语音和拼写**：讲解＋跟读录音＋练习。
10. **读写**：读一篇短文，写一段 30–40 词的短文（便条、消息、明信片、表格）。
11. **文化窗口**：一个西语世界的文化点（中文讲，关键词西语）＋“比一比”问题（和中国比较）。
12. **调解小活动**：把一则西语标牌、菜单、通知的要点用中文转告，或把中文信息用西语转告。
13. **单元任务**：小组或个人完成的综合任务。
14. **自我评估**：“我能……”自评表＋5–10 分钟的 DELE A1 题型小测。
15. **单元小结**：语法要点表＋本单元生词总表（这张表程序会收进书后的总词汇表，并生成词汇跟读录音）。

复习单元（约 4–6 页）：语法和词汇复习练习、DELE A1 题型小测（读、听、写、说各一部分）、学习档案提示。

全书附录（程序生成为主）：A 语法总表（编写）、B 动词变位表（编写）、C 西中词汇总表（程序从各单元生词总表生成）、D 课文译文和听力原文（程序从录音稿生成）。

## 教师用书

- 总体说明（编写）：教学理念、全书目标与 CEFR / PCIC / DELE A1 的对照、课时方案（每周 4、6、8 学时）、录音使用说明、中国学生常见难点总览。
- 逐单元（12＋3 复习单元）：教学目标和重难点；课时安排；按学生用书顺序的分步教学建议（导入—呈现—练习—产出—评价，含时间、组织方式、板书示例；“归纳式”和“讲练式”两种路线；快班慢班建议）；语音教学要点；中国学生常见错误预警；文化背景补充；补充活动（可复印的卡片、角色卡）；**全部练习答案**；单元小测参考答案；本单元全部录音稿（程序附上）。
- 阶段测试 3 套（第 1–4、5–8、9–12 单元后），DELE A1 题型、题目自编，含听力（有录音）、答案、口语和写作评分量表（自编，参照 DELE A1 的 0–3 分整体量表思路，写明是本书的量表）。
