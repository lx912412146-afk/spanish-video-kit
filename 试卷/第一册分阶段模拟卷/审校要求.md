# 分阶段模拟卷审校要求

你是独立审校，没有参与出这套卷。目录 `EX` 同 `EX/sets/出题要求.md`。先读：出题要求 `EX/sets/出题要求.md`、课程大纲 `EX/sets/课程大纲.md`、样板 `EX/试卷.md`（看格式即可），再把要审的卷子从头到尾读完、每道题自己做一遍。

## 逐项检查

1. **超范围**：把卷子里（短文、对话、题干、选项、写作题目、范文、语法填空提示）出现的每个动词形式和语法结构对照课程大纲和本卷范围规则，找出本卷最后一课以后才学的东西。常见的：第 1–4 课卷里出现 tener、规则动词变位、este/esto；第 1–12 课以前的卷里出现自复动词、钟点（第 11 课前）、gustar（第 16 课前）、命令式（第 15 课前）；任何一卷出现过去未完成时、副动词、acabar de、lo que、现在完成时、将来时、虚拟式、否定命令式。
2. **西语错误**：重音符号、¿¡、性数一致、动词变位、介词搭配、冠词、语序、不地道的说法。
3. **答案**：每道选择题是否只有一个正确选项；答案表的字母是否就是那个选项；听力答案在原文里能找到依据，干扰项确实错；阅读答案在短文里有依据；完形每空放进四个选项，是否恰好一个在语法和语义上都通；语法填空是否只有一个正确答案、提示词给得对；「考点」一栏说得对不对。
4. **前后一致**：考试说明、知识点覆盖表里说的题号和内容是否和实际题目相符；覆盖表是否每课都有题；写作词数要求、范文标注的词数、实际词数是否一致。
5. **听力原文**是否适合语音合成：没有缩写、括号、引号、中文；数字写成西语单词；每句不太长；人名只用西语名字（地名可用 Beijing、Shanghai）。
6. **原创**：没有照抄课本课文，没有和样板卷重复的短文或情景。

## 改法

发现的问题**直接在卷子里改**，改动越小越好：只改有问题的词句，不重写整篇，不改动没问题的题。改了题目要同步改答案表、考点、覆盖表和听力原文（听力题干和原文要对得上）。改完跑格式自检：`python EX/check_paper.py <卷子路径>`，到 ✓ 为止。

最后回报（300 字以内）：按「超范围 / 西语错误 / 答案问题 / 不一致 / 其他」分类列出改了什么（题号 + 原来 → 现在）；拿不准、没改的地方单独列出。
