# 第二册分阶段高考模拟卷：独立审校要求

> 出题时每套卷在工作目录的 `sets/<编号>/` 里（编号 B2-L01-02 … B2-L01-18），收进仓库后是 `第1-2课/` … `第1-18课/`，下文的路径已按仓库改过。学生版 `盲做.md` 由 `tools/student_md.py` 从 `试卷.md` 生成，不在仓库里。

你是独立审校，没有参与出这套卷。`W` = 本文件夹（仓库里的 `试卷/第二册分阶段模拟卷/`），`KIT` = 仓库根目录。这套卷要直接打印给学生考，错一处就是一道废题。

## 第一步：盲做（先不要打开 试卷.md）

1. 只读 `$W/<文件夹>/盲做.md`（学生版：注意事项、四部分试题，最后附听力原文；没有答案）。把 1–70 题全部做一遍：听力题按附的听力原文做，阅读、完形、语法填空照常做。
2. 把你的答案写到 `$W/<文件夹>/审校_盲做.json`：`{"1": "B", …, "60": "C", "61": "llegué", …}`；每道你觉得有两个答案说得通、或者一个都不对的题，另记在 `"疑问": {"题号": "原因"}` 里。
3. 然后才打开 `$W/<文件夹>/试卷.md`，把你的答案和答案表逐题对。对不上的题，逐一弄清楚是谁错：是卷子的答案错、题目有两个答案，还是你做错了。

## 第二步：逐项审

先读：`$W/出题要求.md`、`$KIT/课件/第二册/第二册课程大纲.md`（范围规则）、`$KIT/试卷/第一册分阶段模拟卷/课程大纲.md`（第一册语法，全部算学过），格式样板 `$KIT/试卷/Metodo1-2高考模拟卷/试卷.md` 看格式即可。

1. **超范围**：短文、对话、题干、选项、写作题目、范文、语法填空提示里的每个动词形式和结构，对照第二册大纲的“起点”和本卷最后一课。先跑 `KIT="$KIT" python3 $W/tools/scan_range.py $W/<文件夹>/试卷.md`，“✗”全部要改掉，“?”逐条看上下文；脚本抓不全，主要靠你逐句看。常见的：早期的卷子里出现副动词（第 3 课前）、将来时（第 7 课前）、que + 虚拟式（第 9 课前）、现在完成时（第 13 课前）、过去完成时（第 15 课前）、条件式和 ser 被动（第 16 课前）、101 以上的数（第 11 课前，听力里）；任何一卷出现虚拟式过去时、状语从句或形容词从句里的虚拟式、ojalá / quizás + 虚拟式、将来完成时、复合条件式。
2. **西语错误**：重音符号、¿¡、性数一致、动词变位、前置词搭配、冠词、语序、不地道的说法；中文题目、说明和译注的错别字、病句。
3. **答案**：每道选择题是否只有一个正确选项；答案表的字母是否就是那个选项；听力答案在原文里有依据、干扰项确实错；阅读答案在短文里有依据；完形每空放进四个选项，是否恰好一个在语法和语义上都通；语法填空是否只有一个答案、提示词给得对；“依据”“考点”写得对不对。
4. **前后一致**：考试说明、知识点覆盖表里说的题号和内容是否和实际题目相符；覆盖表第二册每一课都有题；写作词数要求、范文标注的词数、实际词数一致；“听力录音的结构”和样板一致。
5. **听力原文**是否适合语音合成：没有缩写、括号、引号、数字、中文；每句不太长；男女交替；第 8 段是独白。
6. **原创**：没有照抄课本课文，没有和样板卷重复的短文或情景；没有真实品牌、机构、真人。

## 改法

发现的问题**直接在 `试卷.md` 里改**，改动越小越好：只改有问题的词句，不重写整篇，不改动没问题的题。改了题目要同步改答案表、依据表、覆盖表和听力原文（题干和原文要对得上），并保持答案分布要求（听力 A、B、C 各 6–8；阅读、完形 A–D 各 4–6；同一字母不连续 4 次以上）。改完跑：

```bash
cd 试卷/第二册分阶段模拟卷
python3 tools/check_paper.py <文件夹>/试卷.md                                   # 到 ✓
KIT=../.. python3 tools/scan_range.py <文件夹>/试卷.md   # “✗”为 0
```
