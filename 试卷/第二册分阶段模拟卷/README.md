# 西班牙语高考模拟试卷：《现代西班牙语》第二册分阶段（7 套）

7 套原创模拟卷，按 2024 年起的高考西班牙语新课标卷出，题型、题量和分值和 [Método 1–2 册卷](../Metodo1-2高考模拟卷/) 完全一样：

- 听力 20 题，每题 1.5 分；每段录音播放两遍（2026 年起第一节也播两遍）。
- 阅读 20 题，每题 2.5 分。
- 完形填空 20 题，每题 1 分。
- 语法填空 10 空，每空 1.5 分；恰好 5 空给提示词。
- 写作两节：应用文 10 分，命题短文 25 分。
- 满分 150 分，考试时间 120 分钟。

范围是《现代西班牙语》第二册（老版，董燕生、刘建编，共 18 课）。每套考第一册全部，加上第二册到所标那一课为止的内容。题目、短文、对话和范文都是原创。

每个文件夹里有：

- `试卷.md`：全卷原文，包括考试说明、注意事项、四部分试题、参考答案与评分标准（每题的依据或考点、写作评分档次、两篇范文）、听力原文（含录音结构）和知识点覆盖表。
- `审校记录.md`：独立审校和第二次盲做的结果，以及改了什么。
- `审校_盲做.json`、`复核_盲做.json`：两次盲做的答案。
- `听力/`：时间轴、逐句识别核对、响度核查和成品逐句复核。

## 范围怎么定的

各课的语法和话题按仓库里的 [`课件/第二册/第二册课程大纲.md`](../../课件/第二册/第二册课程大纲.md)。这份大纲是根据课本目录页和网上的学习笔记整理的。第一册的语法全部算学过，见 [`../第一册分阶段模拟卷/课程大纲.md`](../第一册分阶段模拟卷/课程大纲.md)。

各语法点从哪一课起可以用：

| 起始课 | 语法 |
| --- | --- |
| 第 3 课 | 副动词、否定命令式、acabar de、连词 u |
| 第 7 课 | 将来未完成时（第 8 课起也表示推测） |
| 第 8 课 | ir + 副动词 |
| 第 9 课 | 虚拟式现在时用在名词性从句 |
| 第 10 课 | seguir / llevar + 副动词 |
| 第 11 课 | 101 以上的基数词、日期 |
| 第 13 课 | 现在完成时 |
| 第 15 课 | 过去完成时 |
| 第 16 课 | 简单条件式、ser + 过去分词的被动语态 |

任何一卷都不用这些：将来完成时、复合条件式、虚拟式过去时和完成时、状语从句和形容词从句里的虚拟式、ojalá / quizás + 虚拟式。

`tools/scan_range.py` 用仓库四册单词表里的变位表，把卷面上每个动词形式归类，再按上表报超范围。它还会列出第一册和第二册对应课次之外的词形，供出题人决定是加中文注还是换词。

## 怎么出、怎么查的

1. **出题**：每套由一个人按 [`出题要求.md`](出题要求.md) 出题，然后跑 `check_paper.py`（格式和前后一致）和 `scan_range.py`（超范围），一直改到都通过。
2. **独立审校**：另一个人按 [`审校要求.md`](审校要求.md) 审校。
   - 先只看学生版，把 70 题做一遍。学生版由 `tools/student_md.py` 生成，没有答案。
   - 再对答案表，逐项查超范围、西语错误、答案唯一、前后一致、听力原文和原创性，直接改卷子。
   - 结果记在 `审校记录.md`。7 套的盲做都是 70/70。
3. **第二次盲做**：再换一个模型，只看学生版做第二遍，由 `tools/compare_blind.py` 对答案表。
   - 结果：第 1–2 课卷 69/70、第 1–4 课卷 67/70、第 1–6 课卷 70/70、第 1–8 课卷 69/70、第 1–10 课卷 69/70、第 1–14 课卷 69/70、第 1–18 课卷 70/70。
   - 对不上的题逐一查过，都是复核做错（o / u、eran las tres、sin + 原形动词、vosotros 的否定命令式）。
   - 第 1–8 课卷完形第 47 题，复核觉得 veía 也勉强说得通。为了不留争议，空前加了 de repente。
4. **听力**：合成以后每句用语音识别转回文字和原文核对，成品 MP3 再逐句复核（见下一节）。
5. **排版**：用 `check_pdf_text.py` 确认 `试卷.md` 里的每一段文字都在 PDF 里，答题卡的题号和选项齐全；最后逐页看过预览图。

## 听力录音

- **声音**：西语对话用本仓库的六个 Qwen3 声音（男声两个、女声四个），和 Método 卷相同。每段对话里男女声音不同，第 8 段是独白。语速 0.95 倍。
- **中文指令语**：女声，0.92 倍。
- **结构**：按高考格式，依次是试音、中文指令语、读题时间、每段播两遍、作答停顿，最后提示用两分钟转涂答题卡（这两分钟不在录音里）。
- **合成时逐句核对**：每一句都用语音识别转回文字，和原文逐词（中文逐字）核对。西语用 Parakeet-TDT 0.6B v3，中文用 SenseVoice。
- **成品逐句复核**：成品 MP3 里的每一句（对话两遍都算）又切出来重新识别了一遍。
- **核对结果**：7 套全部一致，见下表。整套录音的响度都在 −16 LUFS 左右（目标 −16）。

**为语音识别改过的原文**：有几句换了 9 个种子重新合成，识别还是对不上，就改了原文。改法记在各套的 `审校记录.md` 里，都不影响题目：

- 单独成句的 “Sí.” 被认成 “See”、“C”。4 处 “Sí. …” 改成 “Sí, …”，只改标点和大小写。
- 第 1–2 课卷的 “¿Tienes tos?” 被认成 “¿Tienes dos?”，改成 “¿Tienes mucha tos?”。
- 第 1–8 课卷 Texto 7 的 “Sí, cabrán sin problema.” 每个种子都被认成粗话 “cabrón”，课堂上学生也可能听岔。改成 “Claro, no habrá ningún problema.”，女声问句里的 “¿Cabrán…?” 保留。
- 第 1–14 课卷 Texto 4 的 “¿has ido hoy a la residencia…?”，ido hoy a 三个元音连读，成品复核时第二遍认成 “has ia”。改成 “¿hoy has visitado la residencia…?”。

## 重新生成

在仓库根目录、`setup_mac.sh` 装好的环境里运行。`ASR` 和 `ASR_ZH` 是两个语音识别模型的解压目录，下载地址和 Método 卷的 README 相同。`LISTEN_CACHE` 可以不设；不设时，合成缓存放在各套的 `听力/_合成缓存/`。

```bash
D=试卷/第二册分阶段模拟卷
T=$D/第1-2课
.mac-env/bin/python $D/tools/check_paper.py $T/试卷.md
KIT=. .mac-env/bin/python $D/tools/scan_range.py $T/试卷.md
.mac-env/bin/python $D/tools/make_listening.py build . $T/试卷.md $T/听力 $ASR $ASR_ZH
.mac-env/bin/python $D/tools/make_listening.py final . $T/试卷.md $T/听力 $ASR $ASR_ZH
.mac-env/bin/python $D/tools/patch_duration.py $T/试卷.md $T/听力/听力_时间轴.json
```

排版要 Node.js 的 `docx`（9.5.1）和 `jszip`。PDF 用 LibreOffice 转，字体是 Times New Roman、宋体 Songti SC 和黑体 Heiti SC：

```bash
python3 $D/tools/export_json.py $T/试卷.md out/paper.json $T/听力/听力_时间轴.json
node $D/tools/build_exam.js out/paper.json out
soffice --headless --convert-to pdf --outdir out out/试卷.docx out/答题卡.docx out/答案与评分说明.docx
python3 $D/tools/check_pdf_text.py out/paper.json out/试卷.pdf out/答案与评分说明.pdf "$(which pdftotext)" out/答题卡.pdf
```
