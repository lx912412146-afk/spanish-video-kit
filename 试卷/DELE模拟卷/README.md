# DELE 模拟卷 A1—C1（非官方）

> **非官方模拟卷。** 本卷按塞万提斯学院公开的 DELE 考试结构（各级考试说明和官方样卷的题型、题量、时间、计分）自编，与塞万提斯学院、萨拉曼卡大学都没有关系，也没有经过它们审定。所有文章、对话、录音、插图和题目都是原创，没有使用或改写官方样卷。

A1、A2、B1、B2、C1 五级各一整套，四项齐全：阅读（Comprensión de lectura）、听力（Comprensión auditiva）、写作（Expresión e interacción escritas）、口语（Expresión e interacción orales）。每一级的 tarea 数量、题型、题量、文本长度、作答时间和计分方法都按考试规格（[`考试规格.md`](考试规格.md)），可以直接打印做整套模考。（目前已完成：A1、A2；B1、B2、C1 正在制作，完成后加进同一个 Release。）

## 计分

- 每级四项各 25 分，满分 100。第 1 组＝阅读＋写作，第 2 组＝听力＋口语，**两组各至少 30 分（满分 50）为 APTO**。
- 阅读、听力每题 1 分，不倒扣，本项得分＝答对题数 × 25 ÷ 题数（教师用书有换算表）。
- 写作、口语按官方公布的评分项（整体评分和分项评分）每项 0—3 分，加权后 × 25 ÷ 3；教师用书写明每一级的评分项、权重、分档描述和计算方法，并附评分表。分档描述和组合方式是本卷为课堂评分设计的，结果只作练习参考。

## 怎么用

1. 打印考生题册和答题卡。按封面上的顺序和时间：阅读 → 听力（放 `DELE_<级别>_CA_completa.mp3`，中间不停）→ 写作（B2、C1 写作 Tarea 1 先放 `DELE_<级别>_EIE_T1.mp3`）。
2. 口语一对一进行：考生按题册里的材料准备，考官照教师用书里的考官用语和提问进行，最好录音，之后对照评分标准和参考回答打分。
3. 用教师用书的答案速查批改阅读、听力，按换算表算出各项得分，再按组判断是否通过。

## 文件

| 文件 | 作用 |
| --- | --- |
| `考试规格.md` | 依据、五个级别各项的结构和时间、每个 tarea 的文本长度和题型、录音里的停顿、评分方法；官方文件有出入时本卷的取舍 |
| `审校记录.md` | 编写、独立审校、插图、版面检查和录音核对的经过，以及统稿时的改动 |
| `review/` | 每一级每一部分的独立审校记录（逐条：位置、原来的问题、怎么改的） |
| `content/<级别>/cl.json` | 阅读：文章、题目、答案、中文译文和解析 |
| `content/<级别>/ca.json` | 听力：录音稿（说话人、声音、西语和中文译文）、题目、答案和解析 |
| `content/<级别>/eie.json` | 写作：题目、材料（B2、C1 含录音稿和图表）、评分标准、范文和点评 |
| `content/<级别>/eio.json` | 口语：考生材料、考官用语和提问、参考回答、评分标准 |
| `content/<级别>/art_*.json` | 插图清单：每幅图的用途和画面说明 |
| `art/svg/` | 全部插图的 SVG 原稿（`tools/render_art.py` 渲染成 PNG） |
| `tools/check_content.py` | 内容自查：题号、答案、选项、配对、词数、录音稿的句长和写法 |
| `tools/render_art.py` | 插图：SVG → PNG，并拼核对用的总览图 |
| `tools/asrcheck.py` | 合成和语音识别核对的公用部分 |
| `tools/make_audio.py` | 录音：按 `ca.json`（和 B2、C1 的 `eie.json`）排出每条音轨，合成、逐句识别核对、母带处理，输出 MP3 和 `核对/report.json` |
| `tools/check_final.py` | 成品录音复核：在成品 MP3 里把每一句切出来再识别一遍；核对连播版各段齐全、顺序对 |
| `tools/build_pdf.py` | 排版：由 JSON 生成考生题册、答题卡、教师用书的 HTML，再用 Chromium 打印成 A4 PDF |
| `tools/contact.py` | 把 PDF 每页拼成缩略图，检查版面用 |

## 重新生成

```bash
python3 tools/check_content.py A1                 # 内容自查，最后一行应是 PASS
python tools/render_art.py A1                     # 插图 SVG → PNG（要 Playwright 和 Chromium）
python tools/make_audio.py A1                     # 录音（要本仓库的 Qwen3-TTS 环境和 Parakeet 识别模型）
python tools/check_final.py A1                    # 成品录音复核
python tools/build_pdf.py A1                      # 三本 PDF
```

录音用本仓库的 Qwen3-TTS 合成（男声旁白读说明语，对话按人物分配男女声），每一句都用语音识别和录音稿逐词核对，成品 MP3 再逐句复核；整体响度 −16 LUFS，MP3 128 kbps。
