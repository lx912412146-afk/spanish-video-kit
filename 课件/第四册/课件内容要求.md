# 《现代西班牙语》第四册（老版）分课课件：内容要求

每课一个 JSON 文件（UTF-8），由统一的程序排成 PPT。你只写内容，不管排版。

- 课次内容：本文件夹的 `第四册课程大纲.md`（每课的课文话题、语法、重点词汇，以及末尾的「范围规则」和「课件对同名项目的分工」，必须遵守）。第一、二、三册学生都学过：见仓库里的 `试卷/第一册分阶段模拟卷/课程大纲.md`、`../第二册/第二册课程大纲.md`、`../第三册/第三册课程大纲.md`。
- 格式参考：第三册课件的 `../第三册/content/L09.json`、`L14.json`（看结构和写法即可）。
- 写到：本文件夹的 `content/L01.json` … `L18.json`（两位数编号），JSON 里写 `"book": 4`。
- 自检：`python check_content.py content/L01.json`，改到显示 ✓。

## 原则

1. **准确第一。**语法讲解、变位表、重音符号、¿¡、性数一致都要逐个核对；讲解用中文，面向学完第一至三册的学生（大学二年级下学期水平），清楚、准确、不啰嗦。第四册的语法多是对已学内容的系统小结，讲解要把已学的零散知识归纳清楚，并点出容易混淆的地方。
2. **范围：**第一至三册全部学过；第四册第 N 课的例句、课文、练习只用到第四册第 N 课为止新讲的项目（见大纲的范围规则：例如自由间接引语第 5 课起，cuyo 和中性 lo cual 第 8 课起，指小词指大词第 9 课起，cualquiera 第 10 课起，关系副词 donde、como 第 11 课起，关系词 + 原形动词第 12 课起，sea… o… 第 13 课起，让步从句变体和助动词时态差别第 15 课起，名词补语从句第 16 课起，直接宾语提前第 17 课起，por + 形容词 + que + 虚拟式第 18 课起；整册不用虚拟式将来时和先过去时）。本课的新词可以用；超出的生僻词尽量不用，非用不可时在中文里解释。
3. **原创：**我们手上没有课本原文。课文部分写一段仿照本课话题和语法的原创对话或短文，`note` 写「仿照本课课文编写」。不要声称是课本原文，不要编造课本的页码、练习题号。涉及史实、数据、文学作品情节的，只写可靠、常见的说法，数字用“约、más de、casi”留余地；拿不准的宁可不写。
4. **第四册没有复习课：**18 课每课都有本课语法。目录里同名的两组项目按大纲「课件对同名项目的分工」来写（第 4 课和第 6 课的“句子的分类”；第 5 课和第 18 课的“表示持续的动词短语”），不要两课讲成一样。每课大纲里的“重点词汇”要放进 `vocab`，并在 `phrases`、课文或例句里给出用法；括号里的派生词可以放进同一格（如 `agradecer (agradecido)`）或在 `phrases` 里出现。
5. **正字法：**和第一至三册一致，按老课本的习惯：副词 sólo、指示代词 éste / ése / aquél（作代词时）带重音，作形容词时不带；在 `notes` 里说明 RAE 2010 年起不再要求，学生不加不算错。
6. 不用表情符号；中文用全角标点（中文提示的括号也用全角“（）”），西语用西语标点。

## JSON 结构（字段名照写；带 ? 的可以省略）

```json
{
  "book": 4,
  "lesson": 1,
  "title_es": "El amigo",
  "title_zh": "朋友",
  "goals": ["……", "……"],
  "vocab": [["recorrer", "走遍；浏览"], ["agradecer (agradecido)", "感谢（感激的）"]],
  "text": {"title": "El amigo", "note": "仿照本课课文编写",
           "lines": [{"who": "A", "es": "¿Quién es él?", "zh": "他是谁？"}]},
  "grammar": [
    {"title": "无先行词的关系从句", "points": ["要点一", "要点二"],
     "table?": {"head": ["关系词", "例句"], "rows": [["quien", "Quien busca, encuentra."]]},
     "examples": [["El que llegue primero, gana.", "谁先到谁赢。"]]}
  ],
  "phrases?": [["Te agradezco mucho tu ayuda.", "非常感谢你的帮助。"]],
  "exercises": [{"type": "填空", "q": "______ (quien / el que) mucho habla, poco hace.", "a": "Quien"}],
  "summary": ["……"],
  "homework": ["……"],
  "notes": {"goals": "教学提示", "vocab": "……", "text": "……", "grammar": "……", "exercises": "……"}
}
```

## 数量和长度（程序按这些排版，超了会挤出页面）

| 字段 | 要求 |
| --- | --- |
| `goals` | 3–5 条，每条 ≤ 30 字 |
| `pronunciation` | 第四册不写 |
| `vocab` | 10–18 个；西语 ≤ 26 个字符，中文 ≤ 14 字 |
| `text.lines` | 6–14 行；每行 `es` ≤ 70 个字符；`who` 用 A、B（短文就每行一句，`who` 写空字符串） |
| `grammar` | 2–4 个语法点；每个 `points` 2–4 条、每条 ≤ 46 字；`table` 最多 7 行 × 4 列，格子 ≤ 22 个字符；`examples` 2–4 句，`es` ≤ 60 个字符 |
| `phrases` | 0–8 条 |
| `exercises` | 6–8 题，题型混合（填空、选择、改写、翻译、问答）；`q` ≤ 80 个字符，`a` ≤ 70 个字符；选择题把选项写进 `q`，如 `Ella ___ china. (es / son)` |
| `summary` | 3–5 条，每条 ≤ 34 字 |
| `homework` | 2–4 条，每条 ≤ 40 字 |
| `notes` | 每项 1–3 句教学提示（给老师看的备注） |

语法标题尽量短（≤ 18 字）；太长时程序会把冒号后面的部分放到第二行小字里。
