# 《现代西班牙语》第四册（老版）分课课件

第 1–18 课，每课一个 PowerPoint 课件（16:9），另有同内容的 PDF。PPTX 和 PDF 在 Release [`courseware-book4`](../../../releases/tag/courseware-book4)。版式和[第一册](../第一册/)、[第二册](../第二册/)、[第三册](../第三册/)课件相同，生成程序沿用第三册的版本（长标题拆成主标题和小字细目、课文按实际行数排位置、常用表达卡片按行对齐、表格列宽按内容分配、同一课语法要点字号一致），另外让数字的分节空格不再断行、标题宽度估得更准、语法标题只在冒号处拆行、词汇表两栏按需要分配宽度。

每课的结构：封面 → 本课目标 → 本课词汇 → 课文（仿照本课编写的原创对话或短文，附中文）→ 语法（要点、例句；表格较大时单独一页）→ 常用表达 → 课堂练习 → 练习答案 → 本课小结 → 课后作业。大部分页附有给老师的备注（演讲者备注）。

- 各课的语法、重点词汇和话题按本文件夹的 `第四册课程大纲.md`（照课本目录整理）；第一至三册全部学过，第四册第 N 课的例句、课文和练习只用到第四册第 N 课为止新讲的项目（例如自由间接引语第 5 课起，cuyo 第 8 课起，cualquiera 第 10 课起，por + 形容词 + que 第 18 课起；整册不用虚拟式将来时和先过去时）。
- 第四册每课都有本课语法，多是对已学语法的系统小结；目录里同名的“句子的分类”（第 4、6 课）和“表示持续的动词短语”（第 5、18 课）按大纲里写的分工分别讲。
- 课文不是课本原文。
- 拼写和前三册一样按老版课本的习惯（sólo、éste 等带重音）。
- 字体用苹方（PingFang SC）。Windows 电脑上没有这个字体，PowerPoint 会换成默认中文字体，版式基本不变。

## 文件

| 文件 | 作用 |
| --- | --- |
| `content/L01.json` … `L18.json` | 每课的内容（目标、词汇、课文、语法、练习、小结、作业、教学备注） |
| `build_decks.js` | 用 pptxgenjs 把内容排成 PPTX（统一版式，按文字量自动调字号、分页） |
| `check_content.py` | 内容格式和长度自检 |
| `第四册课程大纲.md` | 第四册 18 课的语法、重点词汇、课文话题和范围规则 |
| `课件内容要求.md`、`课件审校要求.md` | 编写和审校的规则 |

## 重新生成

需要 Node.js 和 `npm install pptxgenjs@3.12.0`：

```bash
node 课件/第四册/build_decks.js          # 全部 18 课，输出到 课件/第四册/out/
node 课件/第四册/build_decks.js 05 06    # 只生成第 5、6 课
```

改某一课的内容只要改对应的 `content/Lxx.json` 再重新生成，先跑 `python check_content.py content/Lxx.json` 检查长度。
