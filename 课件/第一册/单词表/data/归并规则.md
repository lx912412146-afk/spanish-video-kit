# 词形归并规则（《现代西班牙语》第一册老版分课单词表）

输入：`forms_LAA-BB.json`，每条是一个小写词形 `form`、它第一次出现的课 `lesson`、出现次数、是否只以大写出现 `cap_only`，以及 1—2 个例句（`es` 西语、`zh` 中文译文或所在的中文说明、`src` 出处：词汇、语音、课文、语法要点、语法表、语法例句、常用表达、练习、小结、作业）。

输出：同名的 `lex_LAA-BB.tsv`（UTF-8，制表符分隔，第一行是表头），**每个输入词形一行，不多不少，顺序和输入一样**：

```
form	lemma	pos	zh	note
```

- `form`：照抄输入的词形（小写）。
- `lemma`：词典原形。
  - 名词：单数（`casas`→`casa`，`lápices`→`lápiz`）。只用复数或常用复数的照词典写复数并在 note 注明（`afueras`、`gafas`、`vacaciones`）。阴阳两种词尾的人称名词写成 `amigo, amiga`、`profesor, profesora`；阴阳同形的写一个（`estudiante`）。
  - 形容词：阳性单数，有阴性变化的写成 `cubano, cubana`、`español, española`；无变化的写一个（`grande`、`azul`）。
  - 冠词、指示词、物主词、代词：按传统列法，每个形式各自成条，lemma 写阳性单数并在 note 写出全部形式即可（例：`las` → lemma `el`，note `定冠词 el, la, los, las`）。人称代词各自成条（`me`、`te`、`le`、`lo`、`nos`、`os`、`se`、`ella`、`usted`…，lemma 就是它本身）。
  - 动词：不定式。自复用法（`me levanto`、`se llama`、`acuéstate`）lemma 写 `levantarse`、`llamarse`、`acostarse`；同一个动词既有自复又有非自复用法的，按这个例句里的用法写。命令式后面连写代词的（`pruébatelo`、`dígaselo`、`enseñémoselo`）lemma 写动词原形（`probarse`、`decir`、`enseñar`），note 写 `命令式 + 代词 te, lo` 之类。`hay` 的 lemma 写 `haber`。
  - 缩合词各自成条：`del`（de + el）、`al`（a + el）。
  - 数词各自成条（`dos`、`veintiún`…）；`un`、`una`、`uno` 区分冠词和数词，按例句。
  - 人名（Paco、Pepe、Li Xin 的 li 和 xin、Ana、Wagner…）：lemma 写 `#人名`，pos 空，zh 写人名的通用音译（可以空）。
  - 地名、国名、机构名（España、Madrid、Pekín、Prado、Retiro…）：lemma 写首字母大写的原形，pos `地名`，zh 写通用中文名。
  - 课堂用的缩写、外语词、只在语音练习里出现的字母组合、不是词的片段（例如拆开的音节 `pa`、`co`）：lemma 写 `#跳过`，zh 写原因。
  - 句首大写的普通词（`buenos` 在 Buenos días 里）照普通词处理。
- `pos`：只用这些：`m.`（阳性名词）、`f.`（阴性名词）、`m., f.`（阴阳同形或两种词尾的人称名词）、`m. pl.` / `f. pl.`（只用复数的名词）、`adj.`、`adv.`、`prep.`、`conj.`、`art.`、`pron.`、`num.`、`interj.`、`v.`（所有动词，包括自复动词）、`地名`。指示词、物主词放在名词前当形容词用的写 `adj.`，单用的写 `pron.`。
- `zh`：这个词在本课例句里的中文意思，用通行的词典释义（参照《现代西汉汉西词典》的写法），简短；常见的另一个意思可以用“；”隔开加上（最多两三个意思，不超过 16 个字）。**例句出处是“词汇”或“语音”的，那一行的中文就是课件里审校过的释义，直接用它**。形容词写“……的”；动词写“做……”这样的动词释义（`levantarse` 起床，`llamarse` 名叫）。
- `note`：只在需要时写，简短：
  - 动词：这一个词形是什么形式，例如 `陈述式现在时 第三人称单数`、`简单过去时 第一人称单数`、`过去未完成时 第三人称复数`、`命令式 tú`、`命令式 usted + 代词 se, lo`、`不定式`、`现在分词`、`过去分词`。不定式本身写 `不定式`。
  - 名词、形容词：复数、阴性形式（`复数`、`阴性复数`）；不规则的复数写出单数（`lápices 复数`）。
  - 其他需要说明的（`只用复数`、`与 de 缩合`）。

## 要求

- 只根据例句判断；拿不准的词形，在 note 里写 `？` 和你的疑问，不要猜。
- 西语原形的拼写、重音要准确（`fácil`、`lápiz`、`inglés, inglesa`、`joven`→复数 `jóvenes`）。
- 中文释义要准确、自然，不要把例句的整句意思当成单词的意思。
- 不要改动任何别的文件，只写自己的 `lex_LAA-BB.tsv`（用 Write 工具写，不要用命令行重定向）。
