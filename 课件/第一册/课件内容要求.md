# 《现代西班牙语》第一册（老版）分课课件：内容要求

每课一个 JSON 文件（UTF-8），由统一的程序排成 PPT。你只写内容，不管排版。

- 课次内容：仓库里的 `试卷/第一册分阶段模拟卷/课程大纲.md`（每课的语音、语法、话题，以及末尾的「出题时的范围规则」，必须遵守）。
- 写到：本文件夹的 `content/L01.json` … `L24.json`（两位数编号）。
- 自检：`python check_content.py content/L01.json`，改到显示 ✓。

## 原则

1. **准确第一。**语法讲解、变位表、重音符号、¿¡、性数一致都要逐个核对；讲解用中文，面向中国高中生或大学一年级学生，清楚、准确、不啰嗦。
2. **范围：**第 N 课的例句、课文、练习只用第 1–N 课学过的语法（见大纲的范围规则：例如第 1–4 课只有 ser、estar、hay；过去未完成时第 21 课才有；第 22 课以前不用间接引语等）。本课的新词可以用；超出的生词尽量不用，非用不可时在中文里解释。
3. **原创：**我们手上没有课本原文。课文部分写一段仿照本课话题和语法的原创对话或短文，`note` 写「仿照本课课文编写」。不要声称是课本原文，不要编造课本的页码、练习题号。
4. **大纲里标「?」或写着“没有单列语法”的课**（第 18、24 课等）：按大纲写到的内容和复习来安排，不要编造“本课语法”。
5. 不用表情符号；中文用全角标点，西语用西语标点。

## 数量和长度（程序按这些排版，超了会挤出页面）

| 字段 | 要求 |
| --- | --- |
| `goals` | 3–5 条，每条 ≤ 30 字 |
| `pronunciation` | 只有第 1–8 课有（大纲写了语音的课）；1–3 组，每组 `items` 2–6 个；`tip` ≤ 40 字；每个 `words` 2–3 个词 |
| `vocab` | 10–18 个；西语 ≤ 26 个字符，中文 ≤ 14 字 |
| `text.lines` | 6–14 行；每行 `es` ≤ 70 个字符；`who` 用 A、B（短文就每行一句，`who` 写空字符串） |
| `grammar` | 2–4 个语法点；每个 `points` 2–4 条、每条 ≤ 46 字；`table` 最多 7 行 × 4 列，格子 ≤ 22 个字符；`examples` 2–4 句，`es` ≤ 60 个字符 |
| `phrases` | 0–8 条 |
| `exercises` | 6–8 题，题型混合（填空、选择、改写、翻译、问答）；`q` ≤ 80 个字符，`a` ≤ 70 个字符；选择题把选项写进 `q`，如 `Ella ___ china. (es / son)` |
| `summary` | 3–5 条，每条 ≤ 34 字 |
| `homework` | 2–4 条，每条 ≤ 40 字 |
| `notes` | 每项 1–3 句教学提示（给老师看的备注） |
