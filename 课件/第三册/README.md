# 《现代西班牙语》第三册（老版）分课课件

第 1–18 课，每课一个 PowerPoint 课件（16:9），另有同内容的 PDF。PPTX 和 PDF 在 Release [`courseware-book3`](../../../releases/tag/courseware-book3)。版式和[第一册](../第一册/)、[第二册](../第二册/)课件相同。本册的 `build_decks.js` 在排版上有几处改进：课文按每句实际行数排位置；过长的标题拆成主标题和下面一行小字；常用表达卡片左右按行对齐；表格列宽按内容分配；同一课各页语法要点用同一个字号，单独成页的表格字号也尽量一致。第一、二册文件夹里的生成器保持原样，用它们重新生成的课件和已发布的一致。

每课的结构：封面 → 本课目标 → 本课词汇 → 课文（仿照本课编写的原创对话或短文，附中文）→ 语法（要点、例句；变位表较大时单独一页）→ 常用表达 → 课堂练习 → 练习答案 → 本课小结 → 课后作业。大部分页附有给老师的备注（演讲者备注）。

- 各课的语法、重点词汇和话题按本文件夹的 `第三册课程大纲.md`（照课本目录整理）；第一、二册全部学过，第三册第 N 课的例句、课文和练习只用到第三册第 N 课为止学过的语法（例如虚拟式过去未完成时第 2 课起，Si tuviera…, haría… 第 5 课起，虚拟式过去完成时第 9 课起，将来完成时第 13 课起）。
- 课文不是课本原文。第 6、12、18 课课本目录里没有语法，课件按复习课处理。
- 拼写和第一册一样按老版课本的习惯（sólo、éste 等带重音）。
- 字体用苹方（PingFang SC）。Windows 电脑上没有这个字体，PowerPoint 会换成默认中文字体，版式基本不变。

## 文件

| 文件 | 作用 |
| --- | --- |
| `content/L01.json` … `L18.json` | 每课的内容（目标、词汇、课文、语法、练习、小结、作业、教学备注） |
| `build_decks.js` | 用 pptxgenjs 把内容排成 PPTX（统一版式，按文字量自动调字号、分页） |
| `check_content.py` | 内容格式和长度自检 |
| `第三册课程大纲.md` | 第三册 18 课的语法、重点词汇、课文话题和范围规则 |
| `课件内容要求.md`、`课件审校要求.md` | 编写和审校的规则 |

## 重新生成

需要 Node.js 和 `npm install pptxgenjs@3.12.0`：

```bash
node 课件/第三册/build_decks.js          # 全部 18 课，输出到 课件/第三册/out/
node 课件/第三册/build_decks.js 05 06    # 只生成第 5、6 课
```

改某一课的内容只要改对应的 `content/Lxx.json` 再重新生成，先跑 `python check_content.py content/Lxx.json` 检查长度。
