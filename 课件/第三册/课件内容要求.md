# 《现代西班牙语》第三册（老版）分课课件：内容要求

每课一个 JSON 文件（UTF-8），由统一的程序排成 PPT。你只写内容，不管排版。

- 课次内容：本文件夹的 `第三册课程大纲.md`（每课的课文话题、语法、重点词汇，以及末尾的「范围规则」，必须遵守）。第一、二册学生都学过：见仓库里的 `试卷/第一册分阶段模拟卷/课程大纲.md` 和 `../第二册/第二册课程大纲.md`。
- 格式参考：第二册课件的 `../第二册/content/L09.json`、`L16.json`（看结构和写法即可）。
- 写到：本文件夹的 `content/L01.json` … `L18.json`（两位数编号），JSON 里写 `"book": 3`。
- 自检：`python check_content.py content/L01.json`，改到显示 ✓。

## 原则

1. **准确第一。**语法讲解、变位表、重音符号、¿¡、性数一致都要逐个核对；讲解用中文，面向学完第一、二册的学生（大学二年级水平），清楚、准确、不啰嗦。
2. **范围：**第一、二册全部学过；第三册第 N 课的例句、课文、练习只用到第三册第 N 课为止学过的语法（见大纲的范围规则：例如虚拟式过去未完成时第 2 课起，Si tuviera…, haría… 第 5 课起，虚拟式过去完成时和复合条件式第 9 课起，形容词从句里的虚拟式第 11 课起，将来完成时第 13 课起，虚拟式现在完成时第 15 课起，el cual 第 17 课起；整册不用虚拟式将来时和先过去时）。本课的新词可以用；超出的生词尽量不用，非用不可时在中文里解释。
3. **原创：**我们手上没有课本原文。课文部分写一段仿照本课话题和语法的原创对话或短文，`note` 写「仿照本课课文编写」。不要声称是课本原文，不要编造课本的页码、练习题号。
4. **复习课（第 6、12、18 课，课本目录里没有语法）**：语法部分标题写成“复习：……”，复习前面几课的语法，不要编造“本课语法”。每课大纲里的“重点词汇”要放进 `vocab`，并在 `phrases` 或例句里给出用法。
5. 不用表情符号；中文用全角标点，西语用西语标点。

## JSON 结构（字段名照写；带 ? 的可以省略）

```json
{
  "book": 3,
  "lesson": 1,
  "title_es": "¿Quién es él?",
  "title_zh": "他是谁？",
  "goals": ["……", "……"],
  "pronunciation?": [
    {"title": "元音 a e i o u", "intro": "一句总说明",
     "items": [{"sound": "a", "tip": "口型说明", "words": [["mapa", "地图"], ["papá", "爸爸"]]}]}
  ],
  "vocab": [["amigo, amiga", "朋友"], ["cubano, cubana", "古巴人；古巴的"]],
  "text": {"title": "¿Quién es él?", "note": "仿照本课课文编写",
           "lines": [{"who": "A", "es": "¿Quién es él?", "zh": "他是谁？"}]},
  "grammar": [
    {"title": "动词 ser 的现在时", "points": ["要点一", "要点二"],
     "table?": {"head": ["人称", "ser"], "rows": [["yo", "soy"], ["tú", "eres"]]},
     "examples": [["Él es Paco.", "他是帕科。"]]}
  ],
  "phrases?": [["¿Cómo se llama usted?", "您叫什么名字？"]],
  "exercises": [{"type": "填空", "q": "Ana es ______. (chino)", "a": "Ana es china."}],
  "summary": ["……"],
  "homework": ["……"],
  "notes": {"goals": "教学提示", "pronunciation": "……", "vocab": "……", "text": "……", "grammar": "……", "exercises": "……"}
}
```

## 数量和长度（程序按这些排版，超了会挤出页面）

| 字段 | 要求 |
| --- | --- |
| `goals` | 3–5 条，每条 ≤ 30 字 |
| `pronunciation` | 第三册不写 |
| `vocab` | 10–18 个；西语 ≤ 26 个字符，中文 ≤ 14 字 |
| `text.lines` | 6–14 行；每行 `es` ≤ 70 个字符；`who` 用 A、B（短文就每行一句，`who` 写空字符串） |
| `grammar` | 2–4 个语法点；每个 `points` 2–4 条、每条 ≤ 46 字；`table` 最多 7 行 × 4 列，格子 ≤ 22 个字符；`examples` 2–4 句，`es` ≤ 60 个字符 |
| `phrases` | 0–8 条 |
| `exercises` | 6–8 题，题型混合（填空、选择、改写、翻译、问答）；`q` ≤ 80 个字符，`a` ≤ 70 个字符；选择题把选项写进 `q`，如 `Ella ___ china. (es / son)` |
| `summary` | 3–5 条，每条 ≤ 34 字 |
| `homework` | 2–4 条，每条 ≤ 40 字 |
| `notes` | 每项 1–3 句教学提示（给老师看的备注） |
