# 词形归并规则（《现代西班牙语》第三册老版分课单词表）

第三册单词表接着第一、二册排：前两册学过的词不再算新词。前两册的词条都在 `prior_lemmas.tsv`：原形、词性、第一次学的释义、第一次出现在哪册哪课（“第一册语音N”表示只在第一册第 N 课语音练习里出现过，第二册也没学），最后一栏是前两册学过的全部意思（第二册给第一册的词补过新意思的，都列在里面，标“新义”）。

## 一、新词形：`forms_LAA-BB.json` → `lex_LAA-BB.tsv`

输入：前两册都没出现过的词形。每条是一个小写词形 `form`、它在第三册第一次出现的课 `lesson`、出现次数、是否只以大写出现 `cap_only`，以及 1—2 个例句（`es` 西语、`zh` 中文译文或所在的中文说明、`src` 出处：词汇、课文、语法要点、语法表、语法例句、常用表达、练习、小结、作业）。

输出：同名的 `lex_LAA-BB.tsv`（UTF-8，制表符分隔，第一行是表头），**每个输入词形一行，不多不少，顺序和输入一样**：

```
form	lemma	pos	zh	note
```

- `form`：照抄输入的词形（小写）。
- `lemma`：词典原形。
  - **属于前两册已有词条的**（比如 `tuviera` 是第一册的 `tener`，`hubiéramos` 是第一册的 `haber`，`ciudades` 是第一册的 `ciudad`）：lemma、pos、zh 照抄 `prior_lemmas.tsv` 里那一条（zh 抄第三栏），一个字都不要改；只有这个例句里的意思和前两册学过的所有意思（第五栏）都明显不同时，zh 写这里的意思，note 加一段 `第三册新义`。
  - 名词：单数（`casas`→`casa`，`lápices`→`lápiz`）。只用复数或常用复数的照词典写复数并在 note 注明（`afueras`、`gafas`、`vacaciones`）。阴阳两种词尾的人称名词写成 `amigo, amiga`、`profesor, profesora`；阴阳同形的写一个（`estudiante`）。
  - 形容词：阳性单数，有阴性变化的写成 `cubano, cubana`、`español, española`；无变化的写一个（`grande`、`azul`）。绝对最高级（`riquísimo`）lemma 写原形容词，note 写 `绝对最高级`。
  - 冠词、指示词、物主词、代词：按传统列法，每个形式各自成条，lemma 写阳性单数并在 note 写出全部形式即可（例：`las` → lemma `el`，note `定冠词 el, la, los, las`）。人称代词各自成条（`me`、`te`、`le`、`lo`、`nos`、`os`、`se`、`sí`、`consigo`…，lemma 就是它本身）。关系代词 `cual`、`cuales`（el cual、la cual、los cuales）lemma 写 `cual`。中性冠词 `lo` 和中性代词 `lo` 按例句分。
  - 动词：不定式。
    - 自复动词、代词式动词（`me levanto`、`se queja`、`atreverse`）lemma 写 `levantarse`、`quejarse`、`atreverse`；相互动词（`se ayudan uno a otro`）lemma 写 `ayudarse`，zh 写“互相……”。同一个动词既有自复又有非自复用法的，按这个例句里的用法写。课件生词表写成 `extender(se)`、`contar(se)` 的，按例句判断是哪一个。
    - **自复被动句、无人称句里的 se**（`se venden billetes`、`se dice que…`、`aquí se habla español`）不是自复动词：lemma 写不带 se 的原形（`vender`、`decir`、`hablar`）。
    - 命令式、不定式、副动词后面连写代词的（`pruébatelo`、`dígaselo`、`diciéndole`、`verlo`）lemma 写动词原形，note 写 `命令式 usted + 代词 se, lo`、`副动词 + 代词 le`、`不定式 + 代词 lo` 之类。`hay` 的 lemma 写 `haber`。
    - **过去分词**：用在 haber 后面的复合时态（`he comido`、`había salido`、`habrá terminado`、`hubiera llegado`、`haber visto`）、ser 被动语态（`fue construido`）、分词短语和混合补语（`ir cansado`、`tener escritas tres cartas`）里的，lemma 写动词原形，note 写 `过去分词`（有性数变化的写 `过去分词（阴性复数）`）。用作形容词的（`estar cansado`、`una puerta abierta`）：这一课的生词表（出处“词汇”）列成形容词的、`prior_lemmas.tsv` 里已经是形容词的、或者词典单列为形容词而且意思已经不同于动词的（`cansado` 累的、`ocupado` 忙的、`aburrido` 无聊的），lemma 写形容词 `cansado, cansada`、pos `adj.`；其余的照过去分词归到动词，note 写 `过去分词；作形容词`。
  - 缩合词各自成条：`del`（de + el）、`al`（a + el）。
  - 数词各自成条（`doscientos`、`mil`…），有阴性的写 `doscientos, doscientas`，pos `num.`；`millón`、`billón`、`millar` 是名词（pos `m.`，note `数词`）。`un`、`una`、`uno` 区分冠词和数词，按例句。序数词作形容词：`quinto, quinta`，pos `adj.`，note `序数词`（`primer`、`tercer` 这样的短尾 note 写 `primero 的短尾，用在阳性单数名词前`）。分数（第 5 课：`tercio`、`cuarto`、`quinto`… 作名词“几分之一”）：作名词用的写 pos `m.`，zh 写“三分之一”这类，note `分数`。集合数词（`docena`、`decena`、`centenar`、`par`）是名词。
  - 指小词、指大词（`casita`、`perrito`、`librote`）：lemma 写原词（`casa`、`perro, perra`），note 写 `指小词` 或 `指大词`；意思已经变了、词典单列的（`bolsillo`、`ventanilla`、`bocadillo`）照普通词处理。构词法（第 11、14、15 课）里举的派生词（`deshacer`、`panadería`、`lechero`…）都是普通的词，照普通词处理；语法要点里单独举的前缀、后缀（`des-`、`-ería`、`-dor`）lemma 写 `#跳过`。
  - 以 -mente 结尾的副词各自成条（`lentamente`，pos `adv.`）。
  - 人名（Paloma、Pedro、Noé、Colón、Cervantes、Goya、Velázquez、Prometeo、Zeus…）：lemma 写 `#人名`，pos 空，zh 写人名的通用音译（可以空）。神话、宗教人物（Dios 除外）、小说人物也算人名。
  - 地名、国名、机构名、作品名里的专有名词（España、Numancia、Roma、Egipto、Macondo…）：lemma 写首字母大写的原形，pos `地名`，zh 写通用中文名。民族、国籍词（`romano`、`numantino`、`egipcio`）按普通名词、形容词处理。书名、画名里的普通词（`Cien años de soledad` 的 `soledad`）照普通词处理。
  - 课堂用的缩写、外语词、不是词的片段（语法要点里的词尾 `-ra`、`-se`、`-mente`、前缀、后缀）、练习里故意写错的形式：lemma 写 `#跳过`，zh 写原因。
  - 句首大写的普通词照普通词处理。
- `pos`：只用这些：`m.`（阳性名词）、`f.`（阴性名词）、`m., f.`（阴阳同形或两种词尾的人称名词）、`m. pl.` / `f. pl.`（只用复数的名词）、`adj.`、`adv.`、`prep.`、`conj.`、`art.`、`pron.`、`num.`、`interj.`、`v.`（所有动词，包括自复动词）、`地名`。指示词、物主词放在名词前当形容词用的写 `adj.`，单用的写 `pron.`。
- `zh`：这个词在本课例句里的中文意思，用通行的词典释义（参照《现代西汉汉西词典》的写法），简短；常见的另一个意思可以用“；”隔开加上（最多两三个意思，不超过 16 个字）。**例句出处是“词汇”的，那一行的中文就是课件里审校过的释义，直接用它**（课件把两个词写在一行的，比如 `contar(se)`〈数；讲述；（se）算作〉，取属于这个词的那部分）。形容词写“……的”；动词写动词释义（`levantarse` 起床，`quejarse` 抱怨）。
- `note`：只在需要时写，简短，几段之间用“；”隔开：
  - **动词：第一段写这一个词形是什么形式**，只能用下面这些写法（程序会逐条核对）：
    - `陈述式现在时 第三人称单数`、`简单过去时 第一人称单数`、`过去未完成时 第三人称复数`、`将来未完成时 第一人称复数`、`简单条件式 第二人称单数`、`虚拟式现在时 第三人称复数`；
    - 第三册新学的：`虚拟式过去未完成时 第三人称复数`（-ra 形式：hablara、tuviera）、`虚拟式过去未完成时 -se 形式 第一人称单数`（-se 形式：hablase、tuviese）；
    - 人称：第一/第二/第三人称单数/复数；过去未完成时、简单条件式、虚拟式现在时、虚拟式过去未完成时的第一、第三人称单数同形，按例句写其中一个就行；
    - `命令式 tú`、`命令式 usted`、`命令式 nosotros`、`命令式 vosotros`、`命令式 ustedes`，连写代词的 `命令式 tú + 代词 te, lo`；
    - `不定式`、`副动词`、`过去分词`，连写代词的 `不定式 + 代词 lo`、`副动词 + 代词 se`。
  - 动词的第二段起写用法，只在下面几种情况写：虚拟式现在时用在否定命令式里的，写 `用于否定命令式 no hagas`（换成这个词形）；haber 作助动词的，写 `助动词，构成现在完成时`（或 `过去完成时`、`将来完成时`、`复合条件式`、`虚拟式现在完成时`、`虚拟式过去完成时`、`复合原形动词`）；过去分词作形容词的，写 `作形容词`；用于被动语态的，写 `用于被动语态 ser + 过去分词`。
  - 名词、形容词：复数、阴性形式（`复数`、`阴性复数`）；不规则的复数写出单数（`lápices 复数`）。
  - 其他需要说明的（`只用复数`、`与 de 缩合`、`指小词`）。

## 二、前两册见过的词形：`known_LAA-BB.json` → `known_LAA-BB.tsv`

输入：第三册里出现、前两册也出现过的词形，`prev` 是前两册把它归到的词条（原形（词性）学过的全部意思和出处），`ex` 是第三册第一次出现那一课的 1—2 个例句。要查的是：第三册里这个词形有没有**前两册没有的另一个词或另一个意思**——同形异义词（`sobre` 前置词“在……上”和名词 `el sobre`“信封”）、另一个词性（`bajo` 形容词 → 前置词“在……下”）、明显不同的新意思（前两册的释义都套不上，比如 `contar` 学过“讲述；数”，第三册 `contar con` 是“拥有；指望”）。只看例句不够时，到 `sentences.json`（或 `agent_in/sentences.txt`）里查这个词形在第三册各课的所有用法。

输出：`known_LAA-BB.tsv`，**只列有问题的，没有就只写表头**：

```
form	lesson	lemma	pos	zh	note
```

- `lesson`：第三册里第一次用作这个新词、新意思的课（不一定是输入里的 `lesson`）。
- `lemma`、`pos`、`zh`：照第一部分的规则写这个新词条或新意思。
- `note`：第一段写 `同形词`（另一个词或另一个词性）或 `第三册新义`（同一个词的新意思）；动词照第一部分写形式说明，放在第二段。
- 语法功能上的细微差别（比如 `que` 引导虚拟式从句、`se` 用于被动句、`como` 引导条件句）不算新意思，不列。只在课件生词表的短语里出现的新意思（`al cabo de`、`dar con`），短语会单独列出，也不用列。

## 要求

- 只根据例句判断；拿不准的词形，在 note 里写 `？` 和你的疑问，不要猜。
- 西语原形的拼写、重音要准确（`fácil`、`lápiz`、`inglés, inglesa`、`joven`→复数 `jóvenes`）。课件用老版拼写（`sólo`、`éste`），照课件写。
- 中文释义要准确、自然，不要把例句的整句意思当成单词的意思。
- 不要改动任何别的文件，只写自己的输出文件（用 Write 工具写，不要用命令行重定向）。
