# HSK1 中文阅读视频：文章 JSON 补写规范

这 50 篇来自用户的 Word 原件《HSK 1级中文阅读教材 · 第一册：我的中文生活》，读者是**西班牙语母语的中文初学者**。每篇做成一个逐句精读视频：汉字上方逐字注拼音（ruby）、重点词汇编号并在右侧给出拼音和西语释义、原文下面是西语翻译。参考已完成的 `中文阅读/文章/hsk1_01.json`。

文件在 `中文阅读/文章/hsk1_XX.json`。只改分给你的文件，只改下面列的字段，其他字段（zh、py、ruby、id、series、header）不动。

## 要补的内容

1. **es（每句的西语翻译）**：准确、自然、简短，忠实于中文，不增不减；语气和中文一致。用西班牙的标准西语（和用户教学用的《现代西班牙语》一致）：对大家说话用 vosotros（如 Encantada de conoceros）。说话人的性别：原文看得出来的照原文（如第 01 篇安娜是女的）；看不出来的照原件西语标题的用法（如原件标题 Hoy estoy contento 是阳性，就用阳性）；都没有线索就用阳性。数字写成单词还是阿拉伯数字都可以，同一篇里一致。
2. **补充词条**：没有词条的句子（`w` 是空的），从这句里挑 1–2 个初学者该学的词补上（HSK1 范围的常用词优先，同一篇前面已经列过的词不要重复），格式：
   `{"h": "高兴", "py": "gāoxìng", "es": "contento; alegre", "surface": "高兴", "source": "supplement"}`
   - surface 必须在这句里原样出现，不能和这句已有的词条重叠。
   - py 照这句原件拼音里这个词的写法（声调、变调、轻声都照原件），连写，小写（专有名词除外）。
   - es 释义简短准确（用分号分隔多个意思），取这句里的意思。
   已经有词条的句子不用补。
3. **title_ruby（标题逐字注音）**：程序先用课文里的注音或 pypinyin 生成，请逐字核对并改对：声调、轻声（如 朋友 péngyou 的 you、东西 dōngxi 的 xi）、变调要和原件课文的写法习惯一致——原件课文对“一”“不”标变调（如 yì míng、bú shì），标题也照这个规则；标题开头的普通词小写，专有名词（中国、中文、北京、人名）大写。格式是 `[["我","wǒ"],["的","de"],…]`。
4. **核对原件的词汇表**（`source: "doc"` 的词条）：原件的拼音和西语释义一般照原样保留。确实错了的（拼音和课文对不上、西语释义错）才改，改了写进 _说明。
5. **_说明**：一段中文，写这篇的特别处理：哪些句子的翻译有取舍（比如性别、时态、vosotros）、补了哪些词、改了原件哪里。参考第 01 篇。

## 交之前

对每个文件运行：
`python 中文阅读/tools/check_json.py <文件>…`，必须全部 ✓。

改 JSON 时用 Python 读写（`json.load` / `json.dump(..., ensure_ascii=False, indent=1)`），不要手工拼字符串。

最后用中文汇报（200 字以内）：每篇补了几个词、改了原件哪里、拿不准的地方。
