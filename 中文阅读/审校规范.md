# HSK1 中文阅读视频：文章 JSON 审校规范

你是独立审校，没有参与补写。先读 `补写规范.md`（补写要求），再逐篇审分给你的文件（`中文阅读/文章/hsk1_XX.json`）。改之前把文件备份到给你的备份目录，改完 diff 确认只有你的改动。

逐句查（不要抽样）：
1. **西语翻译 es**：意思和中文完全一致（不增不减、时态和人称对、单复数和性别处理合理、数字对），西语地道、拼写和重音（á é í ó ú ñ ¿ ¡）正确，标点合乎西语规范。用西班牙标准西语（对大家说话用 vosotros）。
2. **词条 w**：
   - 原件词条（source: doc）：拼音和这句课文的拼音一致；西语释义准确（原件确实错了才改，并在 _说明 里写明）。
   - 补充词条（source: supplement）：词选得合适（初学者该学的常用词，同篇前面没有列过），拼音和这句课文一致（声调、变调、轻声照原件），西语释义准确简洁、取句中义。
3. **title_ruby**：逐字核对标题注音：声调、轻声（朋友 péngyou、东西 dōngxi 等）、“一”“不”的变调照原件课文的习惯（原件标变调），标题开头普通词小写、专有名词大写。
4. **_说明**：和实际内容一致。

只改错的，改动越小越好。改完对每个文件运行：
`python 中文阅读/tools/check_json.py <文件>…`，必须全部 ✓。改 JSON 用 Python 读写，不要手工拼字符串。

最后用中文汇报（250 字以内）：改了哪些（篇、句：原来 → 现在）、拿不准没改的。
